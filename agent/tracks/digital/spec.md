# 数字营销赛道 · 赛道规范（digital）

> 适用：全国高校商业精英挑战赛 品牌策划竞赛——数字营销赛道（2026 新设，研究生 / 本科 / 高职组）。交付物为**数字营销方案**（PDF）+ **创意短视频**（≤ 3 分钟，≤ 50 MB，须在 ≥ 3 个平台公开发布并带话题 #全国高校商业精英挑战赛 #数字营销赛）。本系统生成方案全文、短视频脚本与分镜、平台发布与数据回收计划；视频拍摄由团队完成。

## 0. 硬约束（2026 届细则）

| 项 | 要求 |
|---|---|
| 方案 | A4 竖版 PDF，中文，除封面目录外 ≤ 80 页（含短视频脚本、各平台传播数据等附页） |
| 封面 | 作品名称、团队名称、指导企业名称；不含人员姓名与联系方式；全文与短视频不得出现院校名称 / 图片 / LOGO；队名与作品名不得含高校 / 机构 / 企业简称、LOGO、敏感词、品牌恶搞 |
| 短视频 | MP4 ≤ 3 分钟 ≤ 50 MB，画面清晰、音画同步；≥ 3 个平台（抖音 / 小红书 / B 站等）公开发表并带指定话题；使用企业商标 / LOGO / 广告语 / 图片 / 视频须授权；非原创素材用免版权或授权素材并注明来源；遵守《广告法》与平台规则 |
| 命名 | “学校名称-团队名称-作品名称-作品形式”（短视频 / 数字营销方案） |
| 评分 | 预选赛：短视频 40（契合度 / 制作质量 / 平台适配与互动 / 创新亮点各 10）+ 方案 60；总决赛：方案 60 + 展示答辩 40（8 × 5） |
| AI | 严禁抄袭 / 完全使用 AI 工具创作；本系统为辅助底稿 |

## 3. 写作要点
1. 平台机制要写对（抖音完播 / 互动权重、小红书搜索与收藏、B 站长内容），用数据说明为何选该平台。
2. 短视频创意：钩子（前 3 秒）→ 冲突 → 反转 / 价值 → 行动号召；与方案策略互相印证；拍摄可行（学生团队可执行）。
3. 数据必须标注口径：平台后台 / 第三方（蝉妈妈、新榜）/ 模拟预估；模拟数据带【示例数据】标记。
4. 合规清单：广告法禁用词、平台广告标识、素材授权、未成年人与隐私。
