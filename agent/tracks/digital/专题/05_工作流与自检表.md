## 2. 研究员要抓的数据源与 CSV 字段
- 研究员 A（行业与平台）：统计局 / 行业协会（规模、线上渗透）；CNNIC 报告（短视频 / 直播用户规模）；平台官方（巨量算数 https://trendinsight.oceanengine.com/ ，访问 2026-10-25、抖音电商 / 小红书 / B 站年度报告）；第三方（QuestMobile、克劳锐、飞瓜等）。CSV：`平台趋势.csv`（平台 / 指标 / 数值 / 口径 / 年份 / source）。
- 研究员 B（消费者与渠道）：媒介习惯、决策触点、价格带、内容偏好。CSV：`媒介习惯.csv`、`价格带.csv`。
- 研究员 C（竞品与标杆）：3–5 家竞品 + 1–2 个跨界标杆的账号资产与代表性案例。CSV：`竞品数字表现.csv`（品牌 / 平台 / 粉丝 / 近 90 天作品数 / 均赞 / 互动率 / 直播场次 / 估算 GMV / source）、`竞品案例.csv`。
- 研究员 D（企业与政策）：企业账号盘点、店铺数据、历史活动；法规条款（广告法第九 / 十三 / 十四 / 三十八条，互联网广告管理办法第九 / 十九条，网络主播行为规范第十四条，平台规则）。CSV：`企业数字资产.csv`、`政策条款.csv`（法规 / 条款 / 要点 / 约束 / url / accessed）。
- 消费者洞察：问卷 ≥ 25 题中 ≥ 6 题为媒介与触点（常用平台、种草来源、搜索习惯、直播购买），2 题为短视频创意测试；`synthetic` 结果全部标注。

## 3. 策略阶段产出清单（写进 `02_策略/策略框架.md`）
1. 问题树 ≤ 3 + 洞察句（人群 + 场景 + 冲突）。
2. 定位陈述句 + 策略屋（洞察 → 定位 → Big Idea → 五条策略 → KPI）。
3. Big Idea 候选 ≥ 10 → 前 3 对照 → 定选 1 + 与竞品主题差异矩阵。
4. 人群 × 场景 × 平台矩阵草表（平台 ≤ 4，写明不选项）。
5. 5A 目标草表（现状估算 / 目标 / 链路）。
6. 短视频创意一句 + 形式 + 钩子 + CTA；三平台适配要点。
7. 互动机制一句 + 二次传播路径。
8. 各章结论句（7 句，带数字）+ 数字需求单。

## 4. 财务：budget 模式特有要求
- `assumptions.json`：`mode = budget`；`totalCap` 取任务书上限或企业年营收合理比例（写假设与依据）；`phases` 三阶段，每行 `item / unitPrice / quantity / unit / source`，`unit` 用 CPM / CPC / CPE / 条 / 场 / 人天；`contingencyPct` 0.05–0.10；`kpis` ≥ 5 行；`roi.incrementalRevenue` 由漏斗推出。模板：`python -m bizkit.finmodel --example budget`。
- 单价来源优先级：平台后台当期报价 > 官方刊例 / 帮助中心 > 第三方报告 > 建模估算（标“估算”）；达人单价与 CPM 分列。
- 特有表：预算明细（含来源列）、三阶段 × 渠道交叉表、KOL / KOC 分层预算、直播成本（场次 × 人天 + 投流）、内容制作、机动金；KPI 表；ROI 三情景；敏感性（CPM / CTR / 转化率 / 客单 / 达人单价 ±20%）。
- 数字账本 key（`numbers.json`）：`budget_total`、`budget_contingency`、`kpi_exposure`、`kpi_interaction`、`kpi_conversion`、`kpi_search`（可选）、`kpi_gmv`（可选）、`roi`、`sample_size`；研究数字加 `research_` 前缀。
- 反常即查：ROI > 10 倍、CPM 低于行业 1/3、互动率 > 15%、KOL 单价偏离刊例 3 倍。

## 5. 写手落点
第 2 章首段“企业数字化卡在哪 + 2 个反差数字”；第 3 章首段洞察句；第 4 章首段策略主张 + Big Idea，分镜表后接短视频四项得分段；第 5 章首段总预算与阶段结构；第 6 章首段关键数字卡 + ROI 一句；结语 ≤ 150 字。路演骨架见 `06`。
