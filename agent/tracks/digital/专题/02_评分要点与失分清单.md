# 02 评分要点与失分清单（逐条对应官方评分表）

> 来源：2026 数字营销赛道细则第七节与附件 1（`docs/research/raw/sues_2026_品牌策划竞赛数字营销赛道方案及细则_sues.pdf`，访问 2026-10-25）。预选赛 = 短视频 40 + 方案 60；总决赛 = 方案 60 + 展示答辩 40（8 × 5）。方案每项 0–10 分（差 1–2 / 中差 3–4 / 中等 5–6 / 好 7–8 / 极好 9–10），展示每项 0–5。`rubric.json` 把 6 项映射为 analysis / insight / channel / data / plan / innovation + structure；“国金”= 92 档、“国银”= 85 档。

## 1. 方案 6 项（60 分）

| 官方评分项（10 分） | 国金作品长什么样（92 档） | 国银差在哪（85 档的常见缺口） | 典型失分点 → 规避动作 |
|---|---|---|---|
| 分析全面性与深度 | 第 2 章数字资产盘点表（平台 / 粉丝 / 互动率 / GMV / 来源）+ 问题树 ≤ 3；第 3 章用户群体 / 文化偏好 / 消费习惯 / 政策法规四项均有数据；一手调研五要素；竞品数字营销案例 ≥ 3（玩法 / 数据 / 启示）；结论回指表号或文献号；≥ 1 条反直觉发现 | 四项中有一项只有定性；竞品案例无数据；结论不回指证据 | 罗列企业荣誉（细则：“不可直接沿用企业现有成就和做法”）→ 荣誉 ≤ 5% 篇幅；“据统计”无来源 → 四要素；无一手调研 → `has_primary_research` 失败封顶 2 分 |
| 用户洞察与策略定位 | 画像 ≥ 2 个（含媒介习惯）；洞察句 = 人群 + 场景 + 冲突，有一手数据支撑；人群 × 场景 × 平台矩阵；定位陈述句；Big Idea 一句可复述；候选淘汰理由 | 洞察 = 常识（“年轻人追求个性”）；Big Idea 不可一句复述；缺矩阵 | 画像来自二手报告拼贴 → 用问卷交叉表；Big Idea 缺位 → `big_idea` 检查失败封顶 2 分 |
| 策略可行性与渠道匹配度 | 平台 × 角色 × 机制匹配表，每个平台有基线与目标；内容形态与频次；KOL / KOC 分层表（数量 / 单价来源 / 预期曝光）；短视频脚本可拍（分镜 + 时长 + 字幕 + 素材授权）且与 Big Idea 一致；排期；备选方案 | 机制说明空泛；KOL 只写“头部达人”；脚本无分镜时长 | 全平台撒网 → ≤ 4 个主平台并说明不选项；`platform_matrix` / `short_video_script` 失败封顶 3 分 |
| 数据逻辑与评估机制 | 漏斗（曝光 → 播放 → 完播 → 互动 → 搜索 → 进店 → 转化 → 复购）各层转化率有来源；KPI 表 ≥ 5 行含基线 / 目标 / 测算依据 / 工具 / 周期；短视频数据标注实际 / 模拟口径；归因方法；三情景；复盘节奏与停投规则 | 有漏斗无测算；缺基线或工具；模拟数据未标注 | KPI 只有曝光 → `kpi_table` 失败封顶 2 分；模拟当实际 → 示例数据铁律；ROI 凑整 → 保留计算值 |
| 执行计划与财务预算合理性 | 三阶段排期 + 里程碑 + 甘特；分工到角色；预算 = Σ 单价 × 量（带来源）+ 机动金 5–10%；预算行与第 4 章动作、第 6 章 KPI 对账；企业承受能力说明；风险与应急（舆情 / 限流 / 版权 / 规则变化） | ≥ 20% 单价无来源；无风险应急；预算与动作对不上 | 预算一笔总数 → `budget_recalc` 失败封顶 2 分；超企业规模 → 写“占年营收 x%” |
| 方案创新性与价值 | 创意机制（话题 / 挑战 / UGC / 互动玩法）原句；与企业现状差异对照表；可持续价值（二次传播、内容与人群资产沉淀）；创意与洞察、平台机制一一对应 | 创意孤立，与企业现有做法差异不明 | 沿用企业现有玩法 → 第 2 章先列“企业已做 / 未做”；创意不可执行 → 预算表里能找到对应行 |

## 2. 预选赛短视频 4 项（40 分，方案中写“本片如何得分”一段）

| 官方项（10 分） | 国金表现 | 失分点 → 规避 |
|---|---|---|
| 内容契合度 | Big Idea 原句出镜；核心卖点 / 活动主旨与第 4 章一致；企业核心价值可被观众复述 | 视频与方案两张皮 → 分镜表每镜标注“对应策略节号” |
| 制作质量 | 三段式、1080p、音画同步、字幕齐全、无黑屏卡顿；≤ 3 分钟 ≤ 50 MB | 超时超大小 → 导出前核对；AI 全生成 → 细则禁止 |
| 平台适配与互动设计 | 竖版 9:16、前 3 秒钩子、评论区引导、话题 #全国高校商业精英挑战赛 #数字营销赛；三平台封面 / 标题 / CTA 分别适配；传播路径可行（发布 → 互动 → 搜索 → 进店） | 三平台同一条原样搬运 → 写“平台适配表”；未带话题 / 未公开 → 附录 A3 截图位 |
| 创新性与亮点 | 形式新（短剧 / 探店 / 直播切片 / 反转）、创意可一句话说清、与竞品视频主题不同 | 模仿爆款模板 → 候选创意对照表写明差异 |

## 3. 总决赛展示与答辩 8 项（40 分，每项 5 分）
- 内容完整程度：18–20 页覆盖 9 要素，留 1 页短视频页（细则第五节要求简单介绍短视频）。
- 评委提问应答 / 切题回应：题库 ≥ 40 题六维度，三段式（结论 / 证据 / 行动），单答 ≤ 60 秒；不知道就承认并给思路。
- 论述与决策确认清晰 / 结论正确有效：每页一结论句标题；数字与方案一致（`numbers.json`）。
- 演讲专业（含 PPT）：标题 ≥ 32 pt、正文 ≥ 24 pt、≤ 3 色、图表 ≥ 8、无整页文字。
- 谈吐与举止：不念稿、不贬低竞品、不争辩。
- 时间分配与团队配合：讲到 9:15–9:30；3–5 人各 ≥ 1 段；交接语 ≤ 5 字。

## 4. 硬门槛与格式红线（出现即扣分或取消资格）

| 红线 | 规则与出处 | 规避动作 |
|---|---|---|
| 院校信息 | 方案（含附件）、短视频、陈述中出现院校名称 / 图片 / LOGO，每处扣 3 分（附件 2 第 1 条） | `anonymityRegex` 零命中；图片 EXIF、PPT 母版、视频水印一并清理 |
| 页数 | 除封面目录外 ≤ 80 页，含附录（细则第六节（四）2） | 目标 55 页；附录 ≤ 12 页 |
| 封面 | 含作品名称、团队名称、指导企业名称；不得含人员姓名与联系方式（细则第六节（四）4） | `naming.json.coverFields` |
| 命名 | “学校名称-团队名称-作品名称-作品形式（短视频 / 数字营销方案）”（细则第六节（四）3） | 打包时占位“学校名称”，README 提醒 |
| 队名 / 作品名 | 不得含高校、机构、企业简称、LOGO；不得含敏感词、品牌恶搞（细则第四节（二）） | 标题范式“对仗主标题——品牌名数字营销方案” |
| 短视频 | MP4 ≤ 3 分钟 ≤ 50 MB，≥ 3 个平台公开发表并带两个指定话题（细则第六节（四）） | 附录 A3 列三平台链接 / 截图位 |
| 版权与授权 | 企业商标 / LOGO / 广告语 / 图片 / 视频须授权；非原创素材免版权并注明来源；提交企业授权书 + 免责声明（细则第四节） | 素材授权清单；授权书盖章 |
| 广告法与平台规则 | 不得虚假或引人误解；绝对化用语；平台发布规则；内容禁忌清单（细则第六节（一）7–8） | `checks.json.advertisingLawTerms` 零命中；合规自检表 |
| AI | 严禁抄袭 / 完全使用 AI 工具创作，一经发现取消资格（细则第六节（三）8） | 团队确认清单：示例数据替换、≥ 30% 段落重写、签字 |
| 超时 / 语言 | 陈述超时 1–5 分钟扣 1–3 分；非中文普通话扣 3 分 | 讲稿 1 650–1 950 字并掐表 |
| 数据真实 | “所用数据真实、准确，建议标明来源”（细则第六节（三）5） | 示例数据 100% 标注；数据真实性清单 |

## 5. 评委视角
企业评委先看第 4–5 章能否直接执行（平台矩阵、排期、单价、直播）再看 ROI 可信度；教师评委看第 2–3 章证据链与定位推导、引用规范；两类评委都会抽 10 个数字看前后一致——预算总额、KPI、样本量全书同一写法。
