# 01 赛道方法论：10 个框架与推理链

> 主线：企业诉求 → KGI / KPI → 数字资产盘点 → O-5A 与旅程触点 → 洞察与 Big Idea → 人群 × 场景 × 平台内容矩阵 → 投放与直播测算 → 看板与复盘 → 合规。示例用虚构“T 茶”，数字仅示意；来源 [D1]–[D13] 见文末。

## 1. KGI → KPI（第 1 章）
何时用：读题第一步。输入：企业目标原话、各项基线、预算与周期。输出：1 个 KGI + 3–5 个 KPI（曝光 / 互动 / 搜索 / 进店 / 转化 / 复购）各带基线 → 目标 → 口径。误用：只有曝光目标、无基线、与第 6 章口径不一致。示例：KGI = GMV 120 万 → 180 万元；KPI = 播放 1 500 万、互动率 ≥ 4%、搜索指数 +80%、GPM ≥ 600 元。

## 2. 数字资产盘点（第 2 章）
何时用：替代企业荣誉罗列。输入：各平台账号（粉丝、近 90 天发文、互动率、直播 GMV）、店铺（访客、转化率、客单、复购）、搜索指数、私域；来源 = 平台公开页 + 企业后台 + 第三方（蝉妈妈 / 新榜 / 飞瓜）。输出：盘点表（平台 / 粉丝 / 互动率 / GMV / 来源）+ 3–5 家竞品同口径对比 + 问题树 ≤ 3。误用：只列粉丝；跨平台口径混用。示例：抖音互动率 1.2% vs 竞品 3.5%。

## 3. O-5A 人群资产（第 3–4、6 章）
定义：O 机会人群 + A1 了解 / A2 吸引 / A3 种草 / A4 购买 / A5 复购；六大链路：拉新、蓄水、种草、直接转化、种草转化、复购 [D1]。复盘“三看”（总量 / 结构 / 流转率）“三比”（比历史 / 比头部 / 比行业）。输出：5A 表（层级 / 基线 / 目标 / 流转率 / 动作 / 预算），策略章每条动作标注链路。误用：把 5A 当人口画像；无巨量云图后台却写精确数字不标估算。示例：A3 8 万、A3→A4 四周转化 6%，目标 20 万 / 9%（平台口径约 50% 的 A3 四周内转 A4 [D7]）。

## 4. 用户旅程 × 触点（第 3 章 → 第 4 章矩阵）
输入：问卷媒介习惯题、访谈决策故事、平台数据。输出：旅程表（认知 / 兴趣 / 搜索 / 购买 / 分享 × 触点 × 内容需求 × KPI）+ 决策链漏斗。误用：无一手数据；触点全选。示例：62% 受访者在小红书搜、在抖音买 → 小红书卡搜索，抖音做转化。

## 5. 平台机制匹配（第 4 章）
抖音：完播 / 互动权重、看后搜、FACT+S（自播 / 达人矩阵 / 营销活动 / 头部大 V + 搜索 / 商城 / 店铺）[D5]，2024 升级 CORE [D6]；小红书：KFS（KOL / KOC 内容 + 信息流 + 搜索），蒲公英选达人、聚光投放、灵犀洞察 [D8]；视频号 + 小程序 = 私域会员。输出：平台 × 角色 × 机制 × 内容形态 × 频次 × KPI × 预算占比表；主平台 ≤ 4 并写明不选项。误用：全平台撒网、把平台名当策略、机制写错。示例：抖音 = 转化主场，小红书 = 搜索心智，视频号 = 老客复购。

## 6. 内容矩阵与脚本公式（第 4 章 + A2 + 短视频 40 分）
输出：内容宇宙（1 个 Big Idea → 3–4 系列 → 每系列 ≥ 3 选题）、内容日历（首 3 个月按周）、分镜表（镜号 / 时间 / 画面 / 台词 / 字幕 / 音效 / 素材授权 / 对应策略节）。脚本公式：0–3 秒钩子 → 3–30 秒场景与冲突 → 30–120 秒价值证明 → 120–160 秒品牌主张原句 → CTA。四项得分各落一处：契合度（主张出镜）、制作质量（1080p、三段式、字幕）、平台适配与互动（9:16、前 3 秒、评论引导、两个指定话题）、创新亮点（形式新、可一句说清）。误用：广告片思维；三平台原样搬运；素材未授权。示例：钩子“3 块钱的茶，为什么被 00 后抢着回购？”→ CTA“搜 T 茶口粮茶，评论区抽 100 份试饮”。

## 7. 投放测算：CPM / CPC / ROI（第 5–6 章，budget 模式）
公式：曝光 = 预算 ÷ CPM × 1000；点击 = 曝光 × CTR；CPE = 预算 ÷ 互动；进店 = 点击 × 进店率；订单 = 进店 × 转化率；GMV = 订单 × 客单；ROI = GMV ÷ 消耗。单价来源优先级：平台后台当期报价 > 官方刊例 / 帮助中心 [D3] > 第三方报告 [D4] > 建模估算（[D9] 建模值：抖音 CPM 约 45 元、小红书约 35 元，只作量级校验）。输出：预算明细（项目 / 单价 / 数量 / 单位 / 小计 / 来源）、机动金 5–10%、三阶段分配（预热 20–30% / 引爆 ≥ 50% / 长尾 10–20% [D2]）、A/B 测试（首周各 10%，按 CPE 再分配）、ROI 三情景 + tornado。误用：单价无来源；ROI 凑整；漏掉技术服务费与佣金。示例：20 万元 ÷ CPM 40 元 × 1000 = 500 万曝光 × CTR 2% × 进店 30% × 转化 4% = 1 200 单 × 68 元 = 8.16 万元，ROI 0.41（冷启期靠 A3 蓄水，第 3 个月按流转重算）。

## 8. 直播间运营（第 4 章）
输入：人货场——主播人设、品组（引流 / 福利 / 主推 / 利润款）、场景与节奏；承接达标线：平均停留 ≥ 30 秒、进场留存 ≥ 30% [D2]；复盘看 GPM / UV 价值。输出：排期表（周 × 场次 × 时长 × 主题 × 主推款 × 目标场观 / GPM）、脚本（每 15 分钟一轮：留人 → 讲品 → 逼单）、分工（主播 / 助播 / 中控 / 投手，不写姓名）。误用：只写“邀请头部主播”；无品组与节奏；不写付费与自然流量协同条件。示例：每周 3 场 × 2 小时，9.9 元试饮包引流、68 元口粮装主推；首月场观 3 000、GPM 400 元。

## 9. 数据看板、归因与复盘（第 6 章）
漏斗：曝光 → 播放 → 完播 → 互动 → 搜索 → 进店 → 转化 → 复购，每层基线与目标带来源。输出：KPI 表 ≥ 5 行（指标 / 基线 / 目标 / 测算依据 / 工具 / 周期）；监测链路表（埋点 → 看板 → 日 / 周 / 月复盘）；归因口径（最后点击 / 多触点 / 看后搜）；停投与换素材规则；短视频数据表标实际 / 模拟口径。误用：有漏斗无测算；模拟写成实际。示例：两周 CPE 高于基线 30% 即换素材。

## 10. 合规（第 4–5 章 + A3）
法规锚点：《广告法》第九条禁“国家级 / 最高级 / 最佳”、第十三条不贬低竞品、第十四条可识别、第三十八条代言、第四十条未成年人 [D10]；《互联网广告管理办法》第九条附购物链接的体验分享 / 测评须显著标“广告”、第十九条直播带货责任 [D11]；《互联网广告可识别性执法指南》[D12]；《网络主播行为规范》第十四条第 25–26 项禁数据造假与绝对化用语 [D13]。赛事：商标 / 素材须授权（授权书 + 免责声明）；全程匿名。输出：合规自检表、KOL 标“广告 / 合作”、口播禁用词、素材授权清单。示例：“最好喝”改为“比同规格均价低 23%（来源 [n]）”。
