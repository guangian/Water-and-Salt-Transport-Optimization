# 05 工作流与自检表（mice）

> 通用流程见 `agent/CLAUDE.md` Step 0–8；本文件只写会奖赛道「必须多做 / 必须不同」的动作。财务一律 `mode = budget`（`track.json.financeMode`）。

## 一、各阶段差异动作

| 阶段 | 角色 | 必须多做 / 必须不同 | 产出落点 |
|---|---|---|---|
| Step 0 读题 | 主代理 | 关键假设 ≥ 5 条必含：客户公司与人数（200–300 内取一个整数并说明）、目的地三选一依据、举办月份与气候窗、主出发城市分布、预算锚点（建议 260–340 万，留余量）；评分映射表把「突发事件预案」映射到「策划合理性」，「预计效果」映射到「排版可读性 / 一致性」 | `00_任务解析/任务解析.md` |
| Step 1 调研 | 研究员 A（目的地与行业） | 目的地文旅局官网、气象局当月历史均值、景区官网开闭园与承载量、高铁 / 航班班次票价（12306 / 航司）、当地会奖政策与奖补（肇庆补充通知的奖金与「展示洽谈会」要求） | `01_调研/01_宏观与行业.md` + CSV |
| | 研究员 B（参会人与客户） | 客户行业与企业事实、员工结构、上届年会资料、同业年会案例 ≥ 3 个（形式 / 人数 / 预算区间） | `02_消费者与渠道.md` |
| | 研究员 C（供应商与场地） | 候选酒店 ≥ 3 家（容量三口径 + 客房 + 协议价区间 + 访问日期）、地接大巴日租、AV 搭建 / 演出 / 伴手礼报价区间、保险产品费率区间；全部标来源 | `03_竞品与标杆.md` + `供应商报价.csv` |
| | 研究员 D（政策与合规） | 《大型群众性活动安全管理条例》适用边界、旅行社责任险要求、酒店消防核定人数、包车资质、食品留样规定；目的地近 3 年大型活动安全通报 | `04_对象企业与政策.md` |
| | 消费者洞察 | 参会人偏好问卷 ≥ 25 题（行程强度 / 饮食 / 房型 / 团建类型 / 伴手礼 / 自由活动偏好）；synthetic 模式示例结果全部带标记 | `05_消费者洞察.md`、`调研工具包/` |
| Step 2 策略 | 主代理 | 产出：KGI 一句 + KPI 表；目的地决策句；主题 3 选 1 对照表与主题一页；四天节奏草案（每日主题 + 核心环节）；亮点 3–5 条初稿；数字需求单含 `budget_total / budget_per_person / headcount / kpi_satisfaction / kpi_*` | `02_策略/策略框架.md` |

| Step 4 图表 | 制图员 | 按 `04_分析模型与图表库.md` 的 id 清单出图 ≥ 15，gantt 与 tornado 必有 | `04_图表/` |
| Step 5 撰写 | 主笔 | 第 5 章单独成批（页数最大）；每日流程表 8 列；每章落点：1 章→KGI；2 章→对应表指向行程；3 章→风险引第 6 章；4 章→贯穿矩阵引第 5 章；5 章→环节对应第 7 章预算行；6 章→预案对应机动金；7 章→付款排期对应行程；8 章→特色对应 KPI；9 章→结语回扣主题 | `05_正文/` |

## 二、财务 budget 模式特有表
预算明细（科目 / 项目 / 单位 / 单价 / 数量 / 小计 / 来源 / 对应环节）、分日预算、人均成本（含 / 不含机动金）、机动金、敏感性（人数 ±10% / 房价 ±15% / 机票 ±20%）、付款排期、KPI 表 ≥ 5 行、可选「赞助与资源置换抵减表」（不计入区间判断）。

## 三、提交前自检表（≤ 30 条，逐项勾选）
- [ ] 1 目录与 10 要素标题与细则一致，顺序不变（`outline.json`）
- [ ] 2 人数在 200–300 内且全文只有一个数；四天三夜无歧义（Day1 到达至 Day4 离开）
- [ ] 3 目的地三选一有评分表；补充通知（优先肇庆、宣传视频）已回应
- [ ] 4 客户画像含层级 / 年龄 / 出发城市 / 饮食分层
- [ ] 5 KGI 一句 + KPI ≥ 5 行带基线、目标、工具、周期
- [ ] 6 场地容量三口径（剧院式 / 圆桌 / 分会场）核查并给来源与访问日期
- [ ] 7 交通方案表到班次与票价；大巴数量 = 人数 ÷ 45 向上取整
- [ ] 8 举办月份的气候与节假日 / 档期冲突已核
- [ ] 9 主题双关联有推导句，四天贯穿矩阵存在
- [ ] 10 视觉系统为表格（色板 / 字体 / 元素 / 场景），物料清单带数量
- [ ] 11 每日流程表 30 分钟颗粒、8 列齐全、含转场与备选
- [ ] 12 每个环节对应 KPI 与预算行号
- [ ] 13 颁奖晚宴有分钟级脚本与座次原则
- [ ] 14 团建有分组规则、安全员配比、雨天替代
- [ ] 15 餐标表含特殊饮食配额与留样；住宿分配表房型 × 间数 = 人数
- [ ] 16 执行排期 gantt 覆盖 T-90 至 T+30
- [ ] 17 风险矩阵 ≥ 8 类，含触发指标 / 等级 / 时限 / 责任人
- [ ] 18 人群管理要点表（入场 / 转场 / 疏散）存在
- [ ] 19 保险（责任险 + 意外险）有条款与预算行；引用条例标 URL 与访问日期
- [ ] 20 预算 = Σ 单价 × 数量，Excel 与正文合计一致，可复算
- [ ] 21 总额（含机动金）在 200–400 万且不贴边；人均两种口径
- [ ] 22 每科目 ≥ 3 行有报价来源；含税费与服务费
- [ ] 23 敏感性三因子与付款排期存在
- [ ] 24 亮点 3–5 条，每条有预算行与 KPI
- [ ] 25 KPI 评估表 + 满意度问卷回收计划 + 四平台「#肇庆旅游」计划
- [ ] 26 结语 ≤ 150 字回扣开场数字与主题
- [ ] 27 匿名 0 命中（含页眉、PPT 母版、视频画面）；封面不含姓名与占位句，README 已提醒团队手工补填
- [ ] 28 禁语 / 广告法词 0 次；弱评价词 ≤ 0.1/百字
- [ ] 29 图表 ≥ 15、参考文献 ≥ 12、独立域名 ≥ 6、官方占比 ≥ 30%（`checks.json`）
- [ ] 30 PPT 18–22 页、讲稿 1 650–1 950 字、题库 ≥ 40 题；示例数据标记三处同步
