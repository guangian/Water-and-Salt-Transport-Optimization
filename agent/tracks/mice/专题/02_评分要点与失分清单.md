# 02 评分要点与失分清单（mice）

> 官方评分表：书面 60 分（6 项 × 10，标尺 差 1–2 / 中差 3–4 / 中等 5–6 / 好 7–8 / 极好 9–10）+ 演讲与问答 40 分（8 项 × 5）。出处：`docs/research/raw/sdssfw_1443_【山东省竞赛细则】…实施细则.pdf` 附件评分表；量规映射见 `agent/tracks/mice/rubric.json`（bandAnchors 60 / 75 / 85 / 92）。2026 国赛获奖规模：一等奖 72 队、二等奖 95 队、三等奖 54 队（https://www.ccpitcsc.org/eduxq/5093，访问 2026-10-25）——一等奖占获奖队约三分之一，想进冠亚季靠的是「可落地的证据密度」而不是「要素齐全」。

## 一、逐项对照

| 官方项（10 分） | 国金（9–10）长什么样 | 国银（7–8）差在哪 | 典型失分点 → 规避动作 |
|---|---|---|---|
| 内容原创性和结构完整性 | 10 要素标题与细则一字不差；客户画像有数（层级 / 年龄 / 出发城市）；主题原创且贯穿全部章节；封面字段齐 | 要素齐但画像泛泛；主题只在封面出现 | 缺「目录」或把「方案特色」并入「主题」→ 按 `outline.json` 文件名逐章落；复制细则原文当「方案目的」→ 改写为 KGI/KPI 句 |
| 策划的合理性和逻辑性 | 目的地评分表 + 场地容量核查（剧院式 / 圆桌分开）+ 交通方案表 + 季节与政策 + 供应商清单，报价有来源与访问日期 | 有可行性分析但容量 / 库存未核查；交通只写「高铁直达」 | 260 人宴会写 25 围、无 6% 税、Day1 到达即开大会 → 容量按「人数 ÷ 10 + 2 备用围」核算；交通表列到班次与票价 |
| 活动安排和方案目标的一致性 | 30 分钟颗粒日程 + 每环节对应 KPI + 分组与动线 + 雨天 / 延误备选 + 每环节预算行与责任人 | 日程齐全但与目标脱节；颗粒 > 30 分钟；无备选 | 推荐活动 8 项全塞进去但无主次 → 用「环节—目标对应表」删掉与 KGI 无关的环节；团建 3 小时无分组规则 → 写分组表 |
| 方案的新颖和创意性 | 主题双关联（企业文化 × 目的地文化）+ 视觉系统 + 亮点 3–5 个可一句复述 + 与常规方案对照 + 亮点有预算行 | 有主题但未贯穿；亮点是形容词 | 「沉浸式」「科技感」无实物 → 每个亮点写「做什么 / 在哪个时段 / 花多少 / 对应哪个 KPI」 |
| 方案排版设计与可读性 | 每页 ≥ 1 图表；图题图下表题表上；配色 ≤ 3；日程表横向可读；附录有供应商清单与问卷 | 整页文字；表格跨页断裂；图无来源 | 日程表 12 列挤成 7 号字 → 拆「总览表 + 每日表」；地图 / 动线用示意表而非截图 |
| 策划与实施相关财务预算的合理性 | 单价 × 数量 + 来源 + 人均 + 机动金 5–10% + 总额在 200–400 万 + 敏感性 + 付款排期 + 与日程逐项对账 | 有明细无来源；总额贴着上限；无敏感性 | 合计不可复算（Excel 与正文不一致）→ 以 `03_财务/numbers.json` 为唯一口径；人均 > 1.6 万却无解释 → 重排科目 |

## 二、演讲与问答 40 分（8 × 5）的得分动作
内容完整程度（10 要素在 PPT 目录页可见）/ 问题识别（开场 60 秒说清客户痛点与 KGI）/ 论述与决策确认清晰（每页标题是结论句）/ 结论正确有效（数字与 PDF 一致）/ 切题回应（三段式：结论—证据—行动，≤ 45 秒）/ 演讲专业程度含 PPT（图表 ≥ 8、字号 ≥ 24 pt）/ 发声与非语言（站位、不念稿）/ 时间分配与配合（10 分钟 ±15 秒，每人 ≥ 1 段）。细节见 `06_路演与答辩题库.md`。

## 三、硬门槛（任一不过，规范类维度 ≤ 2）
| 门槛 | 规则与出处 | 规避动作 |
|---|---|---|
| 预算区间 | 总额 ∉ [200 万, 400 万] 直接失败（细则六（一）4；`checks.json.requiredEvidence.budget_in_range`） | 机动金计入总额后再比区间；留 ≥ 3% 余量，不贴边 |
| 匿名 | 不得以任何形式透露院校名称、logo、参赛人员联系方式（细则七（二））；品牌 / 文旅类细则院校信息扣 3–5 分 | `checks.json.anonymityRegex` 扫全部产出，含页眉、PPT 母版、视频画面、文件属性 |
| 封面字段 | 细则七（一）要求封面含团队名称、参赛者姓名、指导教师姓名、指导企业；`naming.json.coverFields` 另含作品名、客户公司名 | 姓名字段一律用占位 `【提交前由团队填写：参赛者姓名 / 指导教师姓名】`，正文页眉页脚与 PPT 不出现姓名；README 提醒 |
| 页数 | `checks.json.pageLimit = 80`，目标 50 页 ±10%（`track.json.pageTargetDefault`） | 日程与预算明细超长时移附录 |
| 跨文档一致 | numbers.json / 正文 / PPT / 讲稿同一 key 同一数值（`rubric.hardGates.cross_doc_consistency`） | 人数、总预算、人均、满意度目标四个数全文只写一种写法 |
| 禁语与广告法 | `checks.json.forbiddenTerms / advertisingLawTerms`：「顶级」「独一无二」「唯一」「100%」等 0 次 | 酒店描述用「五星级标准 / 客房 252 间」替代形容词 |
| 查重 / 原创 | 近三届（2023–2025）已递交并获奖的方案不得重复参赛（细则七（七）） | README 写明；主题与客户组合避开本校旧题 |

## 四、格式与交付红线
- 文件：策划方案 PDF（A4 竖版）；命名「院校名称-团队名称-队长姓名-组别」（细则七（四），打包用占位）；宣传视频命名「…-宣传视频」。
- 展示视频 10 分钟 MP4，开头全员出镜、PPT 画面清晰；宣传视频 1–3 分钟，四平台均带「#肇庆旅游」话题（细则七（五））——目的地选南充 / 洛阳的团队同样要交肇庆宣传视频，正文第 9 章传播计划必须覆盖。
- 引用须标出处与页码（细则六（三）3）；图片图表辅助说明（六（三）4）→ 每章 ≥ 1 图 1 表、图下写资料来源。
- 日程：2026 届国赛公告显示总决赛实际于 5 月 22–24 日举行（与 2025-09 通知的 5 月 30–31 日不同），以组委会最新通知为准。

## 五、合规底线（第 6 章必须引用，给评委「懂行」的信号）
- 《大型群众性活动安全管理条例》（国务院令第 505 号，2007-10-01 施行）：适用于面向社会公众、每场次 1 000 人以上的活动；200–300 人的公司内部年会不在许可范围，但其第六条「安全工作方案九项内容」（人数核定 / 消防 / 票证查验 / 车辆疏导 / 秩序维护 / 应急救援预案等）是预案章的权威模板。https://www.gov.cn/zhengce/content/2008-03/28/content_6196.htm（访问 2026-10-25）。
- 保险：指导企业（旅行社）依法投保旅行社责任险；为参会人投保旅游意外险并在预算列行；酒店宴会厅按消防核定人数布置、保留疏散通道宽度。
- 包车：查验道路运输证、驾驶员从业资格、包车标志牌；夜间长途与凌晨时段不安排大巴转场。
- 食品：宴会留样 48 小时、过敏原与清真 / 素食配额写进餐标表。
