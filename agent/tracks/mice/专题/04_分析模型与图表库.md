# 04 分析模型与图表库（mice）

> 图型以 `docs/contracts.md` §7.1 允许的 `type` 为准：bar / grouped_bar / stacked_bar / hbar / line / area / pie_as_bar / donut / waterfall / funnel / tornado / breakeven / cashflow_combo / scatter_matrix / positioning_map / gantt / radar / bmc；data 字段见 `agent/.claude/skills/biz-charts/SKILL.md` §1。全书图表 ≥ 15（`checks.json.chartMin`），每章 ≥ 1 图 1 表；三个数以内写进句子不画图；`donut` ≤ 4 类。每图 `source` 必填，图后两句读图。

## 一、每章推荐（模型 → 图型 → 数据字段 → 读图句模板）

| 章 | 模型 | 图型 id 建议 | data 字段要求 | 读图句模板 |
|---|---|---|---|---|
| 1 客户介绍 | 参会人群画像 | `fig_attendee_mix`：stacked_bar（部门 × 年龄段）或 hbar（出发城市） | categories = 部门 / 城市；series = 年龄段人数，合计 = headcount | 「260 人中销售 143 人占 55%，25–35 岁 177 人占 68% → 团建强度按青年为主设计」 |
| 1 客户介绍 | KGI/KPI 基线 | `fig_kpi_baseline`：grouped_bar（基线 vs 目标） | categories = KPI；series = [基线, 目标]，单位统一 | 「满意度基线 4.1 → 目标 4.5，缺口 0.4 分由晚宴与团建两环节承担」 |
| 2 方案目的 | 目标树 | 表（目标树）+ `fig_goal_map`：radar（4 目标 × 权重） | axes ≥ 3；series = 本方案 | 「表彰与共识两项权重合计 60%，日程 Day2 全天为其服务」 |
| 3 可行性 | 目的地五维评分 | `fig_destination_score`：radar（3 城市） | axes = 交通 / 场地 / 气候 / 政策 / 成本；series ≤ 3 | 「肇庆综合 4.2 分领先南充 0.5 分，差距来自广深出发 1.5 小时高铁可达」 |
| 3 可行性 | 交通成本比较 | `fig_transport_cost`：grouped_bar（方式 × 城市） | categories = 出发城市；series = 高铁 / 航班 / 大巴 人均票价 | 「广州出发高铁人均 65 元仅为航班 1/6 → 主交通定高铁」 |
| 3 可行性 | 场地容量核查 | 表（场地清单）+ `fig_venue_capacity`：hbar（候选场地剧院式容量，highlight 选定） | categories = 场地；values = 容量；标注需求线 260 | 「仅 2 家宴会厅 ≥ 27 围，其中 A 酒店同时满足 252 间客房 → 一站式驻地」 |
| 4 主题 | 候选主题评分 | 表（3 选 1）+ `fig_theme_score`：radar | axes = 文化契合 / 可视化 / 可延展 / 记忆度 | 「主题 A 四维均 ≥ 4，另两案在可延展维度 ≤ 3」 |
| 5 行程 | 执行排期 | `fig_gantt_execution`：gantt（T-90 天至 T+30 天） | tasks[{name,start,end,group}]，group = 筹备 / 招采 / 物料 / 执行 / 评估；milestones = 签约 / 彩排 / 开幕 / 复盘 | 「签约到开幕 60 天，物料与演出招采并行 20 天，彩排在 T-1 日」 |
| 5 行程 | 四天节奏 | `fig_daily_intensity`：line（4 天 × 活动强度 / 时长） | categories = Day1–4；series = 会议时长 / 活动时长 / 自由时长（小时） | 「Day2 会议 6 小时为峰值，Day3 自由时长 3 小时用于恢复」 |
| 5 行程 | 分日人员流动 | `fig_crowd_flow`：stacked_bar（时段 × 场地人数） | categories = 时段；series = 场地 | 「11:30 转场峰值 260 人集中于两部电梯 → 分两梯队错峰 15 分钟」 |
| 6 预案 | 风险矩阵 | `fig_risk_matrix`：scatter_matrix（概率 × 影响） | points[{name,x,y,size}]，quadrants = 四象限文字 | 「暴雨与交通延误落在高概率高影响象限，各配 Ⅰ 级预案与 8 万元机动金」 |
| 7 预算 | 预算结构 | `fig_budget_structure`：pie_as_bar（9 科目） | categories = 科目；values = 金额（万元），合计 = budget_total | 「交通 + 住宿 + 餐饮合计 61%，与行业经验区间一致」 |
| 7 预算 | 预算桥 | `fig_budget_bridge`：waterfall（基础 → 各加项 → 机动金 → 总额） | items[{name,value,total?}] | 「基础 268 万 + 机动 8% = 289.4 万，距上限留 110 万余量」 |
| 7 预算 | 分日预算 | `fig_budget_by_day`：bar | categories = Day1–4 + 行前；values | 「Day2 支出 96 万占 33%，因大会 + 颁奖晚宴同日」 |
| 7 预算 | 敏感性 | `fig_tornado_budget`：tornado | base = budget_total；items = 人数 ±10% / 房价 ±15% / 机票 ±20% | 「人数 +10% 使总额升至 318 万仍在区间；机票 +20% 影响 9 万」 |
| 7 预算 | 付款排期 | `fig_payment_schedule`：cashflow_combo（月度支付 + 累计） | categories = 月份；values = 支付额；cumulative | 「行前 30 天累计支付 80%，与供应商条款一致」 |
| 8 特色 | 特色 vs 常规 | 表（对照）+ `fig_feature_compare`：grouped_bar（特色项 × KPI 贡献） | categories = 特色；series = 贡献 KPI 数 / 预算占比 | 「3 个特色合计预算 9%，覆盖 4 项 KPI」 |
| 9 效果 | 传播漏斗 | `fig_promo_funnel`：funnel | stages = 曝光 / 播放完成 / 互动 / 话题参与 / 内部转发 | 「四平台目标曝光 30 万，按 3% 互动率得 9 000 次互动」 |
| 9 效果 | KPI 达成 | `fig_kpi_target`：grouped_bar（基线 / 目标 / 行业基准） | 同第 1 章 KPI，口径一致 | 「满意度目标 4.5 高于行业会奖均值 4.3（来源 [n]）」 |

## 二、表格元件（渲染为表，不画图）
- 场地清单表：名称 / 区域 / 会议厅面积 / 剧院式 / 圆桌围数 / 客房数 / 协议价区间 / 来源 / 访问日期。
- 交通方案表：出发城市 / 人数 / 方式 / 班次 / 时长 / 票价 / 接驳 / 备选。
- 每日流程表（8 列）：时间 / 环节 / 地点 / 分组与动线 / 负责人角色 / 物料 / 对应 KPI / 备选。
- 餐标与住宿分配表：日 / 餐次 / 形式 / 人均标准 / 围数或份数 / 特殊饮食配额；房型 / 间数 / 人数 / 楼层 / 价格。
- 预算明细表：科目 / 项目 / 单位 / 单价 / 数量 / 小计 / 报价来源 [文献号] / 对应环节。
- 风险矩阵：类别 / 触发指标 / 等级 / 响应时限 / 责任人 / 处置步骤 / 资源 / 保险。
- 人群管理要点表：环节 / 峰值人数 / 通道数 / 通过率（人/分钟，标注假设）/ 用时 / 责任人。
- KPI 评估表：指标 / 基线 / 目标 / 工具 / 周期 / 责任人。

## 三、数据来源与口径规则
- 票价、房价、场地租金写「区间 + 来源 + 访问日期」（如「协议价 650–750 元/间夜，酒店会议页，2026-03-10 访问」）；OTA 与第三方聚合页只能作区间参考，正文标注须经官网 / 电话核实。
- 预算图的数值全部来自 `03_财务/numbers.json`（`budget_total`、`budget_per_person`、`headcount`、`kpi_*`）；图内不出现与正文不同的四舍五入。
- 示例调研（偏好问卷）产生的图在 `source` 写「示例调研数据，须替换」，并在图后段落带【示例数据，须替换为真实调研结果】标记。
- 不要为了「好看」画 donut 表示 9 个科目（自动转 pie_as_bar）；> 8 类一律横向条形。
