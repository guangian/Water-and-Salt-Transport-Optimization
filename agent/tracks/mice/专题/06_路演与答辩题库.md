# 06 路演与答辩题库（mice）

> 国赛：团队陈述 10 分钟 + 评委问答 5 分钟（细则五（四））；演讲与问答 40 分 = 8 项 × 5。PPT 正文 18–22 页、备用页 ≤ 4、讲稿 1 650–1 950 字、题库 ≥ 40 题六维度（`checks.json.pitch`）。版式名取自 `docs/contracts.md` §7.3；`chart` 版式只支持柱 / 条 / 堆叠 / 折线 / 饼环原生图，radar / gantt / tornado / funnel 等用 `image` 版式贴 `04_图表/` 的 PNG。

## 二、评委最常问的 20 题与应答要点（三段式：结论 10 秒 / 证据 30 秒 / 行动 10 秒；单答 ≤ 60 秒 / 150 字）

| # | 维度 | 问题 | 应答要点（主答角色） |
|---|---|---|---|
| 1 | 客户与目标 | 为什么选这家客户？你们真的接触过吗 | 指导企业资源 + 公开资料口径；synthetic 调研如实说明替换计划（总策划） |
| 2 | 客户与目标 | 年会 KGI 怎么衡量？老板凭什么掏 300 万 | 一句 KGI + 两项 KPI 基线→目标；对比上届年会（总策划） |
| 3 | 客户与目标 | 参会人里有 50 岁以上高管，团建强度怎么办 | 画像分层 + 分组规则 + 替代路线（活动策划） |
| 4 | 目的地与可行性 | 为什么不选另外两座城 | 五维评分表分差来源（交通 / 场地）；承认对方优势（总策划） |
| 5 | 目的地与可行性 | 宴会厅 300 人到底坐不坐得下 | 圆桌围数 × 面积口径 + 官网来源 + 备选厅（地接） |
| 6 | 目的地与可行性 | 举办月份是雨季 / 旺季怎么办 | 气候均值 + 档期核查 + 室内版 Day3（活动执行） |
| 7 | 目的地与可行性 | 高铁票 260 张抢不到怎么办 | 团体票 / 分两班次 / 大巴备选与成本差（地接） |
| 8 | 行程与创意 | 主题和企业文化的关系是不是硬凑 | 推导句 + 贯穿矩阵四天实例（活动策划） |
| 9 | 行程与创意 | 哪个环节最可能被砍？砍掉影响什么 | 环节—KPI 对应表；给出「可砍清单」与节省额（总策划） |
| 10 | 行程与创意 | 转场 260 人用多久？怎么防掉队 | 分梯队 + 通道通过率假设 + 领队配比（活动执行） |
| 11 | 行程与创意 | 颁奖晚宴流程多长？高管讲话超时怎么办 | 分钟脚本 + 主持人提示卡 + 弹性 15 分钟（活动策划） |
| 12 | 预算与供应商 | 人均 1.2 万贵不贵 | 结构拆解 + 同类年会区间 + 可降项（财务） |
| 13 | 预算与供应商 | 报价哪来的？签过合同吗 | 来源表（官网 / 协议价区间 / 指导企业历史价）+ 待核实项（财务） |
| 14 | 预算与供应商 | 机动金 8% 怎么用、剩了归谁 | 触发规则（风险矩阵对应）+ 结算返还条款（财务） |
| 15 | 预算与供应商 | 人数变成 230 人，总额怎么变 | 敏感性表数值 + 固定 / 变动成本比例（财务） |
| 16 | 预算与供应商 | 税费和服务费算了吗 | 6% 增值税 + 酒店服务费口径 + 行项位置（财务） |
| 17 | 执行与应急 | 暴雨橙色预警当天怎么办 | 触发指标 → Ⅰ 级 → 室内版流程 → 通知链（活动执行） |
| 18 | 执行与应急 | 有人食物中毒 / 走失 / 舆情，第一小时做什么 | 分级时限 + 责任人 + 医院 / 保险联络（活动执行） |
| 19 | 效果与传播 | 满意度怎么测？回收率低怎么办 | 会后 48 小时问卷 + 激励 + 现场扫码（总策划） |
| 20 | 效果与传播 | 宣传视频发了四平台，数据目标是什么 | 漏斗数值 + 发布时间 + 二次传播机制（活动策划） |

尖锐题（题库必含 ≥ 8）：示例数据如何替换为真实调研；最大短板是什么；指导企业给了什么实际资源；预算若上限压到 250 万砍什么；目的地改为肇庆（若原选他城）方案改动多大；AI 工具使用边界；同校是否用过同一客户；若客户临时加 30 人怎么办。

## 三、现场动作
- 开场 20 秒不自我介绍，直接讲场景；结尾回扣开场数字。
- 评委提问先复述一句确认（≤ 10 字），再三段式作答；超出材料范围的问题承认边界并给核实计划。
- 数字口径只说 numbers.json 的值；两位以上讲者不得给出不同数字。
- 计时员在 9:00 举牌；10 分钟 ±15 秒内结束。
