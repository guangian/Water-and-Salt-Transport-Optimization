# 01 赛道方法论（商务会奖旅游策划 · mice）

> 命题事实（出处：`docs/research/raw/sdssfw_1443_【山东省竞赛细则】2026年全国高校商业精英挑战赛商务会奖旅游策划竞赛实施细则.pdf` 六（一）；补充通知 2026-02-24）：为自选客户公司在 **肇庆 / 南充 / 洛阳** 三选一办公司年会，**200–300 人、四天三夜、预算 200–400 万元**；团队须联系一家会奖公司做指导企业；省赛另交 1–3 分钟「#肇庆旅游」宣传视频。评委是会奖公司 / 酒店 / 文旅从业者为主，看的是「这单生意能不能按方案落地」。

## 0. 总推理链（每一环都要在正文留下可定位的表）
客户事实（行业 / 人数 / 文化 / 年会传统）→ 年会目标 KGI（1 个）与 KPI（≥ 5 行）→ 目的地与场地可行性（容量 / 交通 / 季节 / 政策 / 成本）→ 主题 Big Idea（企业文化 × 目的地文化）→ 四天三夜日程（30 分钟颗粒）→ 每个环节的预算行 → 风险与预案 → KPI 评估与传播。任何一环没有数字支撑，后一环都会被评委判为「拍脑袋」。

## 1. 客户画像与 KGI/KPI 树（第 1–2 章）
- 何时用：读题后第一步；决定全案基调。
- 输入：客户年报 / 官网 / 招聘页（员工结构、年龄中位数、分支机构分布）、上届年会资料（任务书或假设）、参会人偏好问卷（synthetic 时标注示例数据）。
- 输出：画像表（层级 / 年龄段 / 出发城市 / 饮食禁忌 / 体力分层），KGI 一句（如「年会后 30 天销售团队留任率 ≥ 95%」），KPI 表（指标 / 基线 / 目标 / 工具 / 周期）。
- 常见误用：把「增强凝聚力」当 KPI；画像没有出发城市分布，导致第 3 章交通方案无法算票价。
- 示例：某新能源车企华南区 260 人（销售 55%、技术 30%、职能 15%；25–35 岁占 68%；70% 从广州 / 深圳出发）→ KGI「年度表彰 + 次年目标共识」，KPI：满意度 ≥ 4.5/5、表彰仪式到场率 100%、研讨产出 ≥ 12 条可落地提案、内部传播曝光 ≥ 3 万。

## 2. 目的地—场地可行性五维评分（第 3 章）
- 何时用：三选一决策与场地锁定。
- 输入：高铁 / 航班班次与价位（12306、航司官网）、酒店会议厅面积与剧院式 / 圆桌容量（官网或 OTA 会议页，标访问日期）、当月气候（气象局历史均值）、节假日与大型赛事档期、人均成本。
- 输出：目的地评分表（交通可达 25% / 场地库存 25% / 气候季节 15% / 政策安全 15% / 成本 20%，各 1–5 分）；场地清单表（名称 / 会议厅面积 / 剧院式容量 / 圆桌数 / 客房数 / 报价区间 / 来源 / 访问日期）；交通方案表（出发城市 → 目的地：方式 / 时长 / 票价 / 班次 / 大巴接驳）。
- 常见误用：只写「酒店设施完善」；容量用「可容纳 300 人」却不区分剧院式与宴会圆桌（宴会 300 人 = 30 围 ≈ 需 ≥ 500 ㎡）。
- 示例（肇庆，第三方页面数据，写作时必须以官网 / 电话重新核实并标日期）：市区某星湖畔酒店综合会议厅 488 ㎡、剧院式 350 人 / 圆桌 25 围、客房 252 间（https://www.cncn.com/xianlu/748885468706，访问 2026-10-25）；七星岩某国际品牌酒店拥有 3 000 ㎡ 无柱会议中心与 2 500 ㎡ 国宴厅（http://wyndhamgrandzqdt.com/Content/1987759.html，访问 2026-10-25）。结论句写法：「260 人颁奖晚宴需 ≥ 27 围，候选 A 厅 25 围不达标 → 选 B 厅并保留 A 厅作研讨分会场」。

## 3. 主题双关联与贯穿矩阵（第 4 章）
- 何时用：可行性确定后、日程之前。
- 输入：客户文化关键词（价值观 / 年度口号）、目的地文化符号（肇庆：端砚 / 七星岩 / 包公文化；南充：丝绸 / 三国 / 嘉陵江；洛阳：牡丹 / 龙门 / 河洛）。
- 输出：候选主题 3 选 1 对照表（文化契合 / 可视化 / 可延展 / 记忆度 各 1–5）、主题一页（主张 / 视觉锤 / 语言钉 / 推导句）、贯穿矩阵（四天 × 子主题 × 环节 × 物料）。
- 常见误用：主题只出现在封面与晚宴背板；用目的地地名硬拼企业口号。
- 示例：车企「破局·向上」× 肇庆「砚」→ 主题「研磨成器」：Day1「入砚」签到墨迹签名墙、Day2「研」工作大会与研讨、Day3「磨」鼎湖山徒步团建、Day4「成器」颁奖端砚纪念章。

## 4. 日程网格与「环节—目标—预算—责任人」四连表（第 5 章）
- 何时用：全书篇幅最大的章（10–12 页），所有评分项在此交汇。
- 输入：第 2 章 KPI、第 3 章交通到达时刻、场地档期、日落 / 气温、景区开闭园时间与承载量。
- 输出：总日程表（4 天 × 时段）、每日 30 分钟颗粒流程表（时间 / 环节 / 地点 / 分组与动线 / 负责人角色 / 物料 / 备选）、环节—目标对应表、座次与动线说明（文字 + 表）、餐标与房间分配表。
- 常见误用：到达日下午安排大会（旅途疲劳）；晚宴后 22:30 还排团建；没有雨天备选；分组人数不除尽（260 人 ÷ 8 组 = 32.5）。
- 示例：Day2 08:30–08:50 分组签到（5 通道 × 52 人，≤ 12 分钟）→ 09:00–11:30 工作总结大会（剧院式）→ 11:30–11:45 转场宴会厅（两梯队错峰）→ 14:00–17:00 研讨会（6 个圆桌分会场各 45 人）。

## 5. 预算三层法：科目 × 单价 × 数量 + 来源（第 7 章，budget 模式）
- 何时用：日程表定稿后立即对账。
- 输入：每个环节的物料 / 人力 / 场地需求；供应商报价区间（酒店会议页、OTA 协议价、航司票价、地接大巴日租、演出 / AV 搭建公司刊例）。
- 输出：预算明细（科目 / 项目 / 单位 / 单价 / 数量 / 小计 / 报价来源 / 文献号）、预算结构图、分日预算、人均成本、机动金 5–10%、敏感性（人数 ±10%、房价 ±15%、机票 ±20%）、付款排期。
- 常见误用：总额恰好 400 万；只有九大科目没有行项；酒店按「间夜」却按人数计；忘记 6% 增值税与服务费；没有机动金就称「收支平衡」。
- 经验区间（仅供自检，正文必须用报价替换）：交通 15–25%、住宿 18–25%、餐饮 15–22%、场地与搭建 10–15%、活动演出与团建 8–12%、物料礼品 5–8%、地接人力 3–5%、保险与税费 2–4%、机动 5–10%。260 人 × 300 万 → 人均 1.15 万元，评委会立刻心算这个数。
- 收支平衡口径：年会由客户全额出资，不写「盈利」；可选的赞助 / 资源置换（目的地文旅局宣传资源、客户供应商冠名）单列为「收入抵减」表，不得冲抵硬门槛区间。

## 6. 风险矩阵与分级响应（第 6 章）
- 何时用：日程与预算定稿后逐节点扫描。
- 输入：日程节点、气象、交通、食品、医疗、舆情、人员、设备、公共事件；法规底线见 `02_评分要点与失分清单.md` §合规。
- 输出：风险矩阵 ≥ 8 类（概率 / 影响 / 触发指标 / 分级 / 响应时限 / 责任人 / 预案 / 保险条款）、应急组织表、演练安排、与机动金的对应。
- 常见误用：只写「及时处理」；没有触发阈值（如「气象台发布暴雨橙色预警即启动室内版 Day3」）。

## 7. KPI 评估与传播漏斗（第 9 章 + 宣传视频）
- 输入：第 2 章 KPI 基线；四平台（抖音 / 小红书 / 视频号 / B 站）账号现状。
- 输出：KPI 评估表（指标 / 基线 / 目标 / 方法 / 周期 / 责任人）、满意度问卷（会后 48 小时内）、传播漏斗（曝光 → 互动 → 话题参与 → 内部二次传播）、「#肇庆旅游」发布计划（平台 / 时长 / 发布时间 / 目标播放）。
- 常见误用：ROI 写成营收倍数；传播目标无基线。
