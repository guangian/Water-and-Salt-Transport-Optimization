## 二、各章「国金写法」要点

1. **客户公司介绍**：写事实不写赞美（企业荣誉 ≤ 5% 篇幅，`agent/CLAUDE.md` §2.2）。必须出现「出发城市分布」与「体力 / 饮食分层」，否则第 3、5 章的交通与分组没有依据。KGI 一个、KPI ≥ 5 行并带基线。
2. **方案目的**：目标树 + 对应表，每个推荐活动（欢迎晚宴 / 总结大会 / 研讨 / 颁奖晚宴 / 酒会 / 景点 / 购物 / 团建）要么对应一个 KPI，要么被删。
3. **可行性**：五维表「维度 / 证据（数值 + 来源 + 访问日期）/ 风险 / 结论」。场地容量核查给三行：大会剧院式、晚宴圆桌、研讨分会场；交通方案给主出发城市的高铁 / 航班班次与票价、接驳大巴数量（按 53 座 × 85% 上座 = 45 人/车，260 人需 6 辆）。
4. **主题**：主题一页之后立刻给「贯穿矩阵」；视觉系统用表（主色 / 辅色 / 字体 / 图形元素 / 应用场景），不画 LOGO；物料清单带数量与单价引用第 7 章行号。
5. **行程**：每日流程表固定 8 列（时间 / 环节 / 地点 / 分组与动线 / 负责人角色 / 物料 / 对应 KPI / 备选）；每天一句「节奏说明」（张 / 弛）；颁奖晚宴单独给流程脚本（分钟级）与座次原则；团建给分组规则、安全员配比（1:25）、雨天替代。
6. **预案**：矩阵列：类别 / 触发指标 / 等级（Ⅰ–Ⅲ）/ 响应时限 / 第一责任人 / 处置步骤 / 资源与预算 / 保险条款。引用《大型群众性活动安全管理条例》第六条九项作框架（见 `02_评分要点与失分清单.md` §五）。
7. **预算**：先放关键数字卡，再放结构图与明细；每个科目至少 3 行可追溯报价；人均成本写两种口径（含 / 不含机动金）；敏感性表给三因子；付款排期（签约 30% / 行前 30 天 50% / 结算 20%，示例比例须与供应商条款核对）。
8. **特色**：每条特色写「做什么 → 对应 KPI → 预算行号 → 为什么常规方案做不到」。
9. **预计效果**：KPI 评估表（指标 / 基线 / 目标 / 工具 / 周期 / 责任人）、满意度问卷回收计划、传播漏斗图、四平台发布计划表；结语 ≤ 150 字回扣开场与主题。

## 三、页数分配校准（`agent/CLAUDE.md` Step 0 页数模型）
每章先扣 0.5 页标题空白，再扣图 0.45 页/张、表 0.15 页/张 + 0.06 页/行，余量 × 600 字。第 5 章 11 页若放 6 张表（合计 60 行）+ 2 图 → 表占 4.5 页、图 0.9 页，文字约 3 000 字；因此第 5 章表格行数必须在页数预算表里写死，超出移附录。

## 四、与「人群管理方案」赛的互借
姊妹赛要求实施方案涵盖检票、入场、人流、物流、车流、疏散（细则五（三）），并以数据支持论点。会奖方案把这六项浓缩为第 6 章的一张「人群管理要点表」（环节 / 峰值人数 / 通道数与通过率 / 时长 / 责任人），评委会视为专业度加分；通过率可用「每通道每分钟 8–10 人」的经验值并标注为假设。
