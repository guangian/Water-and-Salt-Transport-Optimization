# 商务会奖旅游策划赛道 · 赛道规范（mice）

> 适用：全国高校商业精英挑战赛 商务会奖旅游策划竞赛（本科组含研究生 / 高职组）。2026 命题：联系一家商务会奖旅游公司作为指导企业，为自选客户公司设计在 **肇庆 / 南充 / 洛阳（三选一）** 举办公司年会的会奖旅游方案；团队规模 200–300 人；四天三夜；**预算 200 万–400 万元**；客户行业不限。

## 0. 硬约束

| 项 | 要求 |

| 推荐活动 | 欢迎晚宴、颁奖晚宴、工作总结大会、学习研讨会、社交酒会、景点参观、购物娱乐、团队建设 |

| 匿名 | 全文不得出现院校信息 |

## 2. 写作要点
- 目的地信息（场地容量、酒店、景区、交通）必须来自可核实来源（官网 / OTA / 政府文旅网站），标注日期。
- 预算区间硬约束：总额 ∉ [200, 400] 万元即硬门槛失败。
- 日程要可执行：时间颗粒度 30 分钟，含转场与备选。
- 选择肇庆有额外奖金激励（细则），可在可行性分析中提及但不作为唯一依据。

## 3. 交付清单
会奖策划方案 docx + pdf；预算 Excel（budget 模式，含人均成本）；路演 PPT；讲稿；题库；宣传视频脚本；调研问卷；评审报告；提交包。

- 目的地三选一，组委会鼓励优先肇庆；无论选哪座城，省赛 / 预选赛都要提交「#肇庆旅游」宣传视频，第 9 章传播计划必须覆盖。
- 细则七（一）要求封面含团队名称、参赛者姓名、指导教师姓名、指导企业；系统生成的封面只含 `naming.json.coverFields`（作品名称 / 团队名称 / 指导企业名称 / 客户公司名称），不生成任何姓名或占位句（本赛道 `checks.json.anonymityRegex` 含「指导教师」且无占位白名单），参赛者与指导教师姓名由团队提交前手工补填，打包 README 提醒；正文、页眉页脚、PPT、讲稿不出现任何姓名；院校名称、logo、联系方式全文禁止。
- 近三届（2023–2025）已递交并获奖的方案不得重复参赛；引用须标出处与页码。
