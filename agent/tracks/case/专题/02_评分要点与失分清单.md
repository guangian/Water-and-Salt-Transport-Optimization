## 1. 逐项：国金长什么样 / 国银差在哪 / 失分点与规避
| 官方项 | 国金作品 | 国银差距 | 典型失分 → 规避动作 |

| 内容完整程度 | 12 要素一级标题与细则原文一字不差，目录可跳转，附录有年报页码索引 | 名称改写（“战略分析”代替“策略分析”）让评委找不到 | 缺“知识点列表”或“治理回顾” → 用 `checks.json.requiredElements` 自查，别名只做副标题 |

## 2. 硬门槛与格式红线（任一失守先于内容扣分）
1. 页数：除封面目录外 ≤ 50 页含附录（`track.json.pageLimit`）；目标 42 页（`pageTargetDefault`）。retail 变体 ≥ 3000 字、PPT ≥ 20 页。
2. 字体行距：正文宋体小四、英文 Times New Roman、单倍行距、页码清楚；PDF A4 竖版。
3. **封面与匿名（本赛道例外）**：细则要求封面写团队名称、组别、参赛选手姓名、指导教师姓名，但不得出现电话 / 邮箱，全文不得出现院校名称、logo、标语。本系统**不生成真实姓名**，封面用占位 `【提交前由团队填写：选手姓名】` `【提交前由团队填写：指导教师姓名】`（`checks.json.coverFieldsByVariant.accounting`，已列入 `anonymityWhitelist`），由团队提交前手工填入；文件命名规则 `{学校名称}-{团队名称}-{作品名称}` 只用于文件名，正文与封面仍不得出现院校词。retail 变体封面为团队名称 / 作品名称 / 案例企业名称。
4. 院校信息（文字 / 口头 / PPT / 视频）每处扣 3 分；出镜人数不符扣 3 分；语言不符扣 3 分（细则附件 2）。
5. 引用：年报引用必须标页码；比率必须给公式；外部资料进参考资料；假设必须明示（细则六(三)7）。
6. 禁语与广告法词：`checks.json.forbiddenTerms / advertisingLawTerms / clicheTerms`（“颠覆”“第一”“赋能”“打造”等）命中即扣规范分。
7. 声明：提交包附作品原创性声明与版权声明（`naming.json.declarations`），签名页不进正文页数。
8. 数据真实性：示例数据必须带标记且在团队确认清单列出；不得编造年报页码——页码不确定写【待核实 p.】并在附录索引里补。

## 3. 评委三视角的扣分雷达（`rubric.json.judgeFocus`）
- 投资人：财务分析深度 20 + 财务预测 18。追问“ROE 为什么低、现金流改善能否持续、所得税为负怎么回事、减值会不会再来”。
- 教授：环境 10 + 策略 20 + 结构 12 + 治理 8。追问“框架是否完整、准则条款是否引对、聚类方法是否成立”。
- 高管：实施 12 + 策略 20。追问“三年目标谁负责、资源从哪来、第一年先做什么”。
