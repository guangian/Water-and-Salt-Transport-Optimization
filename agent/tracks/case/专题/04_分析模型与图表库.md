# 04 分析模型与图表库（case）

> 图型名与 `bizkit.charts` 契约一致（`docs/contracts.md` §7.1：bar / grouped_bar / stacked_bar / hbar / line / area / pie_as_bar / donut / waterfall / funnel / tornado / breakeven / cashflow_combo / scatter_matrix / positioning_map / gantt / radar / bmc）。每图必填 `source`（年报年份 + 页码或文献号），标题写结论句，正文配“读图两句”：第一句说数字与方向，第二句说对策略的含义。全书图表 ≥ 12（`checks.json.chartMin`）。

## C1 各章推荐图型与数据字段
| 章 | 图 id 建议 | type | data 字段要求 | 读图句模板 |

| 2 宏观 | fig_macro | line | categories 年份（≥ 5 年）；series 1–2 条（如 GDP 增速、行业规模）；unit | “X 指标 2020–2024 年由 A 升至 B，年均 C%；对本企业意味着……” |

## C2 读图句与数字规则
- 每图标题 = 结论句（含数字或方向），不写“XX 情况图”。
- 读图两句：数字句（数值 + 口径 + 年份 + 页码 / 文献号）+ 含义句（“因此第 N 章……”）。
- 比率图注明分母口径（平均 / 期末）；金额统一亿元、比率统一 %，保留 1–2 位小数。
- 预测图区分 A（实际）与 E（预测），并标“基准 / 策略情景”。
- 同一数字在图、表、正文、PPT 必须同源 `numbers.json`，改数只改 `assumptions.json` 重跑。
