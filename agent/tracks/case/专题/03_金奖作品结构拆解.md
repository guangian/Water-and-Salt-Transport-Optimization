## 2. 每章“国金写法”要点
- 概要：六句固定顺序——企业现状一句（含 2 个比率）/ 核心问题 / 三年目标（收入、归母净利、ROE）/ 三大策略 / 预测结果（基准 vs 策略差额）/ 资本安排。数字全部与第 7 章一致。
- 引言：命题原文一句（不抄整段）→ 命题回应表 → 框架图（F1–F9 对应章节）→ 数据来源表注明“2022–2024 年年报 + 2025 年报（若已披露，按细则建议参考最新）”。
- 当前经济情况：宏观只保留与企业相关的 3 个变量（如 GDP、专项债 / 教育财政、AI 产业政策）；行业用 2–3 家权威来源；聚类放本章末，直接引出第 3 章。
- 财务分析：顺序 = 三表趋势 → 五类比率 → 杜邦 → 现金流与盈利质量 → 同业 / 聚类对比 → 问题识别树。示例证据链：收入 233.43 亿元（+18.79%）但归母净利 5.60 亿元（−14.78%）；经营现金流 24.95 亿元（+613%）；应收 146.66 亿元占总资产 35.4%；信用减值 9.65 亿元；研发资本化 43.58%；其他收益 10.33 亿元（2024 年报“主要会计数据”“费用”“合并利润表”节，页码按 PDF 填）。
- 策略分析：外部→内部→竞争者→TOWS→选项评分，评分表五维权重写依据（如“财务影响权重 30%，因命题目标是经营业绩”）。
- 策略计划：三年总方向一句（如“收入结构 C 端与平台占比提升至 X%，应收天数降至 150 天”），策略屋贯穿到 KPI。
- 实施计划：按营销 / 研发 / 供应链 / 人力 / 数字化 / 财务共享分业务单元，每行动有“关联预测行”（对应第 7 章哪条收入流或费用项）。
- 财务预测：先假设表，再综合收益表（含其他综合收益行），再现金流 / 资产负债摘要，再基准对比与情景、tornado，最后资本安排（经营现金流 / 银行借款 / 可转债等来源、金额、成本、期限）。
- 公司治理：按《上市公司治理准则》条款号逐项（第 25 / 34–37 / 38–39 / 56 / 第八章 / 第九章），现状引年报“公司治理”节页码；建议 3–5 条，每条有条款依据与预期效果。
- 知识点列表：覆盖财务会计（收入确认、减值、研发资本化、所得税）、财务管理（杜邦、现金流、资本结构、WACC）、管理会计（本量利、预算、平衡计分卡、EVA）、战略（五力、TOWS、安索夫）各 ≥ 3 条。
