# 01 赛道方法论（case · 以顾问身份做可复算的诊断）

> 推理链：**命题要求 → 财务症状（比率 / 现金流 / 杜邦）→ 经营原因（分部 / 客户 / 费用）→ 战略根因（TOWS / 选项评分）→ 三年策略计划 → 实施动作 → 计划综合收益表 → 治理保障**，每环可倒查到年报页码或准则条款。示例为 2026 届命题科大讯飞（002230）《2024 年年度报告》（ http://static.cninfo.com.cn/finalpage/2025-04-22/1223191180.PDF ，访问 2026-10-25；页码按 PDF 核实）。

## F1 五类比率表（财务分析章的地基）
- 何时用：第 3 章开篇；细则要求“表明用来计算会计比率的公式”（`docs/research/raw/sdssfw_1449_【山东省赛细则】….pdf` 六(三)1）。
- 输入：三年合并三表 + 附注分部数据；存量项目用期初期末平均值。
- 输出：`指标 | 公式 | 2022 | 2023 | 2024 | 同业均值 | 年报页码`，五类：盈利（毛利率、净利率、ROA、ROE = 归母净利润 ÷ 平均归母权益）、营运（应收 / 存货 / 总资产周转天数）、偿债（流动比率、资产负债率、利息保障倍数）、成长（收入 / 归母净利 / 经营现金流增速）、现金流质量（经营现金比率 = 经营现金流净额 ÷ 净利润、自由现金流）。
- 示例：2024 年毛利率 = (233.43 − 133.91) ÷ 233.43 = 42.6%；资产负债率 = 227.64 ÷ 414.79 = 54.9%；应收账款 146.66 亿元占总资产 35.4%，应收周转天数 ≈ 365 ÷ (233.43 ÷ 134.16) ≈ 210 天。
- 常见误用：用期末值算周转；ROE 不用归母口径（与年报“加权平均净资产收益率 3.21%”对不上）；公式写在文字里不进表。

## F2 杜邦三因素分解（把 ROE 低的责任分到人）
- 何时用：比率表之后，回答“ROE 为什么只有 3%”。
- 输入：归母净利率、总资产周转率（收入 ÷ 平均总资产）、权益乘数（平均总资产 ÷ 平均归母权益），三年各一组。
- 输出：杜邦树 + 归因表（连环替代法算各因素对 ROE 变动的贡献）。
- 示例：2024 年 2.40% × 0.589 × 2.28 ≈ 3.2%，与年报加权 ROE 3.21% 吻合；2023 → 2024 下降 0.73 pct，主因净利率（归母净利 −14.78%），周转率小幅改善（收入 +18.79% 快于总资产 +9.64%）。
- 常见误用：乘积对不上年报又不解释口径；只画树不归因；归因不接到策略章（净利率 → 费用 / 减值 / 结构对策）。

## F3 现金流质量与盈利质量四问
- 第 3 章第三节，投资人评委必追问处。四问：① 经营现金流 ÷ 净利润是否持续 ≥ 1；② 利润中政府补助 / 投资收益 / 公允价值变动占多少；③ 减值与坏账是否吞掉利润；④ 研发资本化是否推高当期利润。
- 示例：2024 年经营现金流净额 24.95 亿元 ÷ 净利润 5.07 亿元 = 4.9（2023 年 3.50 ÷ 6.13 = 0.57），改善来自回款率 98.14%；但其他收益 10.33 亿元 > 利润总额 2.29 亿元，信用减值损失 9.65 亿元（2023 年 6.77 亿元），所得税费用 −2.78 亿元，研发资本化占比 43.58%、开发支出 16.36 亿元（+134%）——这就是“盈利质量”节的证据链。
- 准则锚点：收入 CAS 14 五步法（系统集成合同的时段 / 时点）；坏账 CAS 22 预期信用损失；研发支出 CAS 6 第 7–9 条；政府补助 CAS 16；商誉减值 CAS 8。原文：财政部会计司 https://kjs.mof.gov.cn/zt/kjzzss/ （访问 2026-10-25）。写法：“依据《企业会计准则第 6 号——无形资产》第九条……”，不写“根据相关准则”。
- 常见误用：只说“现金流良好”不算比率；剔除非经常性后不重算净利率；用“操纵”字眼——顾问只写“口径影响与披露建议”。

## F4 行业数据聚类（官方评分项“行业数据聚类分析”5 分）
- 何时用：第 2 章末或第 3 章同业节；研究员 C 取数。
- 输入：同业 5–8 家近一年 2–3 个指标（毛利率 × 研发费用率 × 应收天数），来源各公司年报。
- 输出：四象限散点（`scatter_matrix` / `positioning_map`）+ 簇表（簇名 / 成员 / 均值 / 本企业位置 / 差距）；方法写明 Z-score 后 K-means（k = 2–3）或人工四象限，附录给底稿。
- 示例（候选同业，取数时核实）：海康威视、大华股份、中科创达、金山办公、用友网络、拓尔思、云从科技、寒武纪；结论句：“本企业落在‘高研发、低周转’簇，差距主要在应收天数。”
- 常见误用：2 家对比却叫“聚类”；量纲不统一；结果不回到问题诊断。

## F5 问题识别树（“问题识别”省赛 5 分 / 预选赛 20 分）
- 何时用：第 3 章末“问题诊断”节，≤ 3 个核心问题。
- 结构：财务症状（比率 + 页码）→ 经营原因（分部 / 客户 / 费用）→ 战略根因（定位 / 组合 / 治理）→ 对应第 4–6 章策略。
- 示例：症状“净利率 2.4%，低于簇均”→ 原因“G 端回款慢致坏账计提 10.14 亿元；研发费用 38.92 亿元占收入 16.7%”→ 根因“G 端占比高、C 端规模未摊薄研发”→ 策略“C 端硬件 + 开放平台提升占比，应收天数三年降至 150 天”。
- 常见误用：问题过多；症状无数字；根因是口号。

## F6 TOWS 与战略选项评分
- 何时用：第 4 章，替代只列 SWOT。
- 输入：PEST / 五力、价值链 / VRIO、竞争者矩阵（≥ 3 家 × ≥ 6 维）。
- 输出：TOWS 四象限各 ≥ 2 条选项 → 评分表（吸引力 / 可行性 / 风险 / 协同 / 财务影响，权重合计 100% 并写依据）→ 选 3 舍 2，被否决项给理由。
- 常见误用：SWOT 无数据；评分无权重依据；选项与第 7 章情景不对应（`rubric.json` strategy.92）。

## F7 策略屋与目标体系
- 第 5 章。输出：策略屋（问题 → 策略 → 目标 → 举措 → 指标）+ 三年目标表（收入 / 归母净利 / ROE / 经营现金比率 / 应收天数 / 研发费用率 + 非财务 3 项），与第 7 章预测一致，口径写“2027E”。
- 常见误用：目标只有收入；非财务指标无基线。

## F8 计划综合收益表（硬性：细则六(三)5）
- 第 7 章；`finmodel` startup 模式，`revenueStreams` ≥ 2：“现有业务基准（历史 CAGR 与毛利率）”+“新举措增量”。
- 输出：三年综合收益表（含其他综合收益行，为 0 也注明）+ 现金流 / 资产负债摘要 + 假设表（带来源）+ 三情景 + tornado + “不实施策略”基准对比。
- 连续性检验：2025E 毛利率、费用率、应收天数与 2024A 差异 ≤ 3 pct / 30 天，否则假设表写理由。
- 常见误用：只给利润表叫“综合收益表”；假设无来源；增速与历史脱节无解释。

## F9 公司治理准则逐条评估
- 第 8 章。依据《上市公司治理准则》（证监会公告〔2018〕29 号， https://www.gov.cn/gongbao/content/2019/content_5363087.htm ，访问 2026-10-25）：第 25 条董事会构成、第 34–37 条独立董事、第 38–39 条审计委员会（独董过半并召集，召集人为会计专业人士）、第 56 条绩效评价、第八章利益相关者与 ESG、第九章信息披露。
- 输出：`条款 | 公司现状（年报页码） | 评估（符合 / 部分 / 待改进） | 建议`，加“治理问题 ↔ 财务异常”关联行（如坏账 ↔ 审计委员会对信用政策的监督）。
- 常见误用：抄年报“治理优秀”段落；建议无条款依据；忽略新《公司法》对监事会安排的影响（写作时核实）。

## 流通业变体（`caseVariant = retail`）
框架：案例简介 → 内外部环境（PEST / 五力 / 价值链）→ 发展瓶颈（数据 + 因果链）→ 结论与启示（可迁移）。必备“地区性特点”节（所在省门店 / 供应链 / 消费者 + 省统计局数据）与框架图；前沿方法任选一（RFM、DEA、GIS 热力、情景规划），须有输入数据与输出图。
