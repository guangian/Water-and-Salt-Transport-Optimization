# case 赛道专题包 · 索引

赛道官方名称：全国高校商业精英挑战赛 **会计与商业管理案例竞赛**（`caseVariant = accounting`，默认；2026 届命题企业科大讯飞 002230，2022–2024 年报）；变体：创新创业竞赛 **流通业经营模拟赛道**（`caseVariant = retail`，案例分析报告 ≥ 3000 字 + PPT ≥ 20 页）。
评分：accounting 省赛 BP 70 + 视频 30、全国预选赛 BP 100、总决赛 BP 60 + 演讲 20 + 回应 20（详见 02 §0）；retail 书面 60 + 陈述答辩 40。
封面例外：细则要求封面写选手与指导教师姓名，本系统用占位 `【提交前由团队填写：…】`，团队提交前填写；全文仍不得出现院校词（02 §2 第 3 条）。
