# 05 工作流与自检表（case · 相对 `agent/CLAUDE.md` Step 0–8 的增量动作）

## Step 0 读题解析（主代理）
- 必须多做：① 确认 `subject.caseVariant`（accounting 默认 / retail），据此选 `checks.json.coverFieldsByVariant` 与 `requiredEvidenceByVariant`；② 命题要求逐条列表（细则六(一)(三) 7 条注意事项），每条映射到章节；③ 评分映射表同时列省赛 70 / 预选赛 100 / 总决赛 60 三列权重（见 02 §0）；④ 页数预算按目标 42 页、附录 ≤ 4 页。
- 必须不同：封面字段填占位 `【提交前由团队填写：选手姓名】` `【提交前由团队填写：指导教师姓名】`，不生成人名；`anonymize.forbidden` 加入院校词但保留 “科大讯飞”（白名单）。
- 研究问题清单固定加入：三年三表与附注页码定位、分部数据、同业 5–8 家名单、行业政策、治理现状、2025 年报是否已披露。

## Step 1 调研（研究员 A–D + 消费者洞察）
| 角色 | 本赛道必抓 | 落盘 |
|---|---|---|
| A 宏观与行业 | GDP / 利率 / 财政（与客户结构相关的专项债、教育经费）、行业规模与增速（≥ 2 来源）、技术趋势 | `01_宏观与行业.md` + CSV |
| B 客户与渠道 | 案例企业 G / B / C 客户结构、渠道与回款特征、消费端产品价格带 | `02_消费者与渠道.md` |
| C 同业与聚类 | **5–8 家同业近一年 3 指标**（毛利率 / 研发费用率 / 应收天数 / 收入增速）CSV + 竞争者矩阵 ≥ 6 维 | `03_竞品与标杆.md` + `数据/同业指标.csv` |
| D 对象企业 | 三年年报“主要会计数据 / 费用 / 合并三表 / 分部 / 研发投入 / 应收账龄 / 公司治理”各节**页码索引表**；关键数字 ≥ 40 个进 `关键数字_D.json`（每条 source = “2024 年报 p.NN”） | `04_对象企业与政策.md` + `数据/年报页码索引.csv` |
| 消费者洞察 | 仅在有 C 端产品时做轻量问卷（≥ 25 题）作为新举措证据；示例数据必须标记 | `05_消费者洞察.md` |
- 数据源优先级：巨潮资讯 / 交易所公告原文 > 公司业绩说明会材料 > 国家统计局 / 部委 > 行业协会 > 券商研报 > 媒体。准则原文用财政部会计司页面；治理准则用证监会 / 国务院公报。
- retail 变体：A 另抓院校所在省的零售总额 / 门店 / 人口数据（省统计局）；D 抓案例企业分地区收入与门店数。

## Step 2 策略（主代理）
- 产出必须含：问题树（≤ 3，F5 格式）、TOWS、选项评分表（权重依据）、三大策略与被否决项、三年目标体系（含 ROE / 经营现金比率 / 应收天数）、策略 ↔ 预测情景对应表、命题回应表、各章结论句、数字需求单（`numberKeys` + `roe_y3` 等）。
- 不做品牌 Big Idea；“主线句”改为一句顾问式诊断主题（如“从规模增长转向现金利润”）。

## Step 3 财务（财务建模师，先读 `case-analysis` 再读 `fin-model`）
- 模式：`startup`，`years = 3`（或 4 含基年），`revenueStreams` ≥ 2：“现有业务基准”（按分部历史 CAGR 与毛利率，来源年报页码）+ “新举措增量”（每项对应实施计划行动）。基准情景单独导出“不实施策略”对比。
- 特有表：计划综合收益表（含其他综合收益行）、连续性检验表（2024A vs 2025E 的毛利率 / 费用率 / 应收天数差异与理由）、资本安排表、盈利质量调整表（剔除非经常性后的净利率）。
- 检查：三表勾稽为 0；预测 ROE 用归母口径；悲观情景经营现金流不为负；敏感性含毛利率、研发费用率、应收天数、减值率。
- 数字记账：年报数字经 `record_numbers` 进 `numbers.json`，key 前缀 `research_`，source 必带页码。

## Step 4 图表（制图员）
- 需求单最少 14 张（见 04 C1），其中 第 3 章 ≥ 5 张、第 7 章 ≥ 4 张；聚类图与杜邦瀑布必有。

## Step 5 撰写（主笔，按 `outline.json` 分批）
- 每章落点：概要 = 关键数字卡；引言 = 命题回应表 + 框架图；第 2 章 = “对企业含义”句 ≥ 3；第 3 章 = 比率表（公式列 + 页码列）+ 杜邦 + 四问 + 问题识别表；第 4 章 = 问题 → 策略映射 + TOWS + 选项评分；第 5 章 = 策略屋 + 目标表；第 6 章 = 8 列行动表 + gantt + 风险矩阵；第 7 章 = 假设表 + 综合收益表 + 三表摘要 + 对比 + 敏感性 + 资本安排；第 8 章 = 条款评估表 + 建议；第 9 章 = 知识点表 ≥ 15 + 结语；附录 = 年报页码索引 + 底稿。
- 引用格式：年报“（2024 年年报 p.87）”；准则“《企业会计准则第 14 号——收入》第五条”；治理“《上市公司治理准则》第三十八条”。
- 禁止：院校词、人名、禁语 / 广告法词、“据统计”“预计将”；超 10 行的明细表进附录。

## Step 6 路演（路演设计师，读 06）
- 18–22 页正文 + ≤ 4 页备用；讲稿 1650–1950 字；题库 ≥ 40 题、六维度（财务分析 / 战略逻辑 / 实施与资源 / 财务预测 / 治理与合规 / 行业与竞争）各 ≥ 4；视频分镜开头 3–5 人出镜、全程不露院校。

## Step 7–8 评审与打包
- 评委按 `rubric.json`，另抽查：比率公式列、年报页码 ≥ 3 处、综合收益表存在、聚类样本数、知识点条数、治理条款号。
- 打包：封面占位已说明、声明页、命名规则、团队确认清单加入“填写姓名 / 核对年报页码 / 替换示例数据 / 补 2025 年报（若已披露）”。
