# 案例分析赛道 · 赛道规范（case）

> 适用两类赛事（任务书 `subject.caseVariant` 指定）：
> - `accounting`（默认）：**会计与商业管理案例竞赛**——以组委会指定上市公司（2026 科大讯飞 002230，2025 美的集团，2024 瑞贝卡）近三年财务报告为基础，以商业策略顾问身份制定提升未来三年经营业绩的商业计划书。
> - `retail`：**创新创业竞赛 流通业经营模拟赛道**——对流通企业案例做内外部环境与发展瓶颈分析，提出结论与启示（案例分析报告，配套 PPT ≥ 20 页）。

## 0. 硬约束

| 项 | accounting | retail |
|---|---|---|
| 文件 | 中文 PDF，A4 竖版，**除封面目录外全文 ≤ 50 页（含附录）**，正文宋体小四、英文 Times New Roman、单倍行距、标清页码 | A4 竖版 PDF，≥ 3000 字，配套路演 PPT ≥ 20 页 |
| 封面 | 团队名称、组别、参赛选手姓名与指导教师姓名（本赛道细则要求姓名，但不得出现电话 / 邮箱；全文不得出现院校名称、logo、标语）——**姓名由团队提交前自行填入，本系统用占位** | 团队名称、作品名称、案例企业名称；不得出现院校信息 |
| 评分 | 商业计划书 70 + PPT 陈述视频 30 | 书面报告 60 + 陈述答辩 40 |
| 引用 | 引用业绩报告须标明页码；财务分析标明比率公式 | 数据注明出处 |

## 1. 必备要素与映射

**accounting（12 要素）**：1 目录；2 概要；3 引言；4 当前经济情况；5 本企业财务分析；6 策略分析；7 策略计划；8 实施计划；9 财务预测；10 公司治理惯例回顾；11 附录和参考资料；12 所用到的财务与会计知识点列表。

| 要素 | 页数 | 必答 | 必备图表 |
|---|---|---|---|
| 概要 | 1 | 企业现状一句、核心问题、三年目标（收入 / 利润 / ROE）、三大策略、预测结果、融资 / 资本安排 | — |
| 引言 | 1–2 | 命题解读、分析框架、数据来源（年报页码） | 路线图 |
| 当前经济情况 | 3–4 | 宏观（GDP / 政策 / 利率）、行业（规模 / 增速 / 格局 / 技术趋势）、对企业的含义 | 宏观与行业图 ≥ 2 |
| 本企业财务分析 | 8–10 | 三年三表趋势；盈利 / 营运 / 偿债 / 成长 / 现金流五类比率（**公式标注**）；杜邦分解；与 2–3 家同业对比；问题诊断 | 比率表（含公式列）、杜邦图、同业对比条形、现金流柱线 |
| 策略分析 | 5–6 | 外部（PEST / 五力）、内部（资源 / 能力 / 核心竞争力、价值链）、竞争者、SWOT / TOWS 矩阵、战略选项评估 | 五力表、价值链、TOWS、选项评分表 |
| 策略计划 | 3–4 | 未来三年总体方向、业务组合（BCG / 安索夫）、目标体系（财务 + 非财务）、关键举措 | 安索夫矩阵、目标树 |
| 实施计划 | 4–5 | 关联营销 / 生产 / 研发 / 供应链 / 人力 / 数字化等业务单元的行动、里程碑、责任、资源、KPI | gantt、行动表 |
| 财务预测 | 6–8 | 未来三年**计划综合收益表**（必须）、现金流与资产负债摘要、关键假设表、情景与敏感性、与基准（不实施策略）对比 | 假设表、预测表、对比柱、tornado |
| 公司治理惯例回顾 | 2–3 | 依据公司治理准则评估董事会 / 独董 / 激励 / 信息披露 / ESG，给出改进建议 | 治理评估表 |
| 附录与参考资料 | ≤ 6 | 年报页码索引、比率计算底稿 | 表 |
| 财务与会计知识点列表 | 1 | 本文用到的知识点（≥ 15 条，注明所在章节） | 表 |

**retail（8 要素）**：目录、概要、引言、案例简介、企业内外部环境分析、发展瓶颈分析、结论与启示、附录与参考资料。页数目标 40，PPT ≥ 20 页；瓶颈分析须有数据证据与因果链；结论与启示要能迁移到同类流通企业。

## 2. 写作要点
- 年报数据逐条标页码；比率表含公式列；预测与历史口径一致。
- 策略建议必须有综合收益表支持（预测由 `finmodel` startup 模式以“现有业务 + 新举措”两条收入流实现，或自定义 assumptions）。
- 治理建议引用《上市公司治理准则》条款。
- 匿名：院校信息一律不得出现；姓名字段按细则由团队填写。
