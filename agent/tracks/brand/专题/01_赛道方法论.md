# 品牌策划赛道 · 核心方法论与推理链

> 适用 CUBEC 品牌策划赛道。评分 6×10 + 8×5 见 `tracks/brand/rubric.json`；细则（五步定位、核心价值双认可、八类品牌元素、ICC 准则、资产保护与应急程序）见 `knowledge/评分表与扣分细则.md` 与 https://www.cupk.edu.cn/smxy/upload/resources/file/2026/01/12/110283.pdf（访问 2026-10-25）。
> 唯一主线：**洞察句 → 定位陈述句 → Big Idea → 元素系统 → 传播动作 → 预算行 → KPI 行**，七环每环回指上一环的一个数字；框架只是产生七环的工具，框架名不作标题。

## 1. 七环推理链（写作与评审都按它走）

| 环 | 产出物 | 必须回指的上游证据 | 落点 |
|---|---|---|---|
| ① 洞察句 | 人群 + 场景 + 冲突 + 未满足需求，≤ 60 字 | 一手 ≥ 2 个数字 + 二手 1 个 | 第 2 章末、概要 |
| ② 定位陈述句 | 对于（人群），X 是（参照框架）中（差异点）的品牌，因为（支持点 1、2） | 细分表 + 目标市场评分表 + POP/POD + 定位图 | 3.6 |
| ③ Big Idea | 主张 ≤ 12 字 + 视觉锤 + 语言钉 + “因为（洞察）所以（创意）” | 洞察句、定位句、候选对照表 | 4.1 |
| ④ 元素系统 | 名称 / 域名 / 标识 / 色板字体 / IP / 宣传语 / 听觉 / 包装 ≥ 4 类设计说明 | Big Idea、商标检索结论 | 4.2–4.6 |
| ⑤ 传播动作 | 动作表 8 列（动作 / 目标 / 渠道 / 内容 / 时间 / 负责人 / 预算 / KPI） | 元素延展清单、漏斗各层目标 | 第 5 章 |
| ⑥ 预算行 | 项目 / 单价 / 数量 / 单位 / 小计 / 单价来源 | 第 5 章动作一一对应 | 7.2 |
| ⑦ KPI 行 | 指标 / 基线 / 目标 / 测算依据 / 工具 / 周期 ≥ 5 行 | 漏斗假设、调研基线 | 7.6 + 第 1 章 |

样本七环见 `专题/03_金奖作品结构拆解.md` 第 4 节；能逐环回溯是国金级的最低结构要求。

## 2. 定位五步链（细则列明，“定位的正确性”10 分按步打）

| 步 | 输入 | 输出物 | 常见误用 |
|---|---|---|---|
| ① 宏微观环境预测 | 与品牌直接相关的 PEST 6–8 条、品类近 5 年规模增速、渠道结构变化 | 趋势表 3 条：事实（数值 + 年份 + 文献号）→ 3–5 年判断 → 对本品牌含义 | 复制第 2 章 PEST；只写现状无预测 |
| ② 市场细分 | 问卷的人群 / 场景 / 价值 / 价格带分布，二手人口与渠道数据 | 细分表（维度 × 类别 × 规模证据 × 吸引度） | 只按年龄性别切；无规模数字 |
| ③ 目标市场选择 | 规模 / 增长 / 可及性 / 竞争强度 / 匹配度各 1–5 分及打分口径 | 评分表 + 一句决策 + TAM→SAM→SOM 公式写在正文 | 两格同分不决胜（样本 A/B 均 21 分）；SOM 不与首年 GMV 对账 |
| ④ 竞争对手异同 | 竞品 3–5 家 × 6–8 维（含替代品类）、传播主题监测 | POP/POD 表 + 定位图（≥ 4 竞品，坐标轴有依据） | 只列弱竞品；不写自家短板 |
| ⑤ 独特性与风格 | 品牌个性五维（问卷量表均值）、风格关键词 3 个 | 个性雷达 + 定位陈述句 + 核心价值三层 + 双验证表 + 品牌屋 | “高品质、年轻化”空话；核心价值单边验证 |

双验证写法：企业侧“访谈 N 人，对核心价值 X 认可度 a%”；顾客侧“问卷 n=384，联想匹配 / 概念测试 TOP2 Box b%”，两个数字进 `numbers.json`（`research_` 前缀）。92 分档再加“被否决的备选定位 + 理由”一行（`rubric.json` positioning.bandAnchors.92）。

## 3. Big Idea：10 → 3 → 1（流程见 `.claude/skills/brand-creative/SKILL.md` §2）

- 输入：五个张力源（品类冲突 / 文化符号 / 消费场景 / 对手空白 / 数据反直觉）各 2 个候选，每个 = 主张 + 视觉锤 + 语言钉。
- 输出：7 项打分（可复述 / 与定位一致 / 不侵权 / 可持续 3 年 / UGC 可参与 / KPI 可测 / 企业可执行，满分 35）→ 3 选 1 对照表 + 不选理由 → 与 3 个竞品传播主题的差异矩阵（主题 / 人群 / 情绪 / 符号 / 渠道）。
- 误用：主张是品类通用词（国潮 / 焕新 / 年轻化，`rubric.json` creative.bandAnchors.60）；创意与洞察无关；语言钉含广告法禁用词；视觉锤不能在包装与片头复现。
## 4. 品牌屋与策略屋（两张表，不是两章）

品牌屋：使命 / 愿景 / 核心价值 / 个性 / 支持点 / 口号六行一表，放 3.7。策略屋：洞察 → 定位 → Big Idea → 三大策略 → KPI → 预算，一页收束，放第 3 章末或概要。误用：品牌屋口号与第 4 章语言钉措辞不一致；策略屋 KPI 与第 7 章数字不同（`cross_doc_consistency` 硬门槛）。

## 5. 元素系统八件套（名称、域名、标识、符号、形象代表 / 代言人、宣传语、广告音乐、包装）

- 名称延展：母品牌 + 子系列名，写清“母品牌承接信任、子品牌承接年轻表达”的分工；命题要求“视觉符号 / 名称延展”时本节是命题回应表的直接落点。
- 标识与色板：构成 / 寓意 / 最小尺寸 / 禁用示例；色板给 CMYK/RGB/HEX 与应用比例；字体注明商用授权。
- 商标检索：类别（第 29 / 30 / 32 / 35 类按品类）、检索日期、结论、规避（双轨注册 / 改名预案）；无法检索写【待核实】并降为定性表述。
- 包装：主 SKU 规格与价格（来自 PSM）、信息层级排序要有决策链数据支撑、渠道 SKU 梯度。本系统不画 LOGO，以设计说明表 + 规范表 + 应用清单呈现。

## 6. IMC 三件套：信息屋、总图、分层清单

- 信息屋：核心信息 1 句 → 支持信息 3 条 → 证据（文献号 / 一手数字）。
- 阶段 × 渠道 × 内容总图：声量引爆 / 心智渗透 / 转化沉淀 × 渠道 ≥ 4 × 内容形态，每格对应动作表一行。
- KOL/KOC 分层：头 / 腰 / 尾 / KOC 的数量 × 单价区间 × 来源（星图 / 蒲公英 / 花火公开报价，注明年份）× 预期曝光；合计 = 第 7 章达人行。
- 漏斗：曝光 → 触达 → 互动 → 首购 → 复购，每层“上一层 × 转化率”并写转化率来源；首购量 × 客单价 = 首年 GMV，与 SOM 对账。
## 7. 预算与 KPI（budget 模式，`python -m bizkit.finmodel --example budget`）

- 预算 = Σ 单价 × 数量 + 机动金 5–10%，≤ 命题上限；单价来源必填；不得打包合计（样本把 9 项 84 万元并为一行即“不可复算”）。
- ROI 先定义再算：ROI = （首年增量毛利 − 传播预算）÷ 传播预算，ROAS = GMV ÷ 投放费用，不得混写；保留真实计算值不凑整（`CLAUDE.md` 规则 8）。
- KPI 表 ≥ 5 行：曝光 / 互动 / 搜索指数 / 首购 / 复购 / 品牌认知前后测，每行基线 / 目标 / 依据 / 工具 / 周期。
- 敏感性：预算 ±20% 对曝光与 GMV 的 tornado；92 分档三情景 KPI 与预算联动。

## 8. 品牌资产保护与风险（10 分，常被写薄）

资产清单（商标 / 版权 / 域名 / 外观 / 地理标志 × 状态 × 权属 × 计划）→ 注册计划（类别 / 时间 / 费用 / 来源，规费见 https://www.cnipa.gov.cn/ 收费标准页）→ 一致性管理（VI 手册、授权与渠道管控）→ 舆情 SOP（监测 → 研判 → 响应 → 复盘，小时级时限 + 责任角色）→ 风险矩阵 ≥ 6（概率 × 影响 + 对策 + 触发指标），每条对策指向第 5 章动作或第 7 章预算行；92 分档加 KOL 翻车 / 抢注 / 价格体系三类专项预案。

## 9. 命题回应表（命题企业赛道的“第一张表”）

列：命题要求（逐条抄任务书）/ 对应章节 / 关键举措 / 可量化目标；行数 = 命题条数；每条目标在 KPI 表有对应行。放第 1 章，概要一句话复述；企业真实约束（预算、产能、渠道）要显式处理（`rubric.json` fit.bandAnchors.92）。
