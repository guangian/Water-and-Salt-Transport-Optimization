# 品牌策划赛道 · 工作流差异与提交前自检表

> 通用流程见 `CLAUDE.md` Step 0–8。本文件只写本赛道“必须多做 / 必须不同”的动作；财务模式 `budget`（`tracks/brand/track.json` 的 `financeMode`）。

## 1. 各阶段差异动作

### Step 0 读题解析（主代理）
- 命题企业：任务书“命题要求”逐条编号写进《任务解析》第 1 部分，预建命题回应表骨架（要求 / 章节 / 举措 / 量化目标），行数 = 命题条数；无命题企业以授权书“企业希望解决的问题”代替。
- 评分映射表固定 6 行（现状 / 定位 / 元素 / 传播 / 保护 / 预算）+ 展示 8 项一行，每行写“评委要看到的证据”（抄 `rubric.json.evidenceRequired`）。
- 页数：第 3 + 4 + 6 章合计 ≥ 第 5 章；附录 ≤ pageTarget × 15%。关键假设必含预算上限、主渠道、调研模式、商标可注册性。

### Step 1 调研（研究员 A–D + 消费者洞察）
| 角色 | 本赛道必抓数据 | 落盘 |
|---|---|---|
| A 宏观与行业 | 品类近 5 年规模与增速、渠道结构（线上 / 内容电商占比）、价格带分布、宣称法规（广告法、食品 / 保健 / 化妆品规则、ICC 条款） | `01_宏观与行业.md`、`数据/市场规模.csv` |
| B 消费者与渠道 | 目标人群规模（年龄结构 × 渗透率）、媒介触点占比、平台画像、电商价格带销量 | `02_消费者与渠道.md`、`数据/渠道与触点.csv` |
| C 竞品与标杆 | 3–5 家 × 6–8 维（含替代品类 1 家、跨界标杆 1 家）、各家传播主题 / 代言 / 视觉锤 / 主渠道、达人公开报价区间（注明年份） | `03_竞品与标杆.md`、`数据/竞品矩阵.csv`、`数据/KOL报价.csv` |
| D 对象企业与政策 | 品牌资产现状（商标类别与状态、域名、版权、外观）、产品线与价格、渠道网点、现有账号数据、企业访谈事实；区域政策 | `04_对象企业与政策.md`、`数据/品牌资产.csv` |
| 消费者洞察 | 问卷 ≥ 25 题含品牌资产四维、决策首因、PSM 四题、形态偏好、概念测试（候选主张复述与喜好）、个性量表五维、媒介触点；访谈提纲 ≥ 12 问含企业方 ≥ 2 人；执行计划 n = 384、配额、质控、α / KMO | `05_消费者洞察.md`、`调研工具包/`、`数据/问卷结果_示例.csv` |

### Step 2 策略（主代理，`02_策略/策略框架.md`）
必须产出：问题树 ≤ 3；洞察句；五步链各步一表；定位陈述句 + 被否决的备选定位一行；核心价值双验证两个数字；品牌屋；Big Idea 10 → 3 → 1 候选表与决选理由；差异矩阵；各章结论句 8 条（含数字或 key 占位）；数字需求单（`budget_total / budget_contingency / sample_size / tam / sam / som_y1 / kpi_exposure / kpi_conversion / roi` + `research_*`）；标题；命题回应表终稿。

### Step 3 财务（建模师，`mode = budget`）
- `assumptions.json`：phases × items（item / unitPrice / quantity / unit / source），source = 平台刊例年份 / 公开报价区间 / 供应商报价 / 同类案例；`contingencyPct` 0.05–0.10；`totalCap` = 命题上限；kpis ≥ 5 行。
- 特有表：预算总表（阶段 × 渠道）、月排期、KPI 表、ROI 口径表（定义 / 公式 / 输入 key / 结果）、三情景表（预算 −20% / 基准 / +20% 对曝光、首购、GMV）。
- 禁止：明细打包为“其他”；ROI / ROAS 凑整；预算行与第 5 章动作数量不等。验收：`财务摘要.md` 抽 5 个数与 `numbers.json` 一致，`budget_total ≤ totalCap`。

### Step 4 图表（制图员）
需求单按 `专题/04` 第 3 节最低配置。

### Step 5 撰写（主笔，按批）
按 `outline.json.writingGuide` 与 `专题/03` 第 2–3 节必备元件写。本赛道额外落点：概要数字卡 4–6 个与后文写法一致、定位句与 Big Idea 各一引用块；第 1 章命题回应表 + KGI/KPI 基线→目标表 + 调研设计表；第 2 章章首两个反差数字、一手五要素原句 + α / KMO、竞品矩阵含自家短板、荣誉 ≤ 5%；第 3 章小节标题即五步名、评分表决胜列、SAM 乘数链写在正文、双验证两个数字、品牌屋 + 策略屋、备选定位一行；第 4 章 Big Idea 一页（主张 / 视觉锤 / 语言钉 / 推导句 / 来源）、商标检索含日期、延展指向第 5 章动作、SKU 梯度；第 5 章漏斗转化率来源、KOL 分层表、内容日历首 3 月按周、样稿 ≥ 5、动作表 8 列、平台机制一句、合规自检表（ICC + 广告法 + 广告标注）；第 6 章 SOP 含“N 小时内”、风险 ≥ 6 含触发指标、三类专项预案；第 7 章明细每行独立、ROI 定义 + 公式 + 数值、三情景表、结语 ≤ 150 字回扣开场；附录 A1–A4 问卷全文 / 访谈摘要（企业方 ≥ 2）/ 数据表（示例标注）/ 竞品监测 + 样稿全文。

### Step 6 路演（路演设计师）
结构见 `专题/06`。

### Step 7–8 评审与打包
评委任务书附 `rubric.json` band 口径；修改轮优先处理 cap 项（`专题/02` 第 4 节）。打包：授权书模板、原创性声明、数据真实性清单、团队确认清单（替换示例数据 / 补设计稿 / 真人出镜 / 查重自查 / 删标记）、README 命名占位。

- [ ] 4 除封面目录外 ≤ 80 页且在 pageTarget ± 10%；PDF ≤ 30 MB
- [ ] 5 命题回应表行数 = 命题条数，每行量化目标在 KPI 表可找到
- [ ] 6 一手五要素原句；样本 ≥ 384（或有限总体修正）；访谈 ≥ 8；实地 ≥ 1；α / KMO / 有效率已报告
- [ ] 7 示例数据标记覆盖率 100%，数据真实性清单条数 = 标记条数

- [ ] 11 五步链小节齐全；目标市场评分表有打分口径与决胜
- [ ] 12 定位陈述句格式完整，全书 ≤ 6 次且字字一致
