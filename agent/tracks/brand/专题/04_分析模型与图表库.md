# 品牌策划赛道 · 分析模型与图表库

> 图型以 `bizkit.charts` 的 18 种 `type` 为准（`docs/contracts.md` §7.1；data 结构见 `.claude/skills/biz-charts/SKILL.md` §1–2）。规则：结论句决定图型；三个数以内写进句子不画图；同屏定性色 ≤ 4；> 8 类改 `hbar`；每图 `source` 必填；每图后两句读图（形态 / 数值 + 原因 / 含义）。表格类元件（矩阵、清单、SOP）由 Markdown 表承担，渲染器自动编号。
> 数据来源字段只能指向 `01_调研/数据/*.csv`、`03_财务/numbers.json` 的 key 或带文献号的调研笔记位置（`CLAUDE.md` 规则 3）。

## 2. 模型使用口诀（框架是工具不是标题）

PEST 只留 6–8 条且每条写“所以”；SWOT 必接 TOWS 并指向章节；竞品矩阵维度 = 用户决策维度；定位图坐标轴 = 竞品矩阵中区分度最大的两维；品牌屋六行；策略屋一页；信息屋三层；漏斗每层“上一层 × 转化率”并写来源；风险矩阵每行有触发指标数值。误用见 `docs/research/02_国金级材料标准.md` §4.2。
