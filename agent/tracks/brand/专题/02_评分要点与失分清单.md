# 品牌策划赛道 · 评分要点与失分清单

> 官方评分：品牌策划报告 60 分（6 项 × 10，差 1–2 / 中差 3–4 / 中等 5–6 / 好 7–8 / 极好 9–10）+ 展示与答辩 40 分（8 项 × 5）。来源：`knowledge/评分表与扣分细则.md`、`docs/research/01_赛事情报.md` §3.1；细则 PDF https://www.cupk.edu.cn/smxy/upload/resources/file/2026/01/12/110283.pdf 、镜像 https://www.sdssfw.com/static/upload/file/legacy-source/306c297d21-20250905151933833383.pdf（访问 2026-10-25）。总决赛小组评委 3 名（教师 1、企业 2），去高低取平均（`01_赛事情报.md` §3.18）——企业评委占多数，可执行性与预算真实感比学术框架值钱。
> 内部量规 `tracks/brand/rubric.json`：band 60/75/85/92 = 省赛合格 / 国赛入围 / 国银 / 国金。

## 1. 逐项对照

| 官方项（10 分） | 国金（9–10） | 国银（7–8）差在 | 典型失分 → 规避 |
|---|---|---|---|
| 现状分析的准确性 | 问卷 ≥ 384 + 访谈 ≥ 8 + 实地 ≥ 1 并报告 α / KMO / 有效率；品牌资产四维有数据；洞察句完整；交叉分析 ≥ 1；竞品 3–5 家 × ≥ 6 维含自家短板；问题树 ≤ 3；反直觉发现 ≥ 1 | 洞察等于常识；访谈 < 8；竞品只列弱者；企业荣誉 > 5% | “据统计 / 预计将”无来源 → 每数四要素；PEST 堆常识 → 只留直接相关 6–8 条且每条写“所以”；荣誉罗列 → ≤ 5% 并跟“这意味着什么” |
| 定位的正确性 | 五步链每步有表 / 图；定位句格式完整并被第 4、5、7 章原样引用；定位图 ≥ 4 竞品且坐标轴有依据；核心价值双验证两个数字；品牌屋；被否决的备选定位 | 单边验证；评分表同分不决胜；SOM 不与 GMV 对账 | 跳步 → 小节标题即五步名；定位句 > 60 字 / 无支持点 → 按模板重写；各章措辞不一 → 全书 `> ` 引用块 ≤ 6 个字字一致 |
| 元素设计的创意性 | Big Idea 一页（主张 ≤ 12 字 + 视觉锤 + 语言钉 + 推导句）；候选 ≥ 3 含淘汰理由；元素 ≥ 4 类 + 色板字体规范；商标检索结论（类别 + 日期）；延展 ≥ 3 线上 + 1 线下；与 3 竞品差异矩阵；概念测试 | 缺商标检索或差异对照；主张是“国潮 / 焕新”；元素只有名称与 LOGO | 只换 LOGO → 补 IP / 包装 / 听觉 / 宣传语两类以上；视觉锤写清包装、片头、直播间、周边四处复现；口号含“最 / 第一 / 唯一” → 对照 `checks.json.advertisingLawTerms` 改写 |
| 推广与传播的可行性 | 阶段 × 渠道 × 内容总图；KOL 头 / 腰 / 尾 / KOC 数量 × 单价 × 来源；样稿 ≥ 5；线下 ≥ 1 含流程 / 物料 / 预算；动作表 8 列；平台机制说明；关键动作有备选；ICC / 广告法自检表 | 样稿 < 5；动作缺负责人 / KPI；无平台机制 | 全渠道撒网 → 1–2 主渠道占预算 ≥ 60% 并说明；“邀请头部达人” → 分层表 + 刊例年份；线下一句话 → 流程表；KOL 合作 → 自检表写明“#广告 / 合作”标注 |
| 资产保护及风险管理的全面性 | 资产清单 + 注册计划（类别 / 时间 / 费用 / 来源）+ 一致性管理 + 舆情 SOP（分级 + 小时级时限 + 责任角色）+ 风险矩阵 ≥ 6（概率 × 影响 + 对策 + 触发指标）；每条指向第 5 / 7 章；KOL 翻车 / 抢注 / 价格体系专项预案 | SOP 无时限；风险 < 6；对策“加强监测” | 只写商标或只写舆情 → 两者都要；风险模板化 → 每条写触发指标数值（如“竞品同价位 SKU 上架 ≥ 3 个即启动”） |
| 财务预算的合理性 | 预算 = Σ 单价 × 数量，全部单价有来源；机动金 5–10%；≤ 命题上限；与第 5 章动作逐项对账；KPI ≥ 5 行含基线 / 目标 / 工具 / 周期；ROI 有定义公式；单因子敏感性 + 三情景联动；与企业营收规模相称 | 单价来源 < 80%；KPI 无基线；无敏感性 | “其他 ×× 万元”打包 → 逐行拆开；ROI 恰好 110% / 预算恰好用满 → 真实计算值并写口径；百万预算配千万营收企业要说明可承受性 |

## 2. 展示与答辩 40 分（8 × 5）

| 官方项（5 分） | 对应交付物 | 国金做法 | 常见失分 |
|---|---|---|---|
| 内容完整程度 | PPT 18–20 页覆盖 6 个书面项各 ≥ 1 页 | 每页标题是结论句；目录按评分项排 | 跳过保护 / 预算页 |
| 评委提问应答表现 | 题库 ≥ 40、六维度各 ≥ 4、主答人 | 结论 10 秒 → 证据 30 秒 → 行动 10 秒；承认短板并给方案 | 抢答、争辩、> 1 分钟 |
| 论述和决策确认的清晰程度 | 策略屋一页、目标市场评分表、候选对照表 | 讲“为什么不选另两个” | 只讲选了什么 |
| 结论的正确有效性 | 概要数字卡、KPI 表 | 数字与策划书完全一致 | PPT 与书面不一致 |
| 对问题的切题回应度 | 命题回应表 | 先确认问题再答；每答回到命题目标 | 答非所问 |
| 演讲专业程度（含 PPT） | 字号 ≥ 24 pt、≤ 3 色、图表 ≥ 8 | 一页一结论，多图少字 | 整页文字、念稿 |
| 谈吐清晰有条理，举止得体 | 讲稿句长 ≤ 25 字 | 关键数据前停顿 | 口头禅、卡壳 |
| 时间分配与团队配合 | 讲稿时间合计 = 时长 × 92–95%；交接语 ≤ 5 字 | 方案与执行段占比最高 | 前半过长、财务草草；一人独讲 |

## 3. 硬门槛与格式红线

| 红线 | 规则与出处 | 自检 |
|---|---|---|
| 匿名 | 封面与所有页（含附件、PPT、视频、备注、文件属性）不得出现院校名称 / logo / 人员姓名 / 联系方式；每处扣 3 分（`knowledge/评分表与扣分细则.md`；`naming.json.anonymityPenalty`） | `bizkit.checks` 的 `anonymity_hits` = 0 |
| 页数与格式 | A4 竖版 PDF ≤ 30 MB；除封面目录外 ≤ 80 页含问卷附页；中文（`spec.md` §0） | `bizkit.pdf --pages` ≤ 80；pageTarget ± 10% |
| 跨文档一致 | 正文 / PPT / 讲稿 / 题库同一 key 只有一种写法（`rubric.json.hardGates.cross_doc_consistency`） | 数字只从 `03_财务/numbers.json` 取 |
| 广告法 | 最 / 第一 / 唯一 / 顶级 / 国家级 / 100% 等 0 次（`checks.json.advertisingLawTerms`，白名单 `advertisingLawWhitelist`） | `forbidden_terms_adlaw` = 0 |
| 一手数据真实 | synthetic 模式每段带【示例数据，须替换为真实调研结果】；细则禁止“完全使用 AI 工具创作”（第五条第 11 款） | `syntheticMarkerCoverage` = 1.0 |
| 创新与比重 | “务必具有创新性，不可过多陈述企业现有成就和做法”；2022 届细则曾明示“品牌策划比重多于营销推广”（https://jg.qust.edu.cn/system/_content/download.jsp?owner=1754318326&urltype=news.DownloadAttachUrl&wbfileid=7579029 ，访问 2026-10-25） | 荣誉 ≤ 5%（`checks.json.honor_ratio_max`）；第 3+4+6 章页数 ≥ 第 5 章 |

## 4. 机器 cap 速查（`rubric.json.machineCapRules`）

`has_primary_research` fail → 现状 ≤ 2；`has_competitor_matrix` → 现状 ≤ 3；`positioning_statement` → 定位 ≤ 3；`big_idea` → 创意 ≤ 2；`kol_tiers` / `offline_event` → 传播 ≤ 3；`budget_recalc` → 预算 ≤ 2；`kpi_table` → 预算 ≤ 3；`risk_matrix` < 6 行 → 保护 ≤ 2；`struct_coverage` → 规范 ≤ 2；`brief_response_table`（命题企业）→ 契合 ≤ 2。另：无引用位置 ≤ 2；本维度 ≥ 3 个无来源数字 ≤ 3；示例数据未标注 ≤ 2；≥ 2 处套话 ≤ 3。

## 5. 评委三类视角（`rubric.json.judgeFocus`）

投资人问“预算花在哪、首年 GMV 怎么推、企业承受得起吗”；教授问“样本怎么抽、定位图坐标轴依据、引用格式”；企业高管问“达人报价真不真、线下谁执行、商标查了没、翻车怎么办”。写每章时按三问预埋答案。
