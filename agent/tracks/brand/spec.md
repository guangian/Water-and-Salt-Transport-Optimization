# 品牌策划赛道 · 赛道规范（brand）

> 适用：全国高校商业精英挑战赛 品牌策划竞赛——品牌策划赛道（学生组：研究生 / 本科 / 高职）与在华留学生赛道（同一评分表）。本文件规定**品牌策划书**的章节大纲、每章必答、篇幅、评分映射、图表配额与写作要点；流程与通用文风见 `CLAUDE.md`。

## 0. 硬约束（摘自 2026 届实施细则）

| 项 | 要求 |
|---|---|
| 文件 | 品牌策划书 PDF，A4 竖版，中文，≤ 30 MB；**除封面、目录外其他内容总计 ≤ 80 页（含问卷等附页）**；无字数下限（国金作品通常 55–75 页） |
| 对象 | 真实存在的品牌（自选或组委会命题企业）；以“XXX 品牌策划工作室”名义参赛；企业授权书单独提交 |
| 封面 | 只含：作品名称、团队名称、指导企业名称；**不得出现院校名称 / 图片 / logo、人员姓名与联系方式**（内页同样禁止） |
| 创新 | “参赛作品务必具有创新性，不可过多陈述企业现有的成就和做法”；引用资料标明出处；潜在假设阐述清楚 |
| 传播合规 | 推广与传播须遵循《国际商会广告与营销传播实务统一准则（2018 年版）》与《广告法》 |
| 展示 | 总决赛：策划书评审 + 10 分钟 PPT 视频陈述 + 5 分钟实时答辩；3–5 名队员出镜 |
| AI | “严禁抄袭 / 完全使用 AI 工具进行创作”——本系统产出为辅助底稿，团队须替换示例数据并自行修改确认 |
| 查重 | 同校同品牌 4 年只能使用一次；作品不得与在华留学生赛道作品重复 |
| 命名 | 全国预选赛“抽签编号-团队名称-作品名称”；省赛多为“学校名称-团队名称-作品名称”（打包用占位，README 提醒） |

## 1. 官方评分表与章节映射

**第一部分 品牌策划报告 60 分（每项 0–10：差 1–2 / 中差 3–4 / 中等 5–6 / 好 7–8 / 极好 9–10）**

| 评分项 | 分值 | 对应章节 | 评委要看到的证据 |
|---|---|---|---|
| 品牌现状分析的准确性 | 10 | 第 2 章 品牌现状分析 | 外部（宏观 PEST / 行业规模增速结构 / 消费者 / 竞品）+ 内部（品牌资产、产品、渠道、传播、财务）均有数据与来源；一手调研（样本量、方法、发现）；问题树 ≤ 3 个核心问题 |
| 品牌定位的正确性 | 10 | 第 3 章 品牌定位与核心价值 | 五步链：宏微观环境预测 → 市场细分 → 目标市场 → 竞争对手异同（矩阵 + 定位图）→ 独特性与风格；定位陈述句；核心价值的企业 + 顾客双验证 |
| 品牌元素设计的创意性 | 10 | 第 4 章 品牌元素设计 | Big Idea 一页；名称 / 标识 / 符号 / 形象代表或代言人 / 宣传语 / 广告音乐 / 包装 / 域名 ≥ 4 类设计说明 + 色板字体 + 应用场景；商标检索结论 |
| 品牌推广与传播的可行性 | 10 | 第 5 章 品牌推广与传播 | 阶段 × 渠道 × 内容总图；KOL / KOC 分层清单；线下场景 ≥ 1；内容样稿 ≥ 5；每个动作有目标 / 时间 / 负责人 / 预算 / KPI；符合 ICC 准则与广告法 |
| 品牌资产保护及风险管理的全面性 | 10 | 第 6 章 品牌资产保护与风险管理 | 资产清单（商标 / 版权 / 域名 / 外观专利 / 地理标志）+ 注册计划；舆情监测与应急 SOP（含时限）；风险矩阵 ≥ 6 项（概率 × 影响 + 对策 + 触发指标） |
| 财务预算的合理性 | 10 | 第 7 章 财务预算 | 预算 = Σ 单价 × 数量（单价有来源），分阶段 / 分渠道；机动金 5–10%；ROI 或品牌资产回报测算；与传播计划逐项对应 |

**第二部分 展示与答辩 40 分（8 项 × 5）**：内容完整 / 应答表现 / 论述与决策清晰 / 结论正确有效 / 切题 / 演讲专业（含 PPT）/ 谈吐举止 / 时间分配与团队配合 → 由路演 PPT、讲稿、题库承担（见 `pitch-qa` 技能）。

## 3. 写作要点（本赛道特有）

1. **标题范式**：“对仗主标题（8–14 字，含文化 / 情绪意象）——品牌名 + 品牌策划书”，如“宋韵落天青，一釉生万象——弘宝汝瓷品牌策划书”。
2. **现状分析不写颂歌**：企业荣誉 / 现有做法合计 ≤ 5% 篇幅；每个现状结论后面跟“这意味着什么”。
3. **定位五步链不可跳步**，每一步有表或图；定位陈述句单独成段并加粗。
4. **创意可一句话复述**：Big Idea 页能被评委复述；延展到 ≥ 3 个渠道与 ≥ 1 线下场景；与竞品传播主题明确不同。
5. **传播动作可执行**：每条动作五要素（目标 / 时间 / 负责人 / 预算 / KPI）；KOL 预算按刊例或公开报价区间给来源。
6. **预算与传播一一对应**：第 7 章的每一行预算在第 5 章能找到动作；总额与概要、PPT、讲稿一致（账本 `budget_total`）。
7. **年轻化与文化叙事**（获奖高频主题）：非遗 / 农产品 / 地方文旅 / 大健康 / Z 世代情绪价值；但以调研数据证明人群与品牌的契合，而不是套话。
8. **命题企业**：逐条回应命题的目标市场与要求（如“视觉符号策划”“出海日本”），并在概要和第 1 章显式列出“命题要求 → 本方案回应”。
9. **在华留学生赛道**：同一评分表；语言按任务书（中文或英文），英文版把术语对照表放附录。

## 4. 交付清单（本赛道）

品牌策划书 docx + pdf（≤ 80 页）；路演 PPT（18–20 页 + 备用）；10 分钟讲稿；答辩题库 ≥ 40；视频分镜；调研工具包（问卷 / 访谈提纲 / 执行计划 / 示例结果）；预算 Excel（budget 模式）；评审报告与机器检查；提交包（声明模板、授权书模板、数据真实性清单、README）。
