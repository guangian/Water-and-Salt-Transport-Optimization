# 02 评分要点与失分清单（对应官方 100 分表）

> 官方评分表：Part 1 商业计划书 60（创新性 20 / 商业性 30 / 团队架构 10）+ Part 2 展示与答辩 40（陈述 20 / 答辩 20），所有组别同表；2023–2026 届表格文字未变（`docs/research/01_赛事情报.md` §3.4；2026 细则 https://www.cupk.edu.cn/smxy/upload/resources/file/2026/06/10/114001.pdf ；2023 细则 http://jiaowu.web.hebust.edu.cn/docs/2023-05/89a0e0eee74f48a49ed99896be218b69.pdf ，均访问 2026-10-25）。省赛 / 预选赛仅网评 BP，部分院校把书面 60 分折成 100 分（创新 35 / 商业 50 / 团队 15，https://www.cafuc.edu.cn/jwcx/info/1021/1670.htm ，访问 2026-10-25）——书面阶段商业性占一半，先做满。
> 内部量规 `tracks/startup/rubric.json`：10 个书面维度 + 3 个路演维度，先按 bandAnchors 定档（60 / 75 / 85 / 92）再微调；国金 = 92 档。下表"国银差在哪"即 85 档与 92 档的差。

## 1. 创新性 20（rubric：innovation，官方权重 20）
| 项 | 内容 |
|---|---|
| 官方指标 | 原始创意的创新性或技术含量；专业技术 / 方法 / 思维应用于销售、研发、生产、物流、信息、人力、管理 |
| 国金长什么样 | 参数对比表（≥ 2 列竞品，含测试条件）+ 知识产权清单（匿名、含状态）+ 第三方验证（检测 / 试点 / 用户）+ 12–36 月迭代路线 + 壁垒四类各一证据 + 技术被替代的风险评估；创新点可一句话复述 |
| 国银差在哪 | 四件齐但壁垒只有专利一类；无"被替代"评估；创新点记不住 |
| 典型失分 → 规避 | 只讲原理无对比（cap 3）→ 补参数表；"先进 / 领先"无基准 → 换成百分点或倍数；专利写权利人 → 遮盖并注"匿名处理"；模式创新无数据壁垒 → 写数据积累速度与独家协议；非首次参赛无迭代说明 → 迭代创新说明进附录（`outline.json` 默认 A1–A5，需要时在 `book.json` 追加 `A6_迭代创新说明.md`）+ 查重 < 40% |

## 2. 商业性 30（market 8 + competition 6 + bizmodel 8 + marketing 4 + finance 4）
| 官方子项 | 国金长什么样 | 国银差在哪 | 典型失分 → 规避 |
|---|---|---|---|
| (1) 商业模式完整可行 | 画布 + 收入公式 + 四指标 + 行业对标 + 客户 / 付费方 / 使用者三角一致；单位经济来自试点或订单 | 四指标有但无对标，或 LTV:CAC < 3 无解释 | 无单位经济（cap 3）→ 补表；市场 C 端模式 B 端 → 画布与画像对齐 |
| (2) 目标市场与客户定位 | 画像 2–3 个 + 决策链 + 付费意愿数据；痛点 ≤ 4 每条有频率 × 代价 | 画像有、决策链无；付费意愿缺 | 人群用全国人口 → 用统计公报分层数据 |
| (3) 盈利模式清晰 | 假设表 ≥ 10 带来源 + 驱动因子收入 + 三表勾稽 + 盈亏平衡 12–36 月 + 三情景 / 敏感性 + 融资三件套一致 + ≥ 2 估值法 + 悲观情景现金最低点 + 融资额 ≥ 0 | 敏感性因子 < 3 或估值单法 | 等差 / 等比、首年盈利、融资额 ÷ 投后 ≠ 出让（cap 2）→ 改 `assumptions.json` 重跑，不手改 |
| (4) 营销与渠道可操作 | 漏斗各层转化率 + 来源 + 渠道预算 + 12–36 月甘特 + 已完成事项（带日期）+ 首年收入拆到渠道 × 客户 × 单价与财务对账 + 1–2 个主渠道聚焦论证 | 转化率无来源；甘特 < 12 月 | 全渠道空谈（cap 3）→ 砍到主渠道 1–2 个并给 CAC |
| (5) 行业调研与一手资料 | 样本 ≥ 384 + 五要素（样本量 / 时间 / 地点 / 方法 / 有效率）+ 访谈 ≥ 8 + α / KMO + 双法 TAM/SAM/SOM 调和 + SOM 与首年收入可对账 | 双法未调和；无访谈 | 无一手调研（cap 2）；示例数据未标注（cap 2）→ 段首加【示例数据，须替换为真实调研结果】 |
| (6) 竞争对手分析 | 3–5 家 × 5–8 维（用户维度，含来源）+ 定位图 + 自身短板 ≥ 1 与应对 + 替代方案 + "大公司进来"时间窗口论证 | 无短板；竞品数据过期 | 声称无竞争者（cap 2）→ 至少列替代方案 |

## 3. 团队架构 10（team，官方权重 10）
- 国金：背景 – 分工 – 成果三栏（匿名角色化）+ 组织架构 + 股权表（合计 100%、创始团队 > 51%、法定代表人 ≥ 10%）+ 缺口与补齐 + 成员经历与里程碑对应 + 期权池 / 顾问 + 全职承诺（匿名表述）。
- 国银差在哪：三栏齐但缺口与里程碑脱节；无期权池。
- 失分 → 规避：头衔罗列 → 每人一条"已交付成果 + 日期"；无股权表（cap 3）→ 补现状 + 本轮后两列；导师 / 院校持股 → 注明比例与理由或改为顾问；写姓名 / 院校 → 匿名扫描（`checks.json.anonymityRegex`）。

## 4. 项目展示陈述 20（deck 50 / script 25）
- 国金：22 页左右（20–24，备用 ≤ 4）、一页一结论句、每页 ≥ 1 数字、图表 ≥ 8、抽查数字与 `numbers.json` 一致、开场钩子 + 结尾回扣、note 为可讲的判断句；讲稿 1 650–1 950 字、前 150 字钩子、首句结论 ≥ 80%、方案 / 牵引力段占比最高。
- 国银差在哪：标题是名词短语；念 PPT；时间平均分配。
- 失分 → 规避：PPT < 20 页或省赛 PDF < 3 000 字扣 3 分（`naming.json.deckMinPages / anonymityPenalty`）、超时 1–3 分、院校信息每处 3 分、视频出镜 < 3 或 > 5 人扣 3 分（`01_赛事情报.md` §3.17）→ 用 `06` 骨架与 `05` §3 自检表第 5 条。

## 5. 答辩 20（qa 25）
- 国金：题库 ≥ 40、六维度各 ≥ 4、三段式（结论 10 秒 / 证据 30 秒 / 行动 10 秒）+ 主答人 + 尖锐题 ≥ 8 + 每题证据引用 `numbers.json` 或正文位置 + "承认短板并给方案"题 ≥ 3。
- 失分 → 规避：答非所问、与评委争辩、单答 > 60 秒、数字与 BP 不一致 → 先确认问题，先结论，数字只说账本里有的。

## 6. 硬门槛与格式红线（任一失败：规范类维度 ≤ 2，verdict 首句写"硬门槛未过"）
| 门槛 | 规则 | 出处 |
|---|---|---|
| 匿名 | 封面、正文、页眉页脚、图片、PPT 母版与备注、讲稿、证书扫描件均不得出现院校名称 / logo / 姓名 / 联系方式；命中扣 3 分 | 细则 §十（二）；`checks.json.anonymityRegex` |
| 页数 / 字数 | 除封面目录外 ≤ 80 页（含问卷、证明材料）；≥ 3 000 字；A4 竖排 PDF | 细则；`checks.json.pageLimit / wordMin` |
| 字体 | 中文正文宋体小四、英文 Times New Roman 小四 | `track.json.font` |
| 封面 | 仅竞赛组别 / 团队名称 / 项目名称三项，其他信息均不出现 | `naming.json.coverFields` |
| 命名 | "参赛组别-学校名称-团队名称-商业计划书名称"；声明"…-声明及授权书"（学校名由团队提交时填） | `naming.json` |
| 跨文档一致 | 同一 key 的数字在正文 / PPT / 讲稿 / 题库只能有一种写法 | rubric `cross_doc_consistency` |
| 融资一致 | 出让比例 = 融资额 ÷ 投后（±1 pp）；资金用途合计 100% | rubric `financing_consistency` |
| 禁语 / 广告法 | 颠覆、独一无二、蓝海、据统计、预计将…… 0 次；最佳 / 第一 / 唯一 / 100% 等绝对化用语 0 次 | `checks.json.forbiddenTerms / advertisingLawTerms` |
| 组别资格 | 创业组：运营 ≥ 3 月、注册 < 3 年、融资 ≤ 天使轮、申报人为股东；创客组：未注册；非首次参赛：再创新 ≥ 60%、查重 < 40% 并附迭代说明 | `01_赛事情报.md` §2.5 |
| 真实性 | 抄袭、虚假材料、完全 AI 生成 → 取消资格；示例数据必须标注并进入《数据真实性清单》 | 细则 §四；`CLAUDE.md` 规则 4 |

## 7. 评委视角速记（judgeFocus）
投资人看 market / bizmodel / finance / team：先翻执行摘要的融资三件套与 SOM，再翻假设表。教授看 structure / competition / innovation / style：先看 13 章是否齐、竞品矩阵来源、参考文献格式。企业高管看 marketing / risk_social / innovation：先看首批客户从哪来、风险有没有触发指标。每章首段结论句先答这三问。
