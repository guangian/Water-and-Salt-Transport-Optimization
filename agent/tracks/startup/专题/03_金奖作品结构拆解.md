## 2. 章节结构、页数分配与每章必备元件（60 页目标 / 80 页上限；40 页版按比例缩放）
| 章 | 页 | 必备元件（图 / 表 / 模型） | 记忆点 |
|---|---|---|---|
| 0 执行摘要 | 2–3 | 8 要素一页表；关键数字卡（SOM / Y1·Y3 收入 / 盈亏平衡月 / 融资额·出让）；最硬证据一句 | 首句即 ≤ 40 字定位句；第 2 句就是最硬证据 |
| 1 背景与痛点 | 4–6 | 痛点 – 现有方案 – 本方案表；政策依据表（文号 / 机关 / 条款 / 影响）；三窗口时间线；命题组加"命题回应表" | 一句量化痛点（谁 / 频率 / 代价） |
| 2 产品与技术 | 8–10 | 产品架构图；参数对比表（≥ 2 竞品 + 测试条件）；技术路线 `gantt`；知识产权清单；验证证据表 | 核心指标领先幅度（百分点 / 倍数） |
| 3 创新点与壁垒 | 2–3 | 创新点 – 证据 – 可验证方式表；壁垒 `radar`（专利 / 数据 / 工艺 / 渠道 + 维持期） | 三句创新点，每句一个量化差异 |
| 4 市场分析 | 8–10 | 规模 `stacked_bar`；TAM/SAM/SOM `funnel` + 双法测算表；画像表；决策链 `funnel`；一手调研样本结构表 + 发现图 | SOM 区间 + 首年份额门槛一句；洞察句引用块 |
| 5 竞争分析 | 3–4 | 竞品矩阵 3–5 × 5–8（含来源行）；`positioning_map`；五力表 | 赢在哪两维、输在哪一维 |
| 6 商业模式 | 5–6 | `bmc`；收入流与定价表；单位经济表（四指标 + 公式 + 对标）；获客 `funnel` | 收入公式一句 |
| 7 营销与渠道 | 4–5 | 渠道矩阵与预算表（单价 / 量 / 来源）；获客漏斗；营销日历 `gantt`；复购 / 转介绍机制 | 主渠道与 CAC 一句 |
| 8 运营与实施 | 3–4 | 里程碑 `gantt`（已完成项打勾）；已完成事项表（日期 / 证据）；供应链 / 产能 / 质控表 | 已完成的三件事（带日期） |
| 9 团队与组织 | 3–4 | 三栏团队表；组织架构表；股权 `pie_as_bar`（现状 + 本轮后）；缺口与补齐 | 人 – 事匹配一句 |
| 10 财务与融资 | 8–10 | 关键数字卡；假设表 ≥ 10；收入驱动表；三表 5 年摘要；`breakeven`；`cashflow_combo`；`tornado` / 三情景表；估值区间表；资金用途 `pie_as_bar`；融资一致表 | 三年收入 / 盈亏平衡月 / 现金最低点一句 |
| 11 风险与对策 | 2–3 | 风险矩阵 ≥ 6（概率 / 影响 / 触发指标 / 对策 / 责任角色） | 最大的三个风险一句 |
| 12 社会价值与成长 | 1–3 | 价值计量表（指标 / 口径 / 数值）；团队成长三例；`## 结语` ≤ 150 字 | 结语回扣定位句与开场数字 |
| 附录 A1–A6 | 3–12 | 问卷、访谈摘要、调研数据表、财务明细（首年月度）、证明材料清单（匿名说明）、迭代创新说明（非首次参赛） | 附录与正文引用一一对应 |

页数规则：章节合计 = pageTarget × 0.85，附录 = 0.15；每章先扣 0.5 页标题空白，再扣图 0.45 页 / 张、表 0.15 页 + 0.06 页 / 行（`CLAUDE.md` Step 0 动作 1.7）。市场与财务两章合计约 30%，是篇幅与数字密度（≥ 25 / 千字）最高处；全书图表 ≥ 15（常态 25–40），每章 ≥ 1 图 1 表。

## 3. 记忆点设计（评委读完只记得一句主张和三五个数字）
1. **一句话定位**：为谁 / 解决什么 / 怎么做 / 凭什么赢，≤ 40 字；在概要首句、第 2 章章首、第 6 章画布说明、第 10 章小结、第 12 章结语、PPT 封面与结尾共出现 ≤ 6 次，措辞一致（`outline.bookGuide.thread`）。
2. **最硬证据**：订单 / 专利 / 检测报告 / 试点数据 / 用户数中选 1 个，概要第 2 句、路演第 2 页、答辩第 1 题都用它。
3. **关键数字卡**（全书同一写法）：SOM、Y1 / Y3 收入、毛利率、盈亏平衡月、现金最低点、融资额 · 出让 · 投后。概要页与财务章首各放一次，PPT 用 `kpi` 版式放一次。
4. **章首结论句 + 章末小结 + 跨章引用**：第 4 章 SOM → 第 10 章销量上限；第 6 章单位经济 → 第 10 章假设表；第 7 章渠道预算 → 第 10 章营销费；第 8 章里程碑 → 第 10 章资金用途与跑道；第 10 章敏感性 → 第 11 章风险对策。评委任一章单独读都能回到同一组数字（rubric structure 92 档）。
5. **一图表两读图**：图下一句形态 / 数值，一句含义；无读图句的图删掉。
6. **命题组记忆点**：命题回应表（命题要求 / 对应章节 / 关键举措 / 可量化目标）在第 1 章原样出现，第 12 章回收"命题目标达成度"。

## 4. 国银与国金的三处可见差异
- 国银：要素齐全、数字有来源，但 SOM 与首年收入对不上、单位经济无对标、风险无触发指标。
- 国金：跨章数字零矛盾；每个数字能追到表号 / 图号 / 文献号 / `numbers.json` key；创新点一句话复述后能被参数表验证。
- 做法：写完全书用 `bizkit.checks` 的 `cross_doc_consistency` 与评委 `evidenceRequired` 清单逐条定位，缺一项不交。
