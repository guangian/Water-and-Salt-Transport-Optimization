# 04 分析模型与图表库（按章对应 bizkit.charts 图型）

> 图型与 `data` 字段以 `.claude/skills/biz-charts/SKILL.md` 与 `docs/contracts.md` §7.1 为准（`type` ∈ bar / grouped_bar / stacked_bar / hbar / line / area / pie_as_bar / donut / waterfall / funnel / tornado / breakeven / cashflow_combo / scatter_matrix / positioning_map / gantt / radar / bmc）。硬规则：每图 `source` 必填；纵轴从 0 起；同屏定性色 ≤ 4；> 8 类改 `hbar`；三个数以内写进句子不画图；图内不写标题。表格由主笔用 Markdown 写，不进 charts.json。
> 读图句模板：**句 1 形态 / 数值**（"X 从 A 升至 B，占比 C%"）+ **句 2 含义 / 动作**（"因此本方案在第 N 章……"）。

## 1. 配额与来源写法
- 全书 ≥ 15 张图（`checks.json.chartMin`），常态 25–40；每章 ≥ 1 图 1 表；市场、财务两章各 ≥ 6 图表。
- 财务类图由 `bizkit.finmodel` 生成的 `03_财务/财务图表.charts.json` 直接并入需求单，`source` 写"资料来源：本方案财务模型（03_财务/财务模型.xlsx）"。
- 调研类图 `source` 写"资料来源：本团队 2026 年 N 月问卷（n = ×××）；示例数据，须替换"；二手数据写"机构《报告》年份 [文献号]"。

## 2. 按章推荐（模型 → 图型 → data 要点 → 读图句模板）
| 章 | 模型 | 图型 | data 要点 | 读图句模板 |
|---|---|---|---|---|
| 0 概要 | 8 要素表 / 关键数字卡 | 表（不画图） | — | 数字与各章完全一致 |
| 1 痛点 | 痛点频率 × 代价；三窗口 | `hbar`（sort:true） | categories = 痛点或替代方案，values = 提及率 / 年损失 | "71% 的受访厂商把 X 列为首要痛点，年损失 Y 万元；因此第 2 章核心功能 1 对应 X" |
| 1 痛点 | 政策 / 技术 / 需求窗口 | `line`（≤ 4 条） | categories = 年份，series = 渗透率 / 成本 / 政策数 | "技术成本 5 年下降 N%，跨过可商业化阈值；窗口在 20XX–20XX" |
| 2 产品 | 参数对比 | 表（本品 vs ≥ 2 竞品 + 测试条件 + 出处） | — | "核心指标领先 N 个百分点 / N 倍，测试条件为 …" |
| 2 产品 | 技术路线 / 迭代 | `gantt` | tasks[{name,start,end,group}], milestones[] | "12 个月内完成 3 个版本，第 N 月交付 X 功能" |
| 2 产品 | 多指标对比 | `grouped_bar` | categories = 指标，series = 本品 / 竞品 A / B | "5 项指标中 3 项领先、2 项持平，短板为 X" |
| 3 创新 | 壁垒四类评分 | `radar`（axes ≥ 3） | axes = 专利 / 数据 / 工艺 / 渠道 / 成本，series = 本品 / 主要竞品 | "本品在数据与渠道两轴领先，工艺轴持平；维持期 N 年" |
| 4 市场 | 规模与结构 | `stacked_bar` / `area` | categories = 近 5 年 + 预测 3 年（E 标注），series = 细分 | "规模由 A 增至 B，CAGR N%；细分 X 占比从 … 升至 …" |
| 4 市场 | TAM/SAM/SOM | `funnel` | stages[{name,value}] 三级 + 表（双法并列） | "SAM 取两法中值 X 亿元；SOM 首年 N% ≈ Y 万元，是财务章销量上限" |
| 4 市场 | 决策链 / 画像 | `funnel`；表 | stages = 认知 → 试用 → 付费 → 复购 | "从认知到付费转化 N%，卡点在 X 环节" |
| 4 市场 | 一手调研发现 | `bar` / `hbar`；`donut`（≤ 4 类） | categories = 选项，values = 比例 | "n = 384 中 N% 愿为 X 付费 Y 元以上（示例数据）" |
| 5 竞争 | 竞品矩阵 | 表 3–5 × 5–8（含来源行） | — | "我们赢在 A、B 两维，输在 C 维" |
| 5 竞争 | 定位 | `positioning_map` | xAxis{low,high}, yAxis{low,high}, points[{name,x,y,self}] | "本品落在 X 高 / Y 低象限，与竞品 A 错位" |
| 5 竞争 | 份额 × 增速 | `scatter_matrix` | xLabel,yLabel, points[{name,x,y,size,self}], quadrants[] | "头部两家合计 N%，但增速最高的是本品所在象限" |
| 6 模式 | 商业模式画布 | `bmc` | 九格各数组（每格 ≤ 4 条） | "价值主张对应客户细分 X；收入来自 Y、Z 两流" |
| 6 模式 | 单位经济 | 表（CAC / LTV / 毛利率 / 回收期 + 公式 + 对标） | — | "LTV:CAC = N，高于基准 3；回收期 M 月" |
| 6 / 7 | 获客漏斗 | `funnel` | stages = 触达 → 线索 → 试用 → 付费 | "各层转化率 a/b/c（来源）；CAC = 营销费 ÷ 付费数 = X 元" |
| 7 营销 | 渠道预算结构 | `pie_as_bar`（> 4 类）/ `donut` | categories = 渠道，values = 预算 | "主渠道 A、B 占预算 N%，对应首年获客 M 个" |
| 7 营销 | 首年营销日历 | `gantt` | tasks 按渠道 / 活动，milestones = 节点 | "前 6 个月聚焦 A 渠道，第 7 月起启动 B" |
| 8 运营 | 里程碑 | `gantt`（已完成项用 group = "已完成"） | tasks 12–36 月，milestones = 融资 / 交付节点 | "已完成 3 项（日期），未来 18 个月 5 个节点与资金用途对应" |
| 9 团队 | 股权结构 | `pie_as_bar` | categories = 持股人角色 + 期权池，values 合计 100 | "创始团队合计 N%，法定代表人 M% ≥ 10%" |
| 10 财务 | 收入结构 | `stacked_bar` | categories = 5 年，series = 收入流 | "Y1 → Y5 收入 A → B 万元，X 流占比升至 N%" |
| 10 财务 | 收入与净利 | `line` | series = 收入 / 净利润 / 毛利率（右轴） | "第 2 年转正，Y3 净利率 N%" |
| 10 财务 | 现金流 | `cashflow_combo` | categories = 首年月或 5 年，values + cumulative | "累计现金最低点 −X 万元在第 M 月，融资 Y 万元覆盖并留安全垫 Z" |
| 10 财务 | 盈亏平衡 | `breakeven` | fixedCost, unitPrice, unitVarCost | "保本销量 N 件 / 条，对应第 M 月；安全边际 K%" |
| 10 财务 | 敏感性 | `tornado` | base + items[{name,low,high}]（≥ 5 因子，±15 / 30%） | "单价与销量最敏感，CAC 其次；因此第 11 章风险 1、2 对应" |
| 10 财务 | 成本 / 资金桥 | `waterfall` | items[{name,value,total}] | "收入 X 减各项成本后净利 Y；最大成本块为 Z" |
| 10 财务 | 资金用途 | `pie_as_bar` / `donut`（≤ 4 类） | categories = 用途，values 合计 = 融资额 | "研发 / 市场 / 运营 N/N/N%，分别对应里程碑 …" |
| 10 财务 | 估值区间 | 表（方法 / 结果 / 参数 / 取值） | — | "≥ 2 法区间 A–B 万元，取 C；出让 = 融资额 ÷ 投后" |

## 3. 常见图表错误（评委一眼能看出）
- 收入柱子等高差 / 等比（等差 / 等比增长）→ 用首年按月 S 型，年增速差异 > 5 pp。
- 饼图 > 4 类或双饼并排 → `pie_as_bar`。
- 定位图只有自己一个点或维度是"质量 / 服务"这类无法度量的词 → 维度来自调研 Top 看重因素，点 ≥ 4。
- 漏斗没有转化率标注或来源 → stages 用绝对值，读图句写比例与来源。
- 甘特只有未来没有过去 → 已完成项打勾并带日期。
- 龙卷风只有 2–3 个因子 → ≥ 5 因子（单价 / 销量 / 成本率 / CAC / 固定成本）。
- 图题含"示意图""如图所示"或图内带校名水印 → 图题写结论，水印清理。
