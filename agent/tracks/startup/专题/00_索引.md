# 创业计划赛道 · 专题包索引（startup）

> 用法：主代理在 Step 0 只读本索引；其余文件按下表「阶段 / 角色」定点读，每份只读一次。本包只补充赛道特有做法，通用流程仍以 `CLAUDE.md` 为准，章节大纲以 `spec.md` / `outline.json` 为准。

## 文件一句话

| 文件 | 用途 |
|---|---|
| `01_赛道方法论.md` | 7 个核心框架（痛点验证链、创新证据四件套、双法 TAM/SAM/SOM、商业模式画布 → 单位经济、驱动因子财务、壁垒与竞争应对、团队–里程碑匹配）的用法、输入、输出、误用与示例 |
| `02_评分要点与失分清单.md` | 官方 20/30/10 + 20/20 逐项拆解：国金长什么样、国银差在哪、典型失分与规避动作；硬门槛与格式红线 |
| `03_金奖作品结构拆解.md` | 13 章 + 附录的页数分配、每章必备元件、记忆点设计、历届获奖作品题材与命名特征（含来源） |
| `04_分析模型与图表库.md` | 每章推荐模型与 bizkit 图型（含 data 字段与读图句模板），BP 图表 ≥ 15 张的配额表 |
| `05_工作流与自检表.md` | 相对通用流程本赛道「必须多做 / 必须不同」的动作（研究员数据源、策略产出、startup 财务模式特有表、写手落点、路演结构）+ 提交前 28 条自检 |
| `06_路演与答辩题库.md` | 10 分钟 22 页版式骨架、讲稿节奏、评委最常问 20 题与应答要点 |

## 谁在哪个阶段读哪一份

| 阶段（CLAUDE.md Step） | 角色 | 读 | 取什么 |
|---|---|---|---|
| Step 0 读题解析 | 主代理 | `00_索引` → `02` 的「硬门槛与红线」「评分映射」 | 评分映射表、组别判定（创业 / 创客 / 命题 / 留学生）、命题回应表骨架 |
| Step 1 调研 | 研究员 A–D、消费者洞察 | `05` §1 研究员条目；`01` §1、§3 | 数据源清单（专利 / 招股书 / 行业协会 / 惠州政策）、一手调研五要素、付费意愿题 |
| Step 2 策略 | 主代理 | `01` 全文；`03` §3 记忆点 | 一句话定位、画布九格、收入公式、壁垒四类、各章结论句 |
| Step 3 财务 | 财务建模师 | `01` §5；`05` §1 财务条目；`04` 第 10 章条目 | startup 模式特有表（假设表 ≥ 10、三情景、估值 ≥ 2 法、融资三件套）与穿帮清单 |
| Step 4 图表 | 制图员 | `04` 全文 | 图型选择、data 字段、来源写法 |
| Step 5 撰写 | 主笔 | `03` §2 对应章；`02` 对应评分项；`04` 读图句模板 | 每章必备元件、落点句、失分规避 |
| Step 6 路演 | 路演设计师 | `06` 全文；`03` §3 | 页面骨架、讲稿节奏、20 题应答 |
| Step 7 评审 | 质检员 / 三评委 | `02` 失分清单；`05` §3 自检表 | 对照国金 / 国银锚定找证据缺口 |
| Step 8 打包 | 主代理 | `05` §3 自检表 | 逐条打勾写入交付摘要 |
