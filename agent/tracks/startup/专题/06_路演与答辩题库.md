# 06 路演与答辩题库（10 分钟陈述 + 5 分钟答辩）

> 规则：总决赛线上陈述 + 答辩（视频开头 3–5 名队员真人出镜）；精英赛现场 10 + 5 分钟，PPT ≥ 20 页且 Office 365 兼容；超时 1–5 分钟内扣 1 / 1.5 / 2 / 2.5 / 3 分；透露院校信息扣 3 分（`docs/research/01_赛事情报.md` §2.5、§3.17）。页数区间 20–24、备用页 ≤ 4、讲稿 1 650–1 950 字、题库 ≥ 40 题六维度各 ≥ 4（`checks.json.pitch`）。讲稿与题库格式见 `.claude/skills/pitch-qa/SKILL.md`；版式字段见 `pptx-deck` 技能。

## 2. 讲稿节奏（10 分钟 ≈ 1 750 字，排练到 9:15–9:30）
| 段 | 时间 | 字数 | 要点 |
|---|---|---|---|
| 开场钩子 + 定位 | 0:00–0:50 | 150 | 40 秒内场景或数字 + 一句定位；不自我介绍院校 |
| 痛点与方案 | 0:50–2:30 | 300 | 痛点 ≤ 3、方案三点、每句一个数字 |
| 产品 / 创新 / 壁垒 | 2:30–4:00 | 270 | 参数对比 + 验证证据；"为什么是现在"一句 |
| 市场 / 客户 / 竞争 | 4:00–5:40 | 300 | SOM、一手数据、矩阵各一句结论 |
| 模式 / 牵引 | 5:40–7:10 | 270 | 单位经济四数 + 已完成三件事（最有说服力处放中段偏后） |
| 财务 / 融资 | 7:10–8:10 | 180 | 三年收入、毛利率、盈亏平衡月；融资只讲金额 / 比例 / 用途 |
| 团队 / 社会价值 | 8:10–9:10 | 180 | 人 – 事匹配；就业口径一句 |
| 结尾 | 9:10–9:40 | 90 | 回扣定位句 + 12 个月后的数字画面 |
规则：时间不平均分，方案与牵引力占比最高；每页只讲页面上没有的判断句；关键数字前停顿 1–2 秒；多人交接语 ≤ 5 字；示例数据段末尾加"（示例数据，须替换）"。

## 3. 评委最常问的 20 题与应答要点（结论 10 秒 → 证据 30 秒 → 行动 10 秒；主答人按维度）
| # | 维度 | 问题 | 应答要点（证据指向） |
|---|---|---|---|
| 1 | 技术与壁垒 | 核心创新点与现有方案的本质区别？ | 参数表领先幅度 + 原理一句 + 第三方验证（第 2 章表号） |
| 2 | 技术与壁垒 | 大公司进来怎么办？别人为什么做不了？ | 壁垒四类各一证据 + 维持期 + 触发指标与应对（第 3 / 11 章） |
| 3 | 技术与壁垒 | 知识产权归属？是否来自导师或学校？ | 权属与授权范围，匿名口径只说"团队成员为发明人、已取得授权" |
| 4 | 技术与壁垒 | 产品成熟度？有没有测试或用户数据？ | 成熟度等级 + 测试报告 + 试点数据（附录 A5 编号） |
| 5 | 市场与数据 | 市场规模怎么算的？SOM 依据？ | 双法 + 关键比例来源 + 调和差异 + SOM 约束条件（第 4 章表号） |
| 6 | 市场与数据 | 一手调研怎么做的？样本够吗？ | 五要素 + 有效率 + 3 条发现；示例数据则说明替换计划 |
| 7 | 市场与数据 | 目标客户是谁？谁付钱、谁使用、谁决策？ | 三角关系 + 决策链漏斗 + 画像数据 |
| 8 | 市场与数据 | 客户愿付多少钱？依据？ | 付费意愿调研 / 试点成交价 / 竞品价格带三点 |
| 9 | 市场与数据 | 最主要的竞争对手？你们赢在哪、输在哪？ | 矩阵 2 个领先维度 + 1 个短板及弥补时间表 |
| 10 | 商业模式与财务 | 怎么赚钱？第一年 100 万怎么来？ | 收入公式 + 首年拆到渠道 × 客户 × 单价 + 已签 / 意向对账 |
| 11 | 商业模式与财务 | CAC、LTV、毛利率、回收期各多少？ | 四个数 + 公式 + 行业对标（`numbers.json` cac / ltv） |
| 12 | 商业模式与财务 | 毛利率为什么这么高 / 低？ | 成本结构表 + 同行对比文献号 |
| 13 | 商业模式与财务 | 何时盈亏平衡？现金最低点？融不到钱怎么办？ | 保本月 + 最低点 + 低配情景（成本 / 节奏）+ 替代资金来源 |
| 14 | 商业模式与财务 | 融资多少、出让多少、估值怎么来？ | 三件套一致 + ≥ 2 种估值法区间 + 可比公司 |
| 15 | 商业模式与财务 | 悲观情景下项目还活着吗？ | 主因子 −30% 结果 + 现金最低点 + 应对动作 |
| 16 | 团队与资源 | 为什么是你们？缺什么人、怎么补？ | 三栏表人 – 事匹配 + 缺口岗位 + 期权池 / 顾问 |
| 17 | 团队与资源 | 股权怎么分？毕业后继续做吗？ | 股权表 + 分配原则 + 法定代表人 ≥ 10% + 全职承诺（匿名） |
| 18 | 运营与执行 | 已完成最重要的三件事？下一步 12 个月？ | 日期 + 证据；里程碑三节点与资金用途对应 |
| 19 | 运营与执行 | 供应链 / 产能 / 交付怎么保证？ | 供应商清单 + 产能爬坡 + 备选方案 |
| 20 | 风险与合规 | 最大的三个风险？资质 / 数据 / 行业准入齐了吗？ | 风险矩阵前三 + 触发指标 + 预案；证照清单与办理进度 |
尖锐题补充（题库必含 ≥ 8）：示例数据如何替换为真实调研；最大短板是什么；竞品免费怎么办；政策变化怎么办；外部指导者在项目中的角色（匿名表述）；为什么不先做小一点；现金只够 6 个月怎么办；一句话让评委记住什么。
应答纪律：先确认问题再先结论；数字只说账本有的；承认短板并给方案；不与评委争辩；单题 ≤ 60 秒；不知道就说"这个数据我们没有掌握，赛后补充"。
