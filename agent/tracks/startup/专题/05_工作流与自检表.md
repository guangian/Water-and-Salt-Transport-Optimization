## 2. 本赛道三条红线动作
1. **数字只认账本**：正文 / PPT / 讲稿 / 题库的财务与市场数字全部来自 `03_财务/numbers.json`；要改数字只改 `assumptions.json` 重跑。
2. **一手资料必须可见**：问卷原件、样本结构表、访谈摘要进附录；示例数据标记 100% 覆盖并进《数据真实性清单》。
3. **匿名到证书**：专利 / 软著 / 执照扫描件遮盖权利人与地址，附录 A5 写"匿名处理说明"；PPT 母版与文件属性作者栏清空。

## 3. 提交前自检表（28 条，逐条打勾写入交付摘要）
**合规（8）**
- [ ] 1 匿名扫描 0 命中（正文、页眉页脚、图片、PPT 备注、讲稿、证书）
- [ ] 2 除封面目录外 ≤ 80 页；≥ 3 000 字；A4 竖排 PDF
- [ ] 3 宋体小四 / Times New Roman 小四；封面仅组别 / 团队名 / 项目名
- [ ] 4 文件命名按 `naming.json`，学校名占位已在 README 说明
- [ ] 5 PPT 20–24 页（备用页 ≤ 4）；讲稿 1 650–1 950 字；视频分镜开头 3–5 人出镜
- [ ] 6 禁语 0、广告法绝对化用语 0、套话 0、弱评价词 ≤ 0.1 / 百字
- [ ] 7 组别资格条件已核对并写入团队确认清单（创业组执照 / 股权；非首次参赛迭代说明 + 查重）
- [ ] 8 示例数据标记 100%，条数 = 《数据真实性清单》条数
**创新性（4）**
- [ ] 9 参数对比表 ≥ 2 列竞品，含测试条件与出处
- [ ] 10 知识产权清单含申请号 / 状态，无权利人与院校
- [ ] 11 第三方验证证据（检测 / 试点 / 订单 / 用户）≥ 1 条带日期
- [ ] 12 迭代路线 12–36 月；壁垒四类各一证据 + 维持期
**商业性（10）**
- [ ] 13 痛点 ≤ 4，每条频率 × 代价 + 现有方案缺陷；付费意愿数据点存在
