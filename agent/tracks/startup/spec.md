# 创业计划赛道 · 赛道规范（startup）

> 适用：全国高校商业精英挑战赛 创新创业竞赛——创业计划赛道（命题组 / 创业组 / 创客组 / 在华留学生组），以及智慧文旅创新创业赛项（同一评分表）。同一份商业计划书稍作改写即可用于中国国际大学生创新大赛（原互联网+）与挑战杯（见 §3.8 跨赛复用）。

## 0. 硬约束（摘自 2026 届实施细则）

| 项 | 要求 |
|---|---|
| 文件 | 商业计划书 PDF，A4 竖排，**不少于 3000 字**，除封面、目录外 ≤ 80 页（含问卷等附页）；**中文正文宋体小四，英文正文 Times New Roman 小四**；省赛另要求配套 PPT ≥ 20 页（否则扣 3 分） |
| 封面 | 单独设计封面与目录并与正文合为一份 PDF；封面仅含 ①竞赛组别 ②团队名称 ③项目名称，其他信息均不出现 |
| 匿名 | 计划书与 PPT 不得出现院校名称、logo、联系方式（扣分） |
| 组别 | 创业组：已运营 ≥ 3 个月、注册未满 3 年、融资不超过天使轮、申报人为股东（需营业执照、股权结构）；创客组：未注册、有原型 / 模式；命题组：围绕《惠州市“十五五”规划建议》与命题方向；留学生组：中 / 英文 |
| 项目类型 | 新经济、高科技、泛娱乐三大类 |
| 原创 / 查重 | 原始创新；非首次参赛需再创新 ≥ 60%、BP 查重 < 40% 并附迭代说明 |
| 展示 | 总决赛：线上陈述 + 答辩（视频开头 3–5 名队员真人出镜）；精英赛：10 分钟现场陈述 + 5 分钟答辩，PPT ≥ 20 页（Office 365 兼容） |
| 命名 | “参赛组别-学校名称-团队名称-商业计划书名称” |

## 3. 写作要点（本赛道特有）

1. **执行摘要是最先被读的 3 分钟**：一句话定位 + 最硬证据 + 融资三件套，评委据此决定态度。
2. **一手资料是明文评分点**：问卷 ≥ 384 份（或有限总体修正）、访谈 ≥ 8 人、实地 / 试点记录；示例数据必须标注（synthetic 模式）。
3. **创新要可量化**：参数对比表、第三方验证；知识产权写申请号 / 授权号但隐去权利人（匿名）。
4. **财务三大穿帮零容忍**：等差 / 等比增长、永远盈利、融资额与估值不匹配；收入必须由驱动因子推出，三表勾稽，悲观情景仍存活。
5. **团队角色化**：匿名制下不写姓名院校，用“CEO / 技术负责人（材料学博士在读，持有 X 项专利）”这类角色 + 证据的写法。
6. **命题组（惠州）**：逐条对应《惠州市“十五五”规划建议》与命题方向（两业融合 / 人工智能+ / 外贸新业态），给出平台载体与可操作路径，并在第 1、12 章显式写“命题要求 → 本项目回应”。
7. **创业组**：真实经营数据（收入、用户、融资）与股权结构（法定代表人 ≥ 10%、团队合计 ≥ 1/3）；**创客组**：原型 / 测试 / 预订单证据。
8. **跨赛复用**：国创赛需增加“个人成长 / 产业价值”；挑战杯需加“实践过程 / 社会价值”——第 8、12 章已预留。
