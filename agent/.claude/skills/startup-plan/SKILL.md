# startup-plan：把一个想法写成评委能验证的生意

## 0. 分工
- **本技能**：画布与价值主张、创新 / PMF 证据、壁垒、运营里程碑、团队与股权、融资三件套与退出的**写法与证据要求**；各章落点见 `tracks/startup/专题/01_赛道方法论.md`、`03_金奖作品结构拆解.md`。
- **market-sizing**：TAM/SAM/SOM 双法与调和、PEST / 五力 / 竞品矩阵 / 画像——本技能只规定"SOM 必须成为财务销量上限"。
- **fin-model**：`assumptions.json` 字段、三表、估值、敏感性的计算——本技能只规定每条假设从哪一章来、评委怎么查。
- **pitch-qa**：讲稿与题库格式——本技能补投资人视角的问答逻辑。

## 1. 推理链与证据等级
写作顺序 = 评委验证顺序：痛点被验证 → 方案有可量化差异 → SOM 算得出 → 单位经济为正 → 三表与融资自洽 → 壁垒与团队证明做得到。证据分三级，正文优先写 A 级，B 级标来源，C 级只能作佐证：
- A 级（可查验）：订单 / 合同 / 发票、营业执照与股权、专利 / 软著申请号、第三方检测报告、平台后台数据截图（匿名）、试点协议。
- B 级（有来源）：行业报告、招股书可比数据、政策文号、一手问卷（五要素齐全）。
- C 级（陈述）：意向书、访谈引语、团队经历描述。
缺 A 级证据的章节，在"已完成事项"中写下一步取得该证据的时间点，不用形容词补。

## 2. 商业模式画布（第 6 章，`bmc` 图 + 三句说明）
- 九格每格 ≤ 4 条，条目是名词 + 数字（"中小电子厂 6 800 家"而非"中小企业"）。
- 客户细分 / 价值主张 / 收入来源三格必须互相指认：谁付钱、为什么付、付多少；与第 4 章画像、第 7 章渠道、第 10 章收入流命名一致。
- 三句说明：为谁创造什么价值（≤ 40 字定位句）/ 向谁收什么钱（收入公式）/ 成本花在哪（前三大成本科目占比）。
- 规模化后的变化写一段：哪一格在 Y3 会变（如渠道从直销转代理、收入从硬件转订阅），并在财务假设中体现。

## 3. 价值主张与 PMF 证据（第 1–2 章、第 8 章）
- 价值主张公式：对（客户）在（场景）下的（痛点），我们用（方案）把（指标）从 A 改到 B，证据是（A/B 级证据）。
- PMF 证据按阶段写，不越级：创客组——原型 + 测试数据 + 预订单 / 意向数 + 付费意愿；创业组——收入 / 用户 / 复购 / 留存的月度曲线、客户名单（匿名）、NPS 或访谈引语。
- 每条证据带时间戳与材料编号（附录 A5），正文只写结论与数字。
- 示例数据（`researchMode = synthetic`）必须段首标记【示例数据，须替换为真实调研结果】。

## 4. 创新点与竞争壁垒（第 2–3 章、第 5 章，创新性 20 分）
- 创新四件套：参数对比表（本品 vs ≥ 2 竞品 + 测试条件 + 出处）、知识产权清单（类型 / 名称 / 申请号 / 状态，隐去权利人与院校）、第三方验证、12–36 月迭代路线。
- 创新点 ≤ 3 条，每条"量化差异 + 证据 + 可验证方式"；类型标注技术 / 模式 / 场景。
- 壁垒四类各一证据与维持期：专利（年限）、数据（样本量与积累速度）、工艺 / 成本（单位成本差）、渠道（独家协议期 / 客户切换成本）。
- 必答"大公司进来怎么办"：时间窗口（对手跟进需要几个月、为什么）+ 触发指标 + 应对动作，写进第 11 章风险矩阵。
- 承认短板：竞品矩阵中至少 1 个维度输给对手并给补齐时间。

## 5. 运营计划（第 7–8 章）
- 首批 100 / 1 000 个客户从哪来：渠道 → 转化率（来源）→ CAC → 预算，主渠道 ≤ 2 个；首年收入拆到渠道 × 客户 × 单价，与财务章对账。
- 里程碑 `gantt` 12–36 月：每个里程碑 = 日期 + 可验证指标 + 负责人角色 + 对应资金用途行；已完成项打勾并带证据编号。
- 供应链 / 产能 / 质控表：关键物料或算力来源、备选供应商、产能爬坡与人效，须与第 9 章人员计划、第 10 章人力成本一致。

## 6. 团队与股权（第 9 章，团队 10 分）
- 三栏表：背景（专业 / 经历，角色化匿名）/ 分工（覆盖技术、市场、财务、运营）/ 已交付成果（日期 + 结果）；成员经历与里程碑一一对应。
- 股权表现状 + 本轮后，合计 100%；创始团队 > 51%（> 67% 为佳）、法定代表人 ≥ 10%、期权池 10–15%；外部指导者或院校持股须写比例与理由，否则改为顾问。
- 缺口与补齐：岗位 / 到岗月份 / 来源（招聘 / 顾问 / 期权）；全职承诺用匿名表述。
- 不写姓名、院校、学号、联系方式；团队成长证据（能力 – 事件 – 结果三例）放第 12 章。

## 7. 融资与退出（第 10 章 10.6–10.7）
- 融资额 = 悲观情景现金缺口 + 10–20% 安全垫，跑道 12–18 月；出让比例 = 融资额 ÷ 投后（±1 pp），单轮 ≤ 20%。
- 估值 ≥ 2 法三角验证（PS 可比 / VC 法 / 风险因素汇总 / DCF 仅作参考），给区间与取值理由；学生项目天使轮投后过高需有订单 / 专利 / 团队强证据。
- 资金用途 = 研发 / 市场 / 运营 / 储备比例，金额与第 10 章成本科目、第 8 章里程碑对应，合计 100%。
- 退出与回报：路径（并购 / 回购 / IPO）+ 投资人预期回报倍数，与 VC 法假设一致；下一轮触发的 3 个指标。
- 全文"融资额 / 出让 / 投后 / 用途 / 跑道"只出现同一组数字（概要、第 10 章、PPT、讲稿、题库）。

## 8. 投资人视角自问（写完每章用它查一遍）
是谁的钱、为什么现在付、付多少、获客花多少、多久回本、天花板多大、对手为什么追不上、团队凭什么做到、钱花完到哪一步、最坏情况还活着吗、我怎么退出。任一问在正文找不到带来源的数字即补证据，不补形容词。

## 9. 常见错误
伪痛点无付费意愿；市场章讲 C 端模式章收 B 端；只有 TAM；创新只讲原理；声称无竞争者；里程碑无人负责；股权缺失或导师持股无解释；融资额 ÷ 投后 ≠ 出让；悲观情景仍盈利；专利 / 执照扫描件露出院校或姓名。
