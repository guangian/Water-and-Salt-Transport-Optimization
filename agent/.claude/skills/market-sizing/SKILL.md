# market-sizing：规模要能复算

## 1. 双法测算
- **自上而下**：权威总盘（国家统计局 / 协会 / 头部咨询，写明口径与年份）→ 按地域 / 人群 / 品类 / 价格带逐层比例切分（每个比例有来源）→ TAM → SAM。
- **自下而上**：目标人群数 × 渗透率 × 年购买频次 × 客单价（人群数来自统计公报，渗透率与频次来自一手调研或行业报告）→ SAM；SOM = SAM × 首年可获得份额（0.5–2%，依据渠道容量 / 产能 / 营销预算反推）。
- **调和**：两法差异 > 2 倍必须复核假设；最终给区间并说明取中值的理由；SOM 要与财务模型首年收入一致（账本 `som_y1` ≥ `revenue_y1`）。
- 表格：`表：市场规模测算（自上而下）` 与 `表：市场规模测算（自下而上）`，列 = 步骤 / 参数 / 取值 / 来源；配 `funnel` 图（TAM → SAM → SOM）。

## 2. 框架落地（不是摆设）
- **PEST**：每个维度 2–3 条，每条“事实 + 数据 + 对本方案的含义”；政策写文号与条款。
- **五力**：每力给判断（强 / 中 / 弱）+ 证据 + 对策略的含义，最后一句总结行业吸引力。
- **竞品矩阵**：3–5 家 × 5–8 维（用户在意的维度：价格带 / 核心卖点 / 渠道 / 传播主题 / 用户评价 / 份额），带来源；配定位图；写自身短板。
- **SWOT → TOWS**：S/W/O/T 各 ≤ 4 条且带数据；交叉得出 SO/WO/ST/WT 策略，策略与后文章节对应。
- **价值链 / 画布**：标出本方案改变了哪一环（成本、效率、体验），用数字说明改变幅度。
- **用户画像**：2–3 个，含人群规模估算、场景、动机、阻碍、触点、价格敏感、一句洞察。

## 3. 数据源分级（引用时标注）
A 级：国家统计局与统计公报、部委与地方政府文件、上市公司年报 / 招股书（巨潮资讯）、行业协会年报、国际组织。
B 级：艾瑞 / 易观 / 前瞻 / 头豹 / QuestMobile / 欧睿 / 尼尔森 / 凯度公开报告、券商研报摘要、36 氪 / IT 桔子数据库。
C 级：权威媒体报道、平台公开榜单（蝉妈妈 / 新榜 / 千瓜）、企业官网。
D 级：自媒体、无署名文章——只能作线索，不得作为数据来源。
每个数字四要素 + 文献号；A/B 级占比 ≥ 40%；近 3 年占比 ≥ 70%。

## 4. 常见错误
把 TAM 当 SOM；只有一种方法；比例无来源；增速用“预计将”；人群数用全国人口；SOM 与财务收入不一致；引用二手转载而非原始报告。
