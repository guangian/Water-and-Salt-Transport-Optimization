# revision-round：只改清单项，不重写

1. **定位**：按任务书条目的“文件与位置”用 `Grep` 找到原句 / 原表，`Read` 该处 ±40 行即可，不要通读整章。
2. **最小改动**：用 `Edit` 做局部替换（增加一张表、补一句四要素数据、改一个数字），保留章结论句、图表引用、文献号与小结结构；禁止重排章节、禁止删除其他评委没有提到的内容。
3. **数字纪律**：新增数字先查 `03_财务/numbers.json`；账本没有的数字不能写，改为定性表述并标【待核实】，或在回报中请主代理补账 / 补调研。
4. **新增引用**：写 `05_正文/新增文献_修改N.json`（临时号 `RN-1…`），正文用临时号；不碰 `参考文献.json`。
5. **复检**：正文 → `bizkit.checks --chapter <文件>`；slides → `bizkit.pptx_render`（警告 0）；财务 → `bizkit.finmodel`（检查页 0）；图表 → `bizkit.charts --only <ids>`。
6. **回报**：逐条“序号 → 已完成（改了什么、在哪）/ 未完成（原因）”，列出改动文件；不要复述全文。
7. **白名单**：任务书之外的文件一律不动；发现白名单外的问题只在回报里提出。
