# pitch-qa：10 分钟讲清楚，5 分钟答得住

## 1. 讲稿
- 字数 = 分钟 × 190 × 0.93（10 分钟 ≈ 1 750 字，区间 1 650–1 950；8 分钟 1 320–1 560；15 分钟 2 480–2 930）。
- 开场（≤ 30 秒）：场景或数字钩子（“每年有 2 000 万件汝瓷礼盒被送出，但 73% 的收礼人说不出品牌”）→ 一句定位（为谁 / 做什么 / 凭什么）→ 不说“尊敬的评委，我们来自……”（匿名 + 浪费时间）。
- 段落时间分配（策划案）：开场 8% / 诊断与洞察 20% / 定位与创意 25% / 执行与预算 25% / 效果与风险 12% / 收尾 10%；（BP）：开场 8% / 痛点与方案 25% / 市场与模式 25% / 牵引与财务 25% / 团队与融资 10% / 收尾 7%。
- 每段首句结论，段内“结论 → 数字 → 原因”；句长 ≤ 25 字；数字具象化 ≥ 2 处（“相当于每天新增 30 位首次购买者”）；禁语 0；全文出现 ≥ 10 个 / 千字的数字。
- 收尾 60 秒：回扣定位句 + 预期效果一句 + （BP）融资与愿景；最后一句留给评委一个可记住的句子（Big Idea）。
- 分工：3–5 人出镜，按章节切换，每人 ≥ 1 段；交接句写进讲稿（“接下来由负责传播的同学……”不写姓名）。
- 讲稿文件格式：标题行写时长与字数；每段 `[m:ss–m:ss] 讲者角色` 开头；末尾附“关键数字卡”（10 个数字与来源，供背诵）。

## 2. 答辩题库（≥ 40 题，六维度各 ≥ 4）
格式：
```
### Q7【财务与预算】300 万预算里 KOL 占 38%，为什么不投信息流？
主答：预算负责人（备：传播）
结论：因为我们的目标人群决策靠内容种草，KOL 的互动成本比信息流低 42%。（10 秒）
证据：小红书行业基准 CPE 2.1 元 vs 信息流 3.6 元 [18]；示例调研中 68% 受访者表示“看博主测评后下单”。（30 秒）
行动：首月双渠道各投 10% 做 A/B，第 2 月按 CPE 再分配。（10 秒）
```
必含“尖锐题”≥ 8：数据真实性（示例数据如何替换）、与头部竞品差别、预算砍半怎么办、企业不采纳怎么办、政策 / 平台规则变化、团队缺口、为什么是你们、最大的风险是什么。
回答原则：先结论；给数字与来源；承认局限再给行动；单题 ≤ 60 秒；不与评委争辩；不知道就说“这个数据我们没有掌握，赛后补充”。

## 3. 评委常问 50 问（按维度）
市场与数据：规模怎么算的；SOM 依据；样本量与抽样；数据来源可信度；增速假设；一手调研怎么做的；用户为什么会换品牌；复购证据。
定位与创意：一句话定位；与竞品差异；为什么这个人群；Big Idea 能否被记住；创意会不会侵权；品牌元素能否注册；企业现有资产如何利用。
执行与渠道：首月做什么；渠道选择依据；KOL 怎么选怎么付费；内容产能从哪来；线下活动预期；团队执行能力；时间表是否现实。
财务与预算：预算结构；单价依据；ROI 如何测算；现金流；盈亏平衡；融资用途；估值依据；悲观情景。
团队与资源：分工；缺什么人；企业配合度；导师与资源（匿名描述）；赛后是否继续。
风险与合规：最大风险；舆情预案；平台限流；广告法；数据隐私；供应链；政策变化。

## 4. 陈述视频分镜（10 分钟）
表格列：时间 / 画面（PPT 页码或实拍）/ 出镜人（角色）/ 台词要点 / 字幕 / 备注。开头 15 秒全员出镜（3–5 人，不得出现校徽校名背景）；转场用 PPT 页；结尾致谢 10 秒；导出 1080p MP4、音画同步、字幕 ≥ 28 号；文件命名按赛道规则。

## 5. 现场加分与扣分
加分：开场 10 秒抓住注意力；一页一结论；数字口径一致；团队交接自然；回答先结论；带实物 / 样品 / 样稿（线下）。
扣分：超时（1–3 分）；出现院校信息（每处 3 分）；人数不符（3 分）；念稿；PPT 整页文字；回答绕题；数字前后矛盾；贬低竞品；回答超过 90 秒。
