# brand-creative：从洞察到可执行的创意

## 1. 定位五步链（细则列明，评委按此打“定位的正确性”）
① 宏微观环境预测（3–5 年趋势 3 条，带数据）→ ② 市场细分（维度：人群 / 场景 / 价值 / 价格带；细分表）→ ③ 目标市场（规模 / 增长 / 可及性 / 竞争强度 / 匹配度 打分表，选 1–2 个）→ ④ 竞争对手识别与异同（POP 必须具备 / POD 差异点；二维定位图 ≥ 4 竞品）→ ⑤ 独特性与风格（品牌个性五维 / 风格关键词 3 个）。
定位陈述句：“对于（目标人群），X 是（品类 / 参照框架）中（差异点）的品牌，因为（支持点 1、2）。”单独成段加粗。
核心价值三层：功能价值 / 情感价值 / 自我表达价值；**双验证**：企业内部访谈（认可度）+ 顾客调研（联想匹配度 / 偏好）各给数据。
品牌屋：使命 / 愿景 / 核心价值 / 个性 / 支持点 / 口号，一张表。

## 2. Big Idea（10 → 3 → 1 发散收敛，候选表写进策略框架附表）
1. **发散（10 个候选）**：五个张力源各出 2 个——品类冲突（品类固有矛盾，如“糖 = 不健康”vs“功能补给”）、文化符号（地域 / 非遗 / 节气 / 器物）、消费场景（具体时刻与动作）、对手空白（竞品矩阵里没人占的词）、数据反直觉（调研里出人意料的数字）。每个候选一句主张 + 一个视觉锤 + 一个语言钉。
2. **收敛（打分到 3 个）**：用 7 项清单各 1–5 分（一句话可复述 / 与定位一致 / 不侵权 / 可持续 3 年 / 可被用户参与 UGC / 可被测量 KPI / 企业可执行），满分 35，保留前 3。
3. **决选（1 个）**：三候选对照表（主张 / 视觉锤 / 语言钉 / 得分 / 主要风险），选 1 并写明为何不选另两个；最后做与 3 个竞品传播主题的差异矩阵（主题 / 人群 / 情绪 / 符号 / 渠道）。

一句创意主张（≤ 12 字，可被评委复述）+ 视觉锤（一个可持续重复的视觉符号：图形 / 色彩 / 器物 / 动作）+ 语言钉（口号，≤ 10 字，有节奏）+ 创意来源（文化 / 洞察 / 产品事实）+ 延展：线上 ≥ 3 个渠道各 1 条内容样稿、线下 ≥ 1 个场景；与 3 个竞品传播主题做对照表证明不同。
检查清单：能一句话说清 / 与定位一致 / 不侵权（商标、字体、素材）/ 可持续 3 年 / 可被用户参与（UGC 机制）/ 可被测量（KPI）/ 可被企业执行（预算与能力）。

## 3. 品牌元素系统（≥ 4 类，每类“设计说明 + 寓意 + 应用”）
名称与中英文、域名 / 商标检索结论（写“经中国商标网初步检索，第 X 类无相同在先申请”并注明检索日期；无法检索则写待核实）；标识（构成 / 图形寓意 / 最小尺寸 / 禁用）；色板（主色 / 辅色 CMYK & RGB & 应用比例）；字体（标题 / 正文 / 禁用）；IP 形象或代言策略；宣传语与品牌故事（≤ 150 字）；听觉（音乐 / 口播 slogan）；包装与产品系统；应用场景清单（店招 / 包装 / 电商主图 / 短视频片头 / 周边）。本系统不生成 LOGO 图形：用“设计说明表 + 色板字体规范表 + 应用清单”呈现，并在 README 提醒团队补设计稿。

## 4. 整合传播
信息屋：核心信息 1 句 → 支持信息 3 条 → 证据；人群 × 阶段（认知 / 兴趣 / 购买 / 忠诚）× 渠道 × 内容形态 矩阵；三阶段（声量引爆 / 心智渗透 / 转化沉淀）各有目标、主题、关键动作、时间、预算、KPI；渠道玩法写到可执行（抖音：话题挑战 + 达人矩阵 + 信息流；小红书：关键词布局 + KOC 铺量 + 搜索卡位；B 站：长内容 + 联名；微信：私域 + 会员；电商：主图 / 详情 / 直播；线下：快闪 / 体验 / 异业）；KOL 分层表（头部 / 腰部 / 尾部 / KOC：数量 / 单价来源 / 预算 / 预期曝光）；内容日历（首 3 个月按周）；内容样稿 ≥ 5（标题 / 文案 / 画面描述 / 渠道）。

## 5. 合规（ICC 2018 准则 + 广告法）
不虚假夸大、不贬低竞品、不冒用他人商标 / 肖像、儿童与健康类特殊规则、广告需可识别（KOL 合作标注）、数据隐私；禁用词：最 / 第一 / 国家级 / 顶级 / 唯一 / 极致 / 史无前例。写一张“合规自检表”放第 5 章末。
