# mice-program：可执行的四天三夜

> 先读 `tracks/mice/专题/00_索引.md`，按角色只读对应文件；本技能是操作步骤，方法论与评分依据见专题包 `01`–`04`。命题硬约束：200–300 人、四天三夜、肇庆 / 南充 / 洛阳三选一、总额（含机动金）在 200–400 万元内（`tracks/mice/track.json.budgetRange`）。

## 0. 先定三个锚
人数（区间内取一个整数，全文唯一）、举办月份（查气候与档期）、预算锚点（建议 260–340 万，不贴上限）。三个锚写进《任务解析》关键假设并给依据。

## 1. 可行性核查（第 3 章）
1. 目的地评分表：交通可达 25% / 场地库存 25% / 气候季节 15% / 政策安全 15% / 成本 20%，各 1–5 分，三城并列。
2. 场地与酒店清单（≥ 3 家）：名称 / 会议厅面积 / 剧院式容量 / 圆桌围数 / 分会场数 / 客房数 / 协议价区间 / 来源 / 访问日期。容量三口径分别核：大会剧院式 ≥ 人数 × 1.1；晚宴围数 ≥ 人数 ÷ 10 + 2；研讨分会场 ≥ 组数。
3. 交通方案表：主出发城市 → 目的地：方式 / 班次 / 时长 / 票价 / 到达时刻；接驳大巴数 = 人数 ÷ 45 向上取整；给备选方式与成本差。
4. 时间可行性：避开节假日与当地大型活动档期；Day1 到达日不排大会。
5. 第三方 / OTA 数据只作区间，正文标注「须以官网核实」；无法核实的标【待核实】。

## 2. 主题（第 4 章）
企业文化关键词 × 目的地文化符号 → 候选 3 个打分（文化契合 / 可视化 / 可延展 / 记忆度）→ 选 1 并写推导句 → 主题一页（主张 / 视觉锤 / 语言钉）→ 视觉规范表（主色 / 辅色 / 字体 / 元素 / 应用场景，不画 LOGO）→ 物料清单（背景板 / 胸牌 / 手册 / 伴手礼，带数量，引用预算行）→ 四天贯穿矩阵（日 × 子主题 × 环节 × 物料）。

## 3. 日程网格（第 5 章）
1. 总日程表（4 天 × 上午 / 下午 / 晚上）+ 每日 30 分钟颗粒流程表，固定 8 列：时间 / 环节 / 地点 / 分组与动线 / 负责人角色 / 物料 / 对应 KPI / 备选。
2. 必含：欢迎晚宴、工作总结大会、学习研讨会、颁奖晚宴、团建、景点参观、购物娱乐或社交酒会；每个环节在「环节—目标对应表」里对应一个 KPI，对应不上就删。
3. 转场写梯队与用时；分组人数能整除；团建写分组规则、安全员配比（建议 1:25，标注为假设）、雨天替代；颁奖晚宴给分钟级脚本与座次原则。
4. 餐标表（餐次 / 形式 / 人均标准 / 围数 / 特殊饮食配额）与住宿分配表（房型 × 间数 = 人数）。
5. 执行排期 gantt：T-90 签约 → 招采 → 物料 → T-1 彩排 → 执行 → T+30 复盘。

## 4. 预算（第 7 章，`bizkit.finmodel` budget 模式）
1. 科目：交通 / 住宿 / 餐饮 / 场地与搭建 / 活动演出与团建 / 物料礼品 / 地接人力 / 保险 / 税费服务费 / 机动金；每科目 ≥ 3 行「单价 × 数量 + 来源 [文献号] + 对应环节」。
2. 机动金 5–10% 计入总额；人均写含 / 不含机动金两种口径；总额与区间留 ≥ 3% 余量。
3. 敏感性三因子：人数 ±10%、房价 ±15%、机票 ±20%（tornado）；付款排期按供应商条款（示例 30/50/20）。
4. 赞助或资源置换单列「抵减表」，不参与区间判断；不要反向调参凑整。
5. 验收：Excel 合计 = 正文 = `numbers.json.budget_total`；每个日程环节都能在预算里找到行。

## 5. 预案与人群管理（第 6 章）
1. 风险矩阵 ≥ 8 类：医疗 / 极端天气 / 交通延误 / 食品安全 / 舆情 / 人员走失 / 设备故障 / 公共事件 / 治安财物；列：触发指标 / 等级 Ⅰ–Ⅲ / 响应时限 / 第一责任人 / 处置步骤 / 资源与预算 / 保险条款。
2. 应急组织表 + 通知链 + 演练安排（T-1 彩排含疏散演练）。
3. 人群管理要点表：入场 / 转场 / 疏散三环节的峰值人数、通道数、通过率假设、用时、责任人。
4. 法规引用：《大型群众性活动安全管理条例》第六条九项作框架（内部年会不在许可范围，须写清边界）；旅行社责任险 + 参会人意外险；包车资质；食品留样。来源与访问日期见专题包 `02` §五。

## 6. 效果与传播（第 9 章 + 附录 A3）
KPI 评估表（指标 / 基线 / 目标 / 工具 / 周期 / 责任人）≥ 5 行；满意度问卷会后 48 小时回收计划；传播漏斗；「#肇庆旅游」宣传视频 1–3 分钟四平台（抖音 / 小红书 / 视频号 / B 站）脚本与发布计划（平台 / 时长 / 发布时间 / 目标播放），画面无校徽校名；目的地非肇庆的方案同样要交。

## 7. 路演与答辩
按专题包 `06`：20 页骨架、每页结论句标题、讲稿前 150 字钩子、题库六维度 ≥ 40 题且尖锐题 ≥ 8；全部数字只用 `numbers.json` 的值。
