# mice-program：可执行的四天三夜

1. **可行性核查**：目的地评分表（交通可达 / 场地库存 / 气候季节 / 政策安全 / 成本 / 文化契合，各 1–5 分 × 权重）；场地与酒店清单（名称 / 容量 ≥ 300 / 会议厅面积 / 宴会厅 / 房型房数 / 参考价 / 来源：官网或 OTA，访问日期）；交通方案（出发城市 → 目的地：航班 / 高铁班次与价位，大巴接驳）；时间可行性（避开节假日、场地档期）。
2. **主题**：双关联（企业文化关键词 × 目的地文化符号）→ 主题句 + 视觉系统（主视觉 / 色板 / 物料清单：背景板、胸牌、手册、伴手礼）→ 主题如何贯穿四天（每日子主题）。
3. **日程网格**：四天三夜逐时段（30 分钟粒度）表：时间 / 活动 / 地点 / 人员分组与动线 / 负责人（角色）/ 物料 / 备选方案；必含欢迎晚宴、总结大会、研讨会、颁奖晚宴、团建、景点、购物娱乐；餐标与住宿分配表。
4. **预算**：科目（住宿 / 餐饮 / 交通 / 场地 / 活动 / 物料 / 人力 / 保险 / 税费）× 单价 × 数量 + 来源；人均成本；机动金 5–10%；总额 200–400 万硬门槛；敏感性（人数 ±10%、住宿价 ±15%）。
5. **应急预案 ≥ 8 类**：医疗 / 天气 / 交通延误 / 食品安全 / 舆情 / 人员走失 / 设备故障 / 疫情或公共事件；每类：分级、响应时限、责任人、联络机制、保险条款。
6. **效果与传播**：满意度 / 参与度 / 媒体传播 / 员工敬业度 KPI 表；宣传视频 1–3 分钟四平台脚本（话题 #目的地旅游），画面无校徽校名。
