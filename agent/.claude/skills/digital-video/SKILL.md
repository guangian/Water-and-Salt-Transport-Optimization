# digital-video：短视频 + 投放 + 数据闭环

## 1. 短视频脚本（≤ 3 分钟，MP4 ≤ 50 MB，≥ 3 平台发布带话题）
结构：0–3 秒钩子（冲突 / 反差 / 数字）→ 3–30 秒问题与场景 → 30–120 秒价值与证明（产品事实、用户证言、对比）→ 120–160 秒品牌主张（Big Idea）→ 结尾 CTA（话题 / 搜索词 / 小程序）。脚本表列：时间 / 画面 / 台词 / 字幕 / 音乐音效 / 素材来源与授权。学生团队可执行：手机 1080p、自然光、≤ 3 个场景、素材免版权或企业授权；画面不得出现校徽校名；遵守广告法与平台广告标识。评分四项：契合度 / 制作质量 / 平台适配与互动设计 / 创新亮点——每项在方案中写一段“本片如何得分”。

## 2. 平台矩阵（写成表：平台 / 角色 / 算法机制 / 内容形态 / 频次 / KPI）
抖音（完播与互动权重、话题挑战、达人矩阵、信息流 / 千川）；小红书（搜索与收藏、关键词布局、KOC 铺量、笔记种草 → 搜索卡位）；B 站（长内容、联名、弹幕互动）；微信视频号 + 公众号 + 小程序（私域沉淀、会员）；电商（天猫 / 抖音商城：主图、详情、直播、评价运营）。每个平台给“为什么选它”的数据依据。

## 3. 投放与 A/B
预热 / 引爆 / 长尾三阶段；每阶段预算 = Σ 单价 × 量（CPM / CPC / CPE 刊例或行业均值，带来源）；A/B：两组素材 × 两组人群，首周各 10% 预算，按 CPE / 转化成本再分配；KOL/KOC 分层（头 / 腰 / 尾 / 素人）数量与单价来源。

## 4. 数据回传与归因
漏斗：曝光 → 播放 → 完播 → 互动 → 搜索 → 进店 → 转化 → 复购；每层给基线（行业均值 + 来源）与目标；工具：平台后台（巨量云图 / 蒲公英 / 千瓜）、UTM / 专属口令 / 小程序码；归因口径写明（最后点击 / 多触点）；复盘周期（周 / 月）与调整规则。示例 / 模拟数据必须标注。
