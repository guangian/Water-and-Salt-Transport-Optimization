# digital-video：短视频 + 投放 + 直播 + 数据闭环

> 配套专题：`tracks/digital/专题/`（方法论 `01`、评分 `02`、结构 `03`、图表 `04`、工作流 `05`、路演 `06`）。本技能给“怎么做”的步骤，专题给标准与示例；行业基准值只作量级参考，正文必须换成当期可访问来源。

## 0. 推理链（按此顺序产出，后一步只用前一步的表）
企业诉求 → KGI / KPI 基线→目标表 → 数字资产盘点表 + 问题树 → 用户旅程 × 触点表 + 5A 现状估算 → 洞察句 / 定位 / Big Idea → 人群 × 场景 × 平台矩阵 → 内容矩阵（日历 / 样稿 / 分镜）→ 投放与直播测算（预算表）→ KPI 表 + 监测链路 + ROI 三情景 → 合规自检表。

## 1. 短视频脚本（≤ 3 分钟，MP4 ≤ 50 MB，≥ 3 平台公开发布并带 #全国高校商业精英挑战赛 #数字营销赛）
步骤：① 从 Big Idea 取主张原句与视觉锤；② 选形式（创意广告 / 产品介绍 / 直播切片 / 探店体验 / 品牌短剧，细则列举）；③ 写结构：0–3 秒钩子（反差 / 数字 / 提问）→ 3–30 秒场景与冲突 → 30–120 秒价值证明（产品事实 / 对比 / 证言）→ 120–160 秒品牌主张（原句出镜）→ 结尾 CTA（话题 + 搜索词 + 互动指令）；④ 填分镜表：镜号 / 时间 / 画面 / 台词 / 字幕 / 音乐音效 / 素材来源与授权 / 对应策略节；⑤ 写“平台适配表”：三平台各自的封面、标题、前 3 秒、CTA、发布时间；⑥ 写“本片如何得分”四段：内容契合度 / 制作质量 / 平台适配与互动设计 / 创新性与亮点。
可执行约束：手机 1080p 竖版 9:16、自然光、场景 ≤ 3、素材免版权或企业授权、画面不出现院校标识、无静帧黑屏、字幕齐全；禁用绝对化用语；正文放 ≤ 10 行摘要表，完整脚本与字幕入附录 A2，三平台链接与数据截图位入附录 A3。

## 2. 平台矩阵（表：平台 / 角色 / 算法机制 / 人群 / 内容形态 / 频次 / KPI / 预算占比）
每平台一句“为什么选它”的数据依据（来自旅程 × 触点表）；主平台 ≤ 4 并写明不选的平台与原因。机制要写对：抖音（完播与互动权重、看后搜、FACT+S：商家自播 / 达人矩阵 / 营销活动 / 头部大 V + 搜索 / 商城 / 店铺；千川直投直播间与短视频引流）；小红书（KFS：KOL / KOC 内容 + 信息流 + 搜索，关键词布局与收藏权重，蒲公英选达人、聚光投放）；B 站（长内容、弹幕互动、联名）；视频号 + 公众号 + 小程序（私域沉淀、会员与复购）；电商货架（主图 / 详情 / 评价 / 商品卡）。人群用 O-5A 分层写目标：O 机会 / A1 了解 / A2 吸引 / A3 种草 / A4 购买 / A5 复购，每条动作标注作用链路（拉新 / 蓄水 / 种草 / 直接转化 / 种草转化 / 复购）；无后台数据时标“估算口径”。

## 3. 内容矩阵与 KOL / KOC
1 个 Big Idea → 3–4 个内容系列 → 每系列 ≥ 3 条选题；内容日历首 3 个月按周（平台 × 选题 × 形式 × 负责人角色）；样稿 ≥ 5（标题 / 文案 / 画面描述 / 渠道）；互动机制一句（话题 / 挑战 / UGC / 直播玩法）+ 二次传播路径。KOL / KOC 分层表：头 / 肩 / 腰 / 尾 / 素人 × 数量 × 单价（来源：星图 / 蒲公英 / 花火 / 互选当期报价或第三方报告）× 预期曝光 × CPM 折算；合作内容标“广告 / 合作”。

## 4. 投放与 A/B（budget 模式）
预热 / 引爆 / 长尾三阶段（参考分配 20–30% / ≥ 50% / 10–20%）；每行预算 = 单价 × 量 + 来源（平台当期报价 > 官方刊例 > 第三方报告 > 建模估算并标“估算”）；CPM 与达人商单报价分列；机动金 5–10%；A/B：两组素材 × 两组人群，首周各 10% 预算，按 CPE / 转化成本再分配。测算公式：曝光 = 预算 ÷ CPM × 1000；点击 = 曝光 × CTR；进店 = 点击 × 进店率；订单 = 进店 × 转化率；GMV = 订单 × 客单价；ROI = GMV ÷ 消耗；每层比率写来源。模板：`python -m bizkit.finmodel --example budget`；账本 key：`budget_total budget_contingency kpi_exposure kpi_interaction kpi_conversion roi sample_size`。反常即查：ROI > 10 倍、CPM 低于行业 1/3、互动率 > 15%。

## 5. 直播间运营（方案含直播时必写）
人货场：主播人设与话术、品组（引流款 / 福利款 / 主推款 / 利润款）、场景与节奏（开场 5 分钟留人 → 讲品 → 福利逼单，每 15 分钟一轮）；排期表：周 × 场次 × 时长 × 主题 × 主推款 × 目标场观 / GPM；分工到角色（主播 / 助播 / 中控 / 场控 / 投手）；承接指标达标线（平均停留 ≥ 30 秒、进场留存 ≥ 30%，巨量千川直播间运营指南口径）满足后再放量；复盘看 GPM、UV 价值、转化率、转粉率、互动率，不只看 GMV；学习期不频繁改计划。

## 6. 数据回传、归因与复盘
漏斗：曝光 → 播放 → 完播 → 互动 → 搜索 → 进店 → 转化 → 复购，每层基线（行业均值或企业历史 + 来源）与目标；KPI 表 ≥ 5 行（指标 / 基线 / 目标 / 测算依据 / 工具 / 周期）；工具：巨量云图 / 千川 / 抖店罗盘 / 星图、蒲公英 / 聚光 / 小红书数据中心、B 站花火、视频号助手、UTM / 专属口令 / 小程序码 / 达人专属链接；归因口径写明（最后点击 / 多触点 / 看后搜）；复盘节奏日 / 周 / 月与停投 / 换素材规则；短视频实际或模拟数据表标口径、采集日期、来源；示例数据必须标注。

## 7. 合规自检表（放第 5 章风险节或附录 A3）
条款 → 本方案动作 → 自检：《广告法》第九条绝对化用语、第十三条不贬低竞品、第十四条可识别、第三十八条代言、第四十条未成年人；《互联网广告管理办法》第九条附购物链接的体验分享须标“广告”、第十九条直播带货责任；《互联网广告可识别性执法指南》直播广告标识三种方式与 AI 生成提示；《网络主播行为规范》第十四条禁止数据造假与绝对化用语；平台社区与广告规则；赛事规则：企业商标 / LOGO / 广告语 / 素材授权（企业授权书 + 免责声明）、免版权素材注明来源、全程匿名、队名作品名无机构简称与品牌恶搞。`checks.json.advertisingLawTerms` 零命中。
