# web-research：每个数字都能回到原文

## 1. 检索策略
- 关键词 = 对象 + 指标 + 年份 + 机构 / 文档类型（“电解质软糖 市场规模 2025 报告”“汝州 汝瓷 产业 规划 2026 政府”“小红书 CPE 行业均值 2025 千瓜”）。
- 先搜权威源再搜媒体：stats.gov.cn / 各部委 / 地方政府 → cninfo 年报 / 招股书 → 协会 → 艾瑞 / 易观 / 前瞻 / 头豹 → 36 氪 / 第一财经等。
- 用 `web_search(query, count=8)` 看候选，用 `web_fetch(url)` 读原文（列表页 → 详情页）；数据以原文为准，摘要可能过时。
- 每个问题 ≤ 3 次检索；总量按任务书上限；检索失败换关键词或改用已知权威站点直接 fetch。

## 2. 记录四要素 + 文献
事实表每行：指标 / 数值 / 单位 / 口径 / 年份 / 来源机构与标题 / URL / 访问日期。
参考文献条目追加到 `01_调研/参考文献.json`：
```json
{ "id": 7, "type": "report", "author": "中国陶瓷工业协会", "title": "2025 年陶瓷行业运行报告", "publisher": "中国陶瓷工业协会", "year": 2025, "url": "https://…", "accessed": "2026-03-01" }
```
`type`：report / web / gov / paper / book / annual-report / news / standard / database。id 用“当前最大 id + 1”，用 Python 读改写避免覆盖。

## 3. 冲突与缺失
- 两源不一致：记录两者，取官方或更近年份，并在总览说明。
- 找不到：写【待核实】并给替代口径（上一年数据、相邻品类、区间估计），正文降级为定性表述。
- 绝不编造 URL / 报告名 / 数字；抓不到原文的数字不进正文。

## 4. 引用写法
正文：“2025 年中国汝瓷工艺品零售规模 33.5 亿元（线上 + 线下），同比增长 11.2% [7]。”
图表：`source: "资料来源：中国陶瓷工业协会《2025 年陶瓷行业运行报告》[7]"`。
