# survey-design：让评委相信“形成了一手资料”

## 1. 样本量
n = Z²·p(1−p)/e²，95% 置信、p = 0.5、e = 5% → 384；有限总体修正 n' = n / (1 + (n−1)/N)。
计划发放 = 目标有效 ÷ (1 − 无效率 10–15%)。访谈：企业内部 3–5 人（创始人 / 销售 / 设计 / 渠道）+ 目标顾客 8–12 人 + 渠道 / 专家 2–3 人。实地：门店 / 展会 / 产地 ≥ 1 次，带观察记录表与照片位。

## 2. 问卷结构（≥ 25 题，15 分钟内答完）
甄别（年龄 / 地区 / 是否购买过品类，2–3 题）→ 行为（购买渠道 / 频次 / 花费 / 场景，4–6 题）→ 态度量表（Likert 5 点 ≥ 8 项：品牌认知度 / 联想 / 偏好 / 信任 / 推荐意愿；同一量表方向一致，设 1 道反向题做质控）→ 价格敏感 PSM 四问（太便宜 / 便宜 / 贵 / 太贵）→ 概念 / 创意测试（2–3 个概念，各评“吸引力 / 独特性 / 购买意愿 / 可信度”）→ 媒介习惯（平台 / 内容形态 / 影响购买的信息源）→ 人口统计（性别 / 年龄段 / 城市层级 / 收入段 / 职业）。
每题注明：题型、选项、跳转逻辑、对应研究假设编号、分析方法。

## 3. 质控与质量门槛
逻辑陷阱题、作答时长下限（< 1/3 中位数剔除）、IP / 设备去重、直线作答剔除、开放题空白率；报告有效率。

| 指标 | 阈值 | 计算 / 做法 | 未达标处理 |
|---|---|---|---|
| 有效样本量 | ≥ 384（或有限总体修正值） | n = Z²p(1−p)/e² | 补样或在正文写明置信区间放宽 |
| 有效率 | ≥ 80% | 有效 ÷ 回收 | 说明剔除规则 |
| 量表信度 Cronbach α | ≥ 0.7 | 每个量表分别计算 | 删除低相关题项后重算 |
| 结构效度 KMO | ≥ 0.6（Bartlett p < 0.05） | 因子分析前置检验 | 不做因子分析，只报描述统计 |
| 访谈 | 8–15 人（企业 + 顾客 + 渠道 / 专家） | 记录模板 | 少于 8 人标【待补】 |
| 实地观察 | ≥ 1 次（门店 / 展会 / 产地） | 观察记录表 + 照片位 | 写入执行计划待办 |
| 进阶分析 | Kano / 联合分析 / PSM 任选其一 | 配一张结果图或表 | — |
示例结果必须报告 α、KMO、有效率三个数（带示例数据标记）。

## 4. 分析与呈现
样本结构表（与总体对比）；描述统计（占比 / 均值 ± 标准差）；交叉表（人群 × 行为 / 态度，报告显著性 χ² 或 t 检验的 p 值）；PSM 四条曲线交点（OPP / IPP / 可接受价格区间）；概念测试 TOP2 Box；把 5–8 条关键发现写成“数字 + 含义”的句子并在正文引用。

## 5. 示例数据规则（researchMode = synthetic）
- 文件与段落开头必须有 **【示例数据，须替换为真实调研结果】**；账本条目 `synthetic: true`；写入《数据真实性清单》。
- 数值要内部自洽（占比和为 100%、交叉表边际一致）、与行业数据定锚（例如渗透率不高于行业报告值）、不夸张（愿意尝试率通常 40–70%、推荐意愿 TOP2 30–55%）。
- 给出“替换指引”：团队拿到真实数据后替换哪些文件、重跑哪些命令（charts → docx → checks）。

## 6. 访谈提纲
企业内部：品牌历史与资产 / 目标与痛点 / 产品与定价逻辑 / 渠道与客户结构 / 过往传播与效果 / 资源与预算边界 / 对本次策划的期待。
顾客：品类认知与使用场景 / 购买决策过程 / 对品牌的联想与评价 / 价格感知 / 对概念的反应 / 信息来源与信任对象。
每问附 1–2 个追问；记录模板：时间 / 对象角色 / 要点 / 原话（匿名）/ 启示。
