# case-analysis：以顾问身份做可复算的诊断

先读 `tracks/case/专题/00_索引.md`，按角色取对应专题（方法论 01、评分 02、结构 03、图表 04、工作流 05、路演 06）。推理链固定：命题要求 → 财务症状 → 经营原因 → 战略根因 → 策略计划 → 实施动作 → 计划综合收益表 → 治理保障，每一环可倒查到年报页码或准则条款。

## 步骤
1. **数据与引用**：以指定企业近三年年报为基础（细则建议：若提交前最新一年年报已披露，参考最新内容）。每个数字标“年报年份 + 页码”（如“2024 年年报 p.87”），研究员 D 先产出《年报页码索引》CSV（主要会计数据 / 费用 / 合并三表 / 分部 / 研发投入 / 应收账龄 / 公司治理各节页码），写手只从索引取页码，不确定写【待核实 p.】。比率表必含“公式”列（如 毛利率 = (营业收入 − 营业成本) ÷ 营业收入）。
2. **五类比率 + 杜邦**（专题 01 F1–F2）：盈利（毛利率 / 净利率 / ROA / ROE，ROE 用归母口径）、营运（应收 / 存货 / 总资产周转天数，分母用平均值）、偿债（流动 / 速动 / 资产负债率 / 利息保障）、成长（收入 / 归母净利 / 经营现金流增速）、现金流质量（经营现金流 ÷ 净利润、自由现金流）。杜邦 ROE = 归母净利率 × 总资产周转率 × 权益乘数，三因素乘积须与年报“加权平均净资产收益率”对得上（差 ≤ 0.1 pct 或解释口径），再用连环替代法做三年归因表。
3. **盈利质量四问**（01 F3）：经营现金比率是否持续 ≥ 1；非经常性损益（政府补助 / 投资收益 / 公允价值变动）占利润多少；减值与坏账吞掉多少；研发资本化比例对当期利润的影响。每问给数字 + 准则依据（CAS 14 收入、CAS 22 预期信用损失、CAS 6 第 7–9 条研发支出、CAS 16 政府补助、CAS 8 资产减值），引用写到“《企业会计准则第 N 号——××》第 N 条”，语气为“口径影响与披露建议”，不用“操纵”类字眼。
4. **行业数据聚类**（01 F4）：同业 5–8 家、2–3 个指标（毛利率 × 研发费用率 × 应收天数等），Z-score 后 K-means（k = 2–3）或四象限；输出散点图 + 簇表（簇名 / 成员 / 均值 / 本企业位置 / 差距），算法底稿进附录；样本不足 5 家时明写样本量与方法。
5. **问题识别树**（01 F5）：财务症状（比率 + 页码）→ 经营原因（分部 / 客户 / 费用）→ 战略根因 → 对应策略章节；问题 ≤ 3 个，每条有数据证据。
6. **策略**（01 F6–F7）：外部（PEST / 五力）、内部（资源能力 / 价值链 / VRIO / 核心竞争力）、竞争者矩阵（≥ 3 家 × ≥ 6 维）；TOWS 四象限各 ≥ 2 条选项；选项评分表（吸引力 / 可行性 / 风险 / 协同 / 财务影响，权重合计 100% 并写依据），选 3 舍 2 且被否决项给理由；策略屋 + 三年目标体系（财务：收入 / 归母净利 / ROE / 经营现金比率 / 应收天数 / 研发费用率；非财务 ≥ 3 项）；业务组合（BCG / 安索夫）；策略选项与第 7 章情景一一对应；与企业愿景 / 使命一致（细则要求）。
7. **实施计划**：按营销 / 生产 / 研发 / 供应链 / 人力 / 数字化 / 财务共享分业务单元，8 列行动表（业务单元 / 动作 / 里程碑 / 责任角色 / 资源 / 预算 / KPI 基线→目标 / 关联预测行）+ gantt + 风险矩阵 ≥ 6（含触发指标）。
8. **财务预测**（01 F8）：`finmodel` startup 模式，`years = 3`，`revenueStreams` ≥ 2——“现有业务基准（分部历史 CAGR 与毛利率，来源年报页码）”+“新举措增量（对应行动表）”；输出三年计划综合收益表（含其他综合收益行）+ 现金流 / 资产负债摘要 + 假设表（取值 / 历史值 / 行业值 / 来源）+ 三情景 + tornado（毛利率 / 研发费用率 / 应收天数 / 减值率）+ “不实施策略”基准对比 + 连续性检验表（2025E 与 2024A 的毛利率 / 费用率 / 应收天数差异 ≤ 3 pct / 30 天，否则写理由）+ 资本安排表（来源 / 金额 / 成本 / 期限）。三表勾稽为 0；预测 ROE 用归母口径。
9. **公司治理**（01 F9）：按《上市公司治理准则》（证监会公告〔2018〕29 号）逐条评估：第 25 条董事会构成、第 34–37 条独立董事、第 38–39 条审计委员会、第 56 条绩效评价、第八章 ESG、第九章信息披露；表列 `条款 | 现状（年报页码） | 评估 | 建议`，加“治理问题 ↔ 财务异常”关联行；建议 3–5 条，每条有条款依据。
10. **知识点列表**：≥ 15 条（知识点 / 所在章节 / 用途），覆盖财务会计、财务管理、管理会计（本量利 / 预算 / 平衡计分卡 / EVA）、战略四类各 ≥ 3 条，且正文可定位。
11. **封面与匿名**：封面字段团队名称 / 组别 / `【提交前由团队填写：选手姓名】` / `【提交前由团队填写：指导教师姓名】`，无电话邮箱；全文、PPT、讲稿、分镜不得出现院校词；文件名规则含学校名仅用于文件名。
12. **流通业变体**（retail）：8 要素（目录 / 概要 / 引言 / 案例简介 / 企业内外部环境分析 / 发展瓶颈分析 / 结论与启示 / 附录与参考资料），≥ 3000 字、PPT ≥ 20 页，封面团队名称 / 作品名称 / 案例企业名称；必备“地区性特点”节（案例企业在院校所在省的门店 / 供应链 / 消费者布局与当地政策，配区域数据表，来源省统计局 / 年报分地区数据）、分析框架图、前沿方法任选一（RFM、DEA、GIS 热力、情景规划，须有输入数据与输出图）；瓶颈 ≤ 3 个且每个“数据证据 → 因果链 → 影响量化”；启示可迁移到同类流通企业。

## 自检（交稿前）
比率公式列 ✓ 杜邦与年报 ROE 吻合 ✓ 年报页码 ≥ 3 处且附录有索引 ✓ 聚类 ≥ 5 家 + 方法说明 ✓ 问题 ≤ 3 且有数字 ✓ TOWS + 选项评分 + 否决理由 ✓ 综合收益表含其他综合收益行 ✓ 假设表有来源 + 连续性检验 ✓ 治理条款号 ≥ 4 ✓ 知识点 ≥ 15 ✓ 封面占位与匿名 0 命中 ✓（完整 30 条见 `专题/05_工作流与自检表.md`）。
