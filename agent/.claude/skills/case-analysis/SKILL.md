# case-analysis：以顾问身份做可复算的诊断

1. **数据与引用**：以指定企业近三年年报为基础，每个数字标“年报年份 + 页码”（如“2024 年年报 p.87”）；比率表必须含“公式”列（如 毛利率 = (营业收入 − 营业成本) ÷ 营业收入）。
2. **五类比率 + 杜邦**：盈利（毛利率 / 净利率 / ROE / ROA）、营运（应收 / 存货 / 总资产周转）、偿债（流动 / 速动 / 资产负债率 / 利息保障）、成长（收入 / 净利 / 经营现金流增速）、现金流质量（经营现金流 ÷ 净利润、自由现金流）；杜邦分解 ROE = 净利率 × 周转率 × 权益乘数，三年变化归因。
3. **行业数据聚类**：同业 5–8 家公司 2–3 个指标（如毛利率 × 研发费率）做分组（可用简单 K-means 或四象限），说明企业所处位置与差距。
4. **问题识别树**：财务症状 → 经营原因 → 战略根因，每条有数据证据；问题 ≤ 3 个。
5. **策略**：外部（PEST / 五力）、内部（资源能力 / 价值链 / 核心竞争力）、竞争者；TOWS 交叉；战略选项评分表（吸引力 / 可行性 / 风险 / 协同）；三年方向与目标体系（财务 + 非财务）；业务组合（BCG / 安索夫）。
6. **实施计划**：关联营销 / 生产 / 研发 / 供应链 / 人力 / 数字化行动表（里程碑 / 责任 / 资源 / KPI）。
7. **财务预测**：三年计划综合收益表（必须）+ 现金流与资产负债摘要 + 假设表（增长率 / 毛利率 / 费用率来源）+ 情景与敏感性 + “不实施策略”的基准对比；用 `finmodel` startup 模式以“现有业务 + 新举措”建模。
8. **公司治理**：按《上市公司治理准则》逐项评估（董事会结构 / 独董 / 激励 / 信息披露 / 内控 / ESG）并给建议。
9. **知识点列表**：≥ 15 条（知识点 / 所在章节 / 用途）。
10. **流通业变体**：地区性特点一节（案例企业在所在省份的门店 / 供应链 / 消费者布局与当地政策，配区域数据表，来源：省统计局 / 企业年报分地区数据）；分析框架图；前沿方法任选（RFM、DEA、GIS 热力、情景规划）。
