# ai-disclosure：辅助工作台的边界说清楚

赛事细则：策划方案 / 商业计划书“严禁抄袭 / 完全使用 AI 工具进行创作”；国贸类赛道要求“AI 附录”。本系统定位为辅助底稿，交付时必须让团队清楚哪些内容需要替换、重写、核实。

## 1. 团队确认清单 `08_提交包/团队确认清单.md`（逐项 `- [ ]`）
- 替换全部示例数据（见数据真实性清单，共 N 条），并删除所有“【示例数据…】/（示例数据，须替换）”标记；重跑图表 / 文档 / 检查。
- 文件名中的“学校名称 / 抽签编号”按赛区命名规则填写；正文保持匿名。
- 会计案例：封面填写选手与指导教师姓名（仅封面）。
- 补品牌设计稿（LOGO / 包装 / 主视觉）并替换设计说明表旁的示意位。
- 全文通读并修改：建议 ≥ 30% 段落用团队口吻重写；核对每个数字的来源；删除不认同的观点。
- 一手调研确实执行：问卷 ≥ 384 份、访谈 ≥ 8 人、实地 ≥ 1 次，原始数据留档。
- 原创性声明、版权声明手写签名 + 指印；企业授权书盖章。
- 录制 10 分钟陈述视频（开头 3–5 人出镜，画面无校徽校名），MP4 命名按细则。
- 同校同品牌 4 年查重自查；与历届作品查重名单核对。
- PDF ≤ 页数上限、A4 竖版、≤ 30 MB；PPT ≥ 规定页数（精英赛 / 省赛）。

## 2. 数据真实性清单 `08_提交包/数据真实性清单.md`
由 `bizkit.package` 自动扫描生成（`numbers.json.synthetic` + 正文标记）；人工核对条数 = 正文标记数 = PPT / 讲稿 / 题库标记数。

## 3. 内部《AI 辅助使用说明》（不进提交物，放 `08_提交包/内部_AI辅助使用说明.md`）
说明本底稿由 AI 辅助生成的环节（资料整理、结构搭建、初稿撰写、排版）、团队必须完成的环节（一手调研、创意定稿、数字核实、全文修改、答辩准备），以及若赛道要求 AI 使用附录时可引用的中性表述（“在文献检索、文字润色、排版环节使用了生成式 AI 工具，建模、调研、结论由团队独立完成”）。

## 4. 口径一致
交付摘要第 ⑤⑥ 段、团队确认清单、README 三处对“示例数据条数 / 须团队完成事项”完全一致。
