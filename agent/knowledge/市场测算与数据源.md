## 四、市场规模测算与行业分析框架落地

### 4.1 TAM / SAM / SOM：双法测算与调和

| 步骤 | 做法 | 国金级要求 | 来源 |
|---|---|---|---|
| 0 锁定边界 | 先写清五要素：产品 / 服务定义、地域、客户类型、时间（基准年 + 预测年）、计量单位（销售额 / 销量 / 用户数） | 边界一句话置于章首；全文口径不变 | [R44] |
| 1 自上而下（Top-down） | 行业总规模（官方 / 协会 / 招股书）× 细分占比 × 地域占比 × 可服务渠道占比 → TAM → SAM | 每个乘数有来源；链条 ≤4 层；标注年份 | [R44][R45] |
| 2 自下而上（Bottom-up） | 目标客户数 × 渗透率 × 年购买频次 × 客单价（或 客户数 × ARPU） | 客户数来自统计 / 企查查筛选 / 调研；渗透率来自可比品类或试点 | [R45][R46] |
| 3 调和 | 两法结果并列；差异 ≤10–15% 可取均值；差异 >2 倍必须回查假设并说明取舍 | 调和表（方法 / 结果 / 关键假设 / 取值） | [R45][R46] |
| 4 SOM | SAM × 可达份额；份额由渠道覆盖、产能、营销预算、竞争格局推出 | SOM 给区间（低 / 中 / 高）；首年份额通常 0.5–2%，三年 ≤5–10%，超出需强证据 | [R46][R47] |
| 5 与财务对账 | 财务章 5 年销量 × 单价 ≤ SOM；增长率 ≤ 行业增速 + 份额提升可解释部分 | 跨章一致性检查 | [R45] |
| 6 呈现 | 漏斗图（TAM → SAM → SOM，标金额与年份）+ 测算表（公式、参数、来源）+ 一句结论 | 不超过 2 页正文，细节入附录 | [R44] |
| 常见错误 | 只给 TAM；用全球数据当中国数据；把 GMV 当收入；渗透率拍脑袋；把 SOM 当成收入目标直接抄进财务 | — | [R46] |

### 4.2 行业分析框架在金奖作品里的落地方式

| 框架 | 金奖用法 | 输出物（必须有结论句） | 常见误用（评委反感） | 来源 |
|---|---|---|---|---|
| PEST | 只筛与本项目直接相关的 6–8 条，每条写“事实（来源）→ 对本项目的影响 → 应对 / 机会” | 一张三列表，标题写成结论（如“政策端：三项补贴使单位获客成本下降约 12%”） | 四象限各堆 5 条常识、无来源、无影响分析 | [R15] |
| 波特五力 | 每力给 1–2 个量化证据（供应商集中度、替代品价格比、进入门槛金额、客户议价力），结论为“行业利润池在哪、我们站在哪” | 五力评分雷达图 + 结论句 | 教科书定义复述、不落到本项目 | [R15] |
| SWOT | 每格 ≤3 条且有数据；必须接 TOWS 策略矩阵（SO/WO/ST/WT 各 ≥1 条策略）并与后文策略章对应 | SWOT 表 + TOWS 表 | 优势写“团队年轻有活力”、劣势写“资金不足” | [R15] |
| 价值链 | 画本行业价值链（上游 – 中游 – 下游 – 终端），标注各环节毛利率 / 集中度与本项目切入点 | 价值链图 + 利润分布 | 只画流程不标利润与切入点 | [R44] |
| 商业模式画布 | 九宫格一页，客户细分与价值主张与前文 STP 一致；收入来源与财务章一致；关键指标标在格内 | 画布一页 + 三句说明（谁付费、为什么付、怎么规模化） | 画布与正文矛盾、泛填 | [S19] |
| 竞争矩阵 | 3–5 家（含替代方案），维度为用户购买决策维度（价格、性能、服务、渠道、品牌等 5–8 项），用数据或 ●◐○ 评级并注来源；再用 2 维定位图 | 竞品对比表 + 定位图 + “我们赢在哪、输在哪、怎么办” | 只列弱竞品、全是 ●、无来源、无自家短板 | [S19][R15] |
| 用户旅程 / 决策链 | 认知 → 比较 → 购买 → 使用 → 复购，每步痛点与触点，由调研支撑 | 旅程图 | 想象的旅程 | [R24] |
| 通用规则 | 框架是工具不是章节：标题写结论而非框架名；每个框架 ≤1 页；框架之间结论互相印证并导向策略 | — | 框架堆砌（PEST + 五力 + SWOT + 4P + BCG 连排） | [R15] |
