## 六、机器可检查的评分量规（rubric）

### 6.0 量规设计与使用方法

| 项目 | 规定 |
|---|---|
| 打分制 | 每个维度 1–5 分锚定（1 = 不可接受，3 = 省赛合格，5 = 国金水平；2、4 为介于两者之间），维度得分 × 权重 ÷ 5 求和得 100 分制总分 |
| 两层评审 | 第一层“机器检查项”由规则 / 解析器自动计算，给出维度得分上限（例如缺竞品矩阵则“竞争分析”维度上限 2 分）；第二层由 LLM 评审员在上限内按锚定描述打分并给出修改意见 |
| 硬门槛 | §6.6 任一硬门槛未过即判定“不可提交”，不计总分 |
| 目标线 | 国金目标：总分 ≥85 且无任一维度 <3；省赛合格线：总分 ≥70 |
| 阈值校准 | 所有数值阈值为初始值（依据官方细则与本报告归纳），应使用历届一等奖样本回归校准后更新 |
| 与官方表对齐 | 每张 rubric 的“对应官方评分项”列给出 CUBEC / 国创赛映射，便于换算为官方口径的模拟分 |
| 权重复核 | 各表权重之和 = 100，已在表尾注明 |

| 证据密度 | 15 | 答辩“事实论据”[S19] | 无数字 | 数字少且无来源 | 每 100 字 ≥1 个数字；关键数据带来源短语（“据××”“我们调研”） | 数字密度 ≥10 / 千字；来源短语 ≥5 处 |
| 语言可讲性 | 15 | “谈吐清晰有条理”5 [S15] | 长句书面语、禁语密集 | 可读但句长 >35 字 | 平均句长 ≤25 字；口语化；禁语 = 0；数字具象化换算 ≥2 处 | 平均句长 ≤25 字；禁语命中 = 0（颠覆 / 独一无二 / 蓝海 / 据统计 / 众所周知 / 前景广阔 / 我们学校 / 老师说）；“相当于”“等于”换算 ≥2 |
| 答辩准备 | 15 | 答辩 20 [S19]；“评委提问应答”5 [S15] | 无题库 | 题库 <20 题或无分工 | 覆盖 §5.5 六维度 ≥40 题，每题结论 – 证据 – 行动三段，指定主答人，单答 ≤150 字 | 题库条数 ≥40 且六维度各 ≥4；每题含三段标记；主答人字段非空；单答字数 ≤150 |

权重合计：20+15+20+15+15+15 = 100。

### 6.6 硬门槛（一票否决）与跨材料一致性

| 类别 | 检查项 | 判定 | 依据 |
|---|---|---|---|
| 匿名 | 正文 / 图片 OCR / PPT 母版 / 视频帧 / 文件属性 / 证书申请人 出现校名、校徽、院系、导师姓名或单位、学生联系方式 | 任一命中 = 不可提交（赛场每处扣 3 分，文旅 5 分） | [S06][S15][S19][R65] |
| 格式 | BP：PDF、A4 竖版、≥3000 字、宋体小四、除封面目录外 ≤80 页、≤30 MB；策划案：≤80 页、≤30 MB；大广赛：正文 ≤30 页 + 附件 ≤10 页；挑战杯 PPT ≤20 页 ≤20 MB | 任一不符 = 不可提交 | [S19][S15][R19][R65] |
| 封面 | BP 封面仅含组别 / 团队名 / 项目名；策划案封面含作品名 / 团队名 / 指导企业名，无人员姓名与联系方式 | 不符 = 不可提交 | [S19][S15] |
| 命名 | 文件名按“组别-学校-团队-作品名”（BP）或赛区规定（文件名可含校名，正文不可） | 不符 = 警告 | [S19][S15] |
| 真实性 | 企业授权书（策划案）、知识产权证明、营业执照（已注册项目）齐全；无法验证的订单 / 收入不得写入 | 缺 = 不可提交 | [S15][S19][R66] |
| 原创 | 与模板库 / 历届作品相似度 <20%（市调口径）；创业计划重复参赛再创新 ≥60% 且查重 <40%；不得“完全使用 AI 工具创作” | 超标 = 不可提交 | [R22][S19][S15] |
| 人数与时长 | 出镜 / 上台 3–5 人；陈述 ≤10 分钟（讲稿字数校验） | 不符 = 警告（赛场扣 3 / 1–3 分） | [S15][S19] |
| 语言 | 中文（留学生组中 / 英） | 不符 = 警告 | [S15][S19] |
| 跨材料一致性 | BP / 策划书、财务模型、PPT、讲稿中的关键数字集合完全一致：收入 Y1–Y5、毛利率、净利、融资额、出让比例、估值、SOM、单价、样本量、预算总额、KPI 目标 | 任一不一致 = 不可提交 | §3.9、§5.7 |
| 数据可追溯 | 正文每个外部数字可回溯到参考文献条目；参考文献 URL 可访问（HTTP 200 或已归档） | 不可追溯比例 >10% = 不可提交 | [R48] |
