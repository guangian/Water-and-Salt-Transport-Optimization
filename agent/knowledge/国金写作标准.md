### 1.3 每章必答问题清单（生成系统应逐条自检）

| 章节 | 必答问题 | 答不出即为缺项 |
|---|---|---|
| 执行摘要 | ① 用一句话（≤40 字）说清“为谁、解决什么、怎么做、凭什么赢”？② 本项目最硬的 1 个证据是什么（订单 / 专利 / 数据）？③ 融资多少、出让多少、花在哪？ | 缺 ① 则评委 3 分钟内无法建立信任 [R52] |
| 背景与痛点 | ① 痛点发生在谁身上、什么场景、频率与代价（量化）？② 现有解决方案是什么、为什么不够？③ 为什么是现在（政策 / 技术 / 消费变化的时间窗口）？ | 缺 ③ 属“伪痛点” [R14] |
| 产品与技术 | ① 产品形态与核心功能（≤3 个）？② 创新点与现有技术的可量化差异（参数表）？③ 技术成熟度与验证证据（样机 / 测试报告 / 用户数）？④ 知识产权状态（申请号 / 授权号 / 权属）？⑤ 下一步迭代路线？ | 缺 ②④ 则创新性 20 分落入“中等” |
| 市场分析 | ① 行业规模、增速、口径与来源？② TAM/SAM/SOM 各多少、怎么算、两法是否一致？③ 目标客户画像与购买决策链？④ 一手调研：样本量、时间、地点、方法、3–5 条关键发现？⑤ 趋势与驱动力？ | 缺 ④ 直接违反“形成一手资料” [S19] |
| 竞争分析 | ① 直接 / 间接 / 替代竞品各是谁？② 用户在意的 5–8 个维度上逐项对比？③ 我们的壁垒是什么、能维持多久？④ 竞品的反应与我们的应对？ | 缺竞品矩阵 = 常见致命缺陷 |
| 商业模式 | ① 向谁收费、收什么费、怎么定价？② 单位经济是否为正（毛利率、CAC、LTV、回收期）？③ 关键合作方与成本结构？④ 规模化后模式有何变化？ | 缺 ② 则“盈利模式不清晰” |
| 营销与渠道 | ① 首批 100 / 1000 个客户从哪来、花多少钱？② 渠道优先级与各渠道转化率假设？③ 复购 / 转介绍机制？ | “营销不聚焦”是 7 大常见问题之一 [R14] |
| 运营与实施 | ① 未来 12 / 24 / 36 个月里程碑？② 已完成了什么（时间戳 + 证据）？③ 供应链 / 产能 / 质控如何保证？ | 挑战杯“实践过程”25 分看此章 [R07] |
| 团队 | ① 每位核心成员与项目的匹配证据（经历 / 成果）？② 分工是否覆盖技术 / 市场 / 财务 / 运营？③ 缺什么人、怎么补？④ 股权结构与激励？ | “团队流水账”为常见缺陷 [R14] |
| 财务 | ① 关键假设表（≥10 条，每条有依据）？② 收入如何由驱动因子推出？③ 三表勾稽是否平？④ 何时盈亏平衡、现金最低点与所需融资？⑤ 悲观情景下是否仍活着？⑥ 估值依据与出让比例是否一致？ | 见第三章“穿帮清单” |
| 风险 | ① 技术 / 市场 / 政策 / 财务 / 运营 / 团队 6 类风险各 ≥1 条？② 每条有概率、影响、对策、触发指标？ | “风险模板化”为常见缺陷 [R14] |
| 社会价值 | ① 直接 / 间接带动就业多少（计算口径）？② 对产业链 / 区域 / 弱势群体的可量化贡献？③ 团队成员在项目中的成长证据？ | 国创赛个人成长 25–30 分 [S44] |

### 1.8 文风示例：好句子 vs 坏句子

> 说明：“好句子”中的数字、机构、人名均为示意写法（展示句式与要素），生成系统须替换为真实可追溯数据，不得照搬。

| 场景 | 坏句子 | 好句子 | 规则 |
|---|---|---|---|
| 定位句 | “我们致力于打造一个颠覆性的智慧农业综合服务平台。” | “我们为云南 1.2 万户中小咖农提供按亩付费的病害 AI 识别服务，识别准确率 94.6%（云南农科院 2025 年测试），每亩减少农药成本 38 元。” | 为谁 + 做什么 + 可验证数字 |
| 市场 | “中国咖啡市场规模巨大，前景广阔。” | “2024 年中国咖啡市场规模 3 133 亿元、近五年 CAGR 17.1%（艾媒咨询，2025），其中云南产区生豆供应占全国 98%（云南省农业农村厅，2024）。” | 数值 + 口径 + 年份 + 来源 |
| 痛点 | “农户普遍面临病虫害防治难题。” | “调研的 386 户咖农中，71.2% 在 2025 年因锈病减产 ≥15%，平均损失 4 200 元/户（本团队 2026 年 3 月问卷）。” | 频率 + 代价 + 一手数据 |
| 竞争 | “目前市场上没有同类竞争对手。” | “直接竞品 A（识别准确率 88%、年费 600 元 / 亩）、B（仅支持 3 类病害）；我们的差异在于本地化病害库 27 类与按亩计费，详见表 5-1。” | 承认竞品 + 维度化差异 |
| 技术 | “采用先进的深度学习算法。” | “采用 YOLOv8 改进模型，在自建 2.3 万张标注图像上 mAP 0.91，较基线提升 7.4 个百分点（测试报告见附录 C）。” | 方法 + 数据集 + 指标 + 证据 |
| 商业模式 | “通过多元化方式盈利。” | “收入 = 付费亩数 × 年费 120 元 / 亩 + 农资导购佣金 6%；2027E 两项占比 78% / 22%。” | 公式化 + 占比 |

### 2.3 各部分的国金级标准与量化指标

| 部分 | 国金级标准 | 必含量化指标 / 产出物 | 常见失分 | 来源 |
|---|---|---|---|---|
| 命题解读 | 把企业“想要”翻译成可衡量目标；明确不做什么 | KGI 1 个（如 12 个月销量 +30%）、KPI 3–5 个、预算上限、时间窗、区域 | 复述命题、未拆目标、与企业预算脱节 | [R20] |
| 市场与消费者洞察 | 得出一句“洞察句”：人群 + 场景 + 冲突 + 未被满足的需求；洞察必须由一手数据支撑 | 品类规模与 CAGR、渗透率、价格带分布、目标人群规模、一手调研样本量 ≥384（见 §2.6）、3–5 条关键发现（含交叉分析） | 泛 PEST、数据无出处、洞察 = 常识 | [S15][R24] |
| 品牌诊断 | 用数据说清“品牌卡在哪”，结论可推出后续定位 | 知名度 / 首选率 / NPS / 复购率（调研或企业数据）、价格指数、竞品对比表（3–5 家）、SWOT 每格 ≤3 条且有数据 | 罗列企业荣誉（细则明令“不可过多陈述企业现有成就”） | [S15] |
| STP | 细分变量可操作（地理 / 人口 / 行为 / 心理），目标市场选择有标准（规模、增长、可达、匹配），定位陈述格式：对于［目标人群］，［品牌］是［品类］中［差异点］的品牌，因为［支持点］ | 细分市场规模估算、目标市场占比、竞品定位图（2 维 ≥4 竞品）、核心价值验证（企业访谈 + 顾客问卷认可率） | 定位空泛（“高品质、年轻化”）、与洞察脱节 | [S15] |
| 策略与 Big Idea | 一句话可复述、与洞察一一对应、可延展到 ≥3 渠道 + 1 线下、可视化、可注册 | Big Idea 页、创意检查清单 5 项全过、品牌元素 ≥4 类、设计说明（含文化意象来源）、商标近似检索结果 | 创意与洞察无关、只做 LOGO 换新、元素不可注册 | [R26][R24] |
| 整合传播执行 | 阶段化（预热 / 引爆 / 延续）× 渠道 × 内容 × KOL × 线下，每个动作有目标、预算、负责人、时间 | 渠道 ≥4、内容样稿 ≥5、KOL 分层（头部 1–2 / 腰部 5–10 / 尾部与 KOC 批量）、线下场景 ≥1、合作资源清单；每渠道预期曝光与转化率假设有依据 | 全渠道撒网、无样稿、KOL 只写“邀请头部达人” | [R24][R26] |
| 预算与排期 | 预算 = Σ（渠道 × 单价 × 量）+ 制作 + 活动 + 机动；与企业规模与命题预算匹配；甘特图到周 | 预算表、分配比例（媒介 / 内容 / KOL / 活动 / 物料 / 机动）、单价来源（平台刊例 / 报价截图）、ROI 测算 | 预算一笔总数、无依据、超出命题预算 | [S15][R20] |
| 效果评估 KPI | 每个 KPI 有基线、目标、测量方式、监测工具、复盘节奏 | 曝光、互动率、搜索指数变化、进店 / 加购、转化率、GMV、ROI、复购率、NPS、品牌资产调研（前后测） | 只写曝光量、无基线、无测量方法 | [S16] |
| 风险与资产保护 | 商标 / 版权 / 域名注册计划 + 舆情响应流程 + 合规审查 | 资产清单（类别 / 状态 / 计划）、风险矩阵 ≥6 项、应急响应 SOP（监测 → 研判 → 响应 → 复盘，含时限） | 只写“加强监测”、缺商标检索 | [S15] |

### 2.4 创意呈现方法（评分项“品牌元素设计的创意性”10 分 + 展示“演讲专业程度含 PPT”5 分）

| 方法 | 用途 | 规范 | 来源 |
|---|---|---|---|
| Big Idea 一页纸 | 让评委 10 秒看懂创意 | 创意主张（≤12 字）+ 视觉锤（主视觉）+ 语言钉（口号）+ 一句推导（洞察 → 创意） | [R26] |
| 标题范式 | 作品名即创意 | 2026 一等奖约 70% 采用“对仗主标题（8–14 字，含文化意象）——品牌名 + 品牌策划书” | [S38]、01 报告 §4.8 |
| 品牌元素系统页 | 展示元素设计的完整性 | 名称释义、LOGO 标准制图（网格 / 最小尺寸 / 禁用示例）、标准色（CMYK/RGB/Pantone）、字体、辅助图形、IP 形象三视图、包装展开图 | [S15] |
| 情绪板与风格定义 | 让“独特性与风格”可视 | 关键词 3–5 个 + 参考图 + 色板；标注与竞品风格差异 | [S15] |
| 内容样稿 | 证明可执行 | 海报 ≥3（含投放尺寸）、短视频分镜脚本表（镜号 / 画面 / 文案 / 时长）、直播脚本、H5 流程图 | [R24] |
| 消费者旅程 × 渠道图 | 展示整合逻辑 | 认知 → 兴趣 → 购买 → 复购 → 推荐，每阶段对应渠道、内容、KPI | [R24][R26] |
| 落地效果图 | 增强真实感 | 门店 / 快闪 / 货架 / 包装 mockup；标注尺寸与物料清单 | [R20] |
| 原创与 AI 透明 | 合规 | 非原创素材注明来源与授权；AI 辅助生成图像需在附录说明；企业商标 / 素材须有授权 | [S16][S15] |
| 答辩呈现创新 | 展示 5×8 分项 | 情景剧 / 采访式 / 产品实演均可，但须在 10 分钟内完成并与策划书一致 | [S43] |

### 2.6 调研设计标准（问卷 / 访谈 / 样本量 / 质控 / 分析）

| 项目 | 国金级标准 | 公式 / 阈值 | 来源 |
|---|---|---|---|
| 调研设计总览 | 先写研究问题与假设，再选方法；定量（问卷）+ 定性（访谈 / 观察）+ 二手数据三角验证 | 市调大赛“方案设计”20 分看：抽样设计、样本量确定、问卷设计、信效度 | [R21] |
| 样本量（问卷） | 按置信度 95%、允许误差 ±5%、p=0.5 计算 | n = Z²p(1−p)/e² = 1.96²×0.25/0.05² ≈ 384；有限总体修正 n′ = n/(1+(n−1)/N)；分层 / 分组比较时每层 ≥30–50 | [R27][R28] |
| 抽样方式 | 写明总体、抽样框、方式（配额 / 分层 / 便利）及其局限 | 便利抽样须说明偏差与补救（配额控制） | [R29] |
| 回收与有效率 | 报告发放数、回收数、有效数、有效率 | 有效率 ≥80%；剔除规则写明 | [R30] |
| 质控 | 质控题（注意力检查 / 反向题）、填写时长过滤、IP / 设备去重、逻辑一致性检查 | 填写时长 <合理下限（如 <1/3 中位时长）判无效 | [R30] |
| 信度 / 效度 | 量表题报告 Cronbach α 与 KMO、Bartlett 检验 | α ≥0.7；KMO ≥0.6（≥0.7 为佳）；Bartlett p<0.05 | [R30][R21] |
| 访谈 | 半结构化提纲（≥8 个开放题），对象分层（消费者 / 经销商 / 企业方 / 专家） | 消费者 8–15 人至信息饱和；企业方 ≥2 人；记录转写入附录 | [R29] |
| 实地 | 门店 / 产地 / 展会观察，拍照留证（匿名处理） | ≥1 次实地，附时间、地点、照片 | [S43] |
| 分析 | 描述统计 + 交叉分析 + 至少 1 种进阶方法（因子 / 聚类 / 回归 / 联合分析 / 文本分析） | 市调大赛“分析与结论”25 分 | [R21] |
| 呈现 | 样本结构表、关键发现 3–5 条（每条一图 + 一句结论）、洞察句；问卷原件入附录 | 调研章 ≤6 页正文，其余入附录 | [S15][R18] |
| 学术诚信 | 数据真实、可提供原始数据；查重 | 市调大赛查重 >20% 取消、规则另有 ≤15% 口径 | [R22][R23] |
