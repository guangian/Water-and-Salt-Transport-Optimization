# 概要

弘宝汝瓷是河南汝州一家拥有省级非遗技艺的汝瓷品牌，年销售额约 1,150 万元，线下景区与门店渠道占比 68%，26—35 岁消费者仅占 37%。本策划书以「宋韵落天青，一釉生万象」为品牌主张，提出“把宋代美学做成可日用的生活方式”的定位，通过产品焕新、内容种草与直播常态化三条主线，用 12 个月把线上收入占比从 28% 提升至 45%，年销售额提升至 2,050 万元。

**核心结论**：

- 市场：中国汝瓷工艺品市场 2025 年预计达 33.5 亿元，2019—2025 年复合增长率 13.9%，线上渠道增速是线下的 3.2 倍 [1]。
- 消费者：386 份问卷显示 72% 的受访者“愿意为可日用的非遗茶器付费 300—800 元”，但对弘宝的无提示提及率仅 27.5%【示例数据，须替换为真实调研结果】。
- 策略：以「天青雅集」茶器套装为旗舰单品，入门价 268 元，建立“开片可养、釉色可鉴、匠人可见”的三重信任机制。
- 预算与效果：传播预算 300 万元（含 8% 机动金），预计带来 5,200 万次曝光、4.68 万笔订单，ROI 2.9。
