# 消费者调研问卷

## 问卷说明

本问卷用于了解消费者对汝瓷产品的认知、购买动机与价格接受度，预计填写时间 5 分钟。所有信息仅用于学术与策划研究，匿名处理。

## 问卷题目

1. 您是否听说过汝瓷？
   - 听说过并购买过
   - 听说过但未购买
   - 没听说过（跳至第 6 题）
2. 请写出您能想到的汝瓷品牌（最多 3 个）：________
3. 您购买或打算购买汝瓷的首要动机是？
   - 自用品茶
   - 送礼
   - 收藏投资
   - 家居陈设
   - 文化认同
4. 您愿意为一套可日用的非遗汝瓷茶器支付的价格区间是？
   - 300 元以下
   - 300—800 元
   - 800—1,500 元
   - 1,500 元以上
5. 您最常通过哪些渠道了解或购买工艺品？（多选）
6. 您的年龄段：18—25 / 26—35 / 36—50 / 50 以上
7. 您所在城市：________
