# 概要

云岫茶坊是武汉本土现制茶饮品牌，20 家门店集中于汉口老城区，2025 年营收 4,860 万元，25—35 岁顾客占比 31%，低于行业均值 48%[1]。本策划书回应企业命题「品牌年轻化与门店焕新」，以「一杯云岫，半城山色」为核心创意，提出 12 个月、300 万元预算的整合传播方案，目标将 25—35 岁顾客占比提升至 45%，全案曝光量 5000 万次，ROI 2.5 倍。

方案分为四个部分：第 1 章说明命题与方法；第 2 章基于 412 份有效问卷（示例数据）与竞品对比给出诊断；第 3 章提出定位、核心创意、传播节奏、预算与 KPI；附录 A1 为调研问卷。

**关键词**：品牌年轻化；门店焕新；整合传播；武汉现制茶饮
