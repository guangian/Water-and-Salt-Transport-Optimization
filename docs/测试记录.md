## 5. 端到端实跑

示例项目：`docs/examples/示例项目_马大姐电解质软糖.md`（品牌策划赛道 · 命题企业 · researchMode=synthetic · 2 轮评审 · 目标 55 页）。脚本：`scripts/e2e_run.sh`（Linux）/ `scripts/e2e_run.ps1`（Windows）。

### 5.1 第 1 次（沙箱，冒烟）

- `smoke=true`、maxTurns 15：验证网关 → SDK → MCP 工具（web_search / web_fetch / update_progress / record_numbers）→ 事件归一化 → SSE → project.json 全链路可通；无产出要求。

### 5.2 第 2 次（沙箱，完整，`p_20261025_010541_a2ey` 第一段）

- 读题解析 7 分钟：任务解析.md 七部分、环境自检.md 齐全。
- 调研阶段暴露三个缺陷：① 主代理为“官方来源占比 ≥ 40%”这一项指标反复补派研究员（A–D + 消费者洞察 + 补 1 + 补 2），调研 > 55 分钟；② SDK 0.3.x 默认把 Agent 调用后台化，主代理向正在运行的子代理“续派”消息，导致该子代理的工具调用全部被打断（`The tool call was interrupted before a result was received`）；③ 主代理随后以“等待子代理通知”结束回复，query 正常返回但阶段未完成，项目落为 paused。
- 修复：`CLAUDE_CODE_DISABLE_BACKGROUND_TASKS=1`（子代理前台同步，主代理拿到返回值才继续）；服务端自动续跑（主代理提前收尾且阶段未全部完成时，3 秒后以 resume 模式续跑，最多 6 次，运行中的阶段回退为 pending）；CLAUDE.md 增加研究预算（检索 ≤ 12 / 抓取 ≤ 8 / ≤ 15 分钟，补派最多 1 次、不阻塞、调研 ≤ 40 分钟）、“同步回收”和“绝不向运行中的子代理追加消息”；`update_progress` 回执带“本阶段用时 / 预算”，检索与抓取超预算时附收尾提醒。
- 检索：沙箱内 Bing 跳首页、DuckDuckGo 被封、百度验证码、搜狗验证；新增 360 搜索提供商（curl 握手 WAF Cookie），主代理与研究员全程可用。

### 5.3 第 3 次（沙箱，从调研续跑，同一项目）

- 续跑后主代理先盘点工作区，补齐被打断的研究员 G（15 条官方文献全部 fetched），合并参考文献（A/B/C/D/F/G + 消费者）并写 `00_调研总览.md`；策略框架 2.07 万字（问题树、洞察句、五步定位链、目标市场打分表、Big Idea 10→3→1、命题回应表），所有二手数据带正式文献编号、一手数据带【示例数据】标记。
- 财务：budget 模式，预算总计 300.0 万（机动金 5%），`财务模型.xlsx` 公式 + 数值校验列、`numbers.json` 合并调研关键数字（`research_` 前缀）。
- 观察到的改进点：财务建模师会去读 `finmodel.py` / `charts.py` 源码确认字段 → 新增 `python -m bizkit.finmodel --example startup|budget` 随包模板，技能文档明确“不要读源码”。
- 图表：制图员一次渲染 23 张 PNG（含财务 7 张），逐张读图自检中文与版式。
- 撰写：主笔分 5 批写 7 章 + 概要 + 引言 + 附录 A1–A4，段落“结论→证据（带文献号）→启示”，表后来源行与读表句齐全；首次渲染 docx → PDF **100 页**（上限 80、目标 55）。根因：页数估算模型“650 字/页 + 图 0.45 + 表行/40”把 87 页正文估成 58 页——62 张表 423 行的占页被严重低估。用这次真实渲染的 12 章逐章页数回归，改为 **600 字/页 + 图 0.45 + 表 0.15 + 表行 0.06 + 章 0.5**（MAE 0.9 页/章），`checks.py`、`docx_render.py`、CLAUDE.md 页数预算表、主笔定义同步更新；压缩一轮后 91 页、模型估 89.6 页，与实际一致。
- 一次误伤：`scripts/e2e_run.sh` 的 240 分钟看门狗调用了 `/stop` 把运行停在压缩阶段；两份脚本改为超时只停止轮询，不再打断运行；项目从撰写阶段 resume 续跑，主代理按新模型做第二轮精准压缩（目标 ≤ 60 页）。
- 后续阶段（路演 → 评审 2 轮 → 打包）的时长、分数与产出见 5.5。
